# 판화(engraving) 그림 조각 규약

랜딩 페이지(SUU-141 푸터, SUU-142 히어로)가 이 폴더의 파일명을 그대로 쓴다.
파일은 사용자가 AI로 생성해 넣는다. 코드는 그림을 만들지 않는다.

| 파일 | 내용 | 비율/크기 | 배경 |
|---|---|---|---|
| `factory.png` | 공장 건물 줄, 굴뚝 3개, 연기 없음 | 3:1, 가로 2400px | 투명 |
| `train.png` | 기차 측면(기관차+화차 2~3량), 오른쪽 향함, 연기 없음 | 가로 1200px | 투명 |
| `smoke-1.png` `smoke-2.png` `smoke-3.png` | 연기 뭉치 3종 | 400×400 | 투명 |
| `hero.png` | 넓은 공장 풍경 판화 | 16:9, 가로 1920px | 투명 |

## 스타일

- 19세기 동판화. 가는 교차 해칭·점각
- 세피아 단색 `#4A2E1E`만. 회색 면 채움·그림자 없음
- **배경 투명** (PNG). 크림 배경 `#F5F0E6`은 CSS가 깐다. 그림에 흰 배경이 박혀 있으면 흰 네모가 뜬다
- 기차·공장에는 연기를 그리지 않는다. 연기는 `smoke-*.png`가 따로 움직인다
