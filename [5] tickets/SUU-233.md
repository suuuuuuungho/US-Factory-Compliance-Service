# SUU-233 feat(frontend): FR diff를 원문·개정문 나란히 비교

## 목표
diff 영역을 줄마다 Before(원문) | After(개정문) 두 칸으로 나란히 그려, 무엇이 무엇으로 바뀌었는지 한눈에 보이게 한다.

## 건드릴 파일
- 고칠 것 `[4]frontend/src/components/FrDiff.tsx` — 이 파일 하나만

## 안 하는 것
- `page.tsx`·`fr-diff.json`·파이프라인 수정
- diff 계산 방식 변경 (`diffWords` 그대로)
- 줄 접기·펼치기, 문맥 줄 더 보기

## 완료 기준 ↔ 테스트
테스트 파일: `[4]frontend/tests/fr_diff_side_by_side.test.tsx`. 기존 `fr_diff_view.test.tsx`(클래스 `diff-removed`/`diff-added`/`diff-changed`, mark 순서 `["A.", "B."]`)도 계속 통과.

| 완료 기준 | 테스트 함수 |
|---|---|
| 줄마다 `[data-diff-row]` 안에 `[data-side='before']`·`[data-side='after']` 하나씩, 칸 머리글 Before/After | `각 줄이 Before/After 두 칸으로 나온다` |
| 삭제 줄은 왼쪽만, 추가 줄은 오른쪽만 글 | `삭제 줄은 왼쪽만, 추가 줄은 오른쪽만 글이 있다` |
| 바뀐 줄: 왼쪽 mark = 빠진 단어, 오른쪽 mark = 새 단어 | `바뀐 줄에서 왼쪽 mark는 빠진 단어, 오른쪽 mark는 새 단어만이다` |
| 문맥 줄은 양쪽 같은 글 | `문맥 줄은 양쪽에 같은 글이 있다` |

## Codex 메모
Claude가 직접 구현·merge (사용자 지시).
- `Row` 컴포넌트가 kind 별로 2칸 grid 를 그린다. `data-diff-row={kind}`, 칸에 `data-side`
- `ChangedText` 는 `side` 를 받아 한쪽만 그린다: before 면 removed 조각만 mark, added 조각은 건너뜀 (after 는 반대). 바로 뒤 구두점은 mark 안으로 삼킨다
- 색: 삭제 `bg-gradient-coral/15 text-gradient-coral`, 추가 `bg-semantic-success/15 text-semantic-success`, 바뀐 줄의 mark 는 `[&>mark]:` 로 같은 색
