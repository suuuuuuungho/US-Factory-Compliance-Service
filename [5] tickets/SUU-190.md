# SUU-190 feat(frontend): 질문 화면을 /applicability 페이지로 옮긴다

## 목표
질문 폼 + 3열(Subpart·Checklist·조문) 화면이 `/` 대신 `/applicability`에서 보인다. `/`는 다음 티켓(SUU-191)에서 히어로로 채운다.

## 건드릴 파일
- `[4]frontend/src/app/applicability/page.tsx` — 지금 `src/app/page.tsx` 내용을 그대로 옮긴다. h1 글자만 `Applicability`로. import 경로 `../../lib/api`
- `[4]frontend/src/app/page.tsx` — 임시 페이지. `<main>` 안에 h1 `US Factory Compliance AI Service`(whitespace-nowrap, text-ink) + 설명문 p(text-accent-blue, "40 CFR Part 63 applicability criteria, with the sections to check.")만 남긴다

## 안 하는 것
- 디자인·기능 변경, TopNav 변경, api.ts 변경
- `tests/` 수정 금지 (import 경로는 이미 바꿔 놓음)
