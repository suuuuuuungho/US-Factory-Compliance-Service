## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| `rrf_merge`: 순위 r에 1/(k+r)을 `chunk_key`별로 합산. 두 목록에 다 있는 청크가 위. 동점은 `chunk_key` 오름차순 | `test_rrf_merge_ranks_chunks_in_both_lists_first` |
| `keyword`가 있으면 `keyword(question, chunk_top_k)`를 부르고, 벡터·키워드를 RRF로 합쳐 상위 `chunk_top_k`개를 리랭커에 넘긴다. 넘기는 청크는 `chunks`의 원본 dict(embedding·텍스트 포함) | `test_search_sections_passes_rrf_candidates_to_rerank` |
| `rerank` 없이 `keyword`만 있으면 `score`는 RRF 점수 | `test_search_sections_hybrid_without_rerank_uses_rrf_scores` |
| `keyword=None`이면 지금(SUU-92/101)과 완전히 같다 | `test_search_sections_without_keyword_is_unchanged` |

## Codex 메모
- **`rrf_merge(ranked_lists, *, k=60) -> list[dict]`**: 입력은 순위순 청크 dict 목록 여러 개(순위는 1부터). 출력은 `{**chunk, "score": 합산값}` — `chunk`는 그 `chunk_key`를 **처음 본 목록의 dict**. `(-score, chunk_key)`로 정렬. 순수 함수, 입력 dict를 바꾸지 않는다.
- **`search_sections(question, *, embed, chunks, keyword=None, rerank=None, top_k=5, chunk_top_k=300)`**. `keyword`가 있으면:
  1. `vector = rank_chunks_by_similarity(query_embedding, chunks, top_k=chunk_top_k)` (지금과 같음)
  2. `hits = keyword(question, chunk_top_k)` → 각 hit의 `chunk_key`로 `chunks`에서 원본 dict를 찾아 목록으로 만든다(`by_key = {c["chunk_key"]: c for c in chunks}`). 키워드 결과는 `chunk_key, node_key, score`만 있고 텍스트·임베딩이 없으므로 **반드시 원본 dict로 바꿔서** 넘긴다(리랭커가 `context_text`/`chunk_text`를 씀).
  3. `ranked_chunks = rrf_merge([vector, keyword_chunks])[:chunk_top_k]`
  4. 그 다음은 지금과 같다(`rerank`가 있으면 점수 교체 → `rank_sections`).
  `keyword=None`이면 1 → 4로 바로 간다(현재 코드 그대로).
- **`run_eval.py`**: `--config` choices에 `hybrid` 추가. `hybrid`는 `rerank`와 같은 설정(텍스트 포함 fetch, `rerank=rerank`, `chunk_top_k=150`, `cost_usd` 계산)에 `keyword=keyword`만 더한다. `keyword` 클로저:
  ```python
  def keyword(question, k):
      return client.rpc("rag_keyword_search",
                        {"p_release_id": release_id, "p_query": question, "p_k": k}).execute().data
  ```
  RPC는 SUU-99에서 만든 SQL 함수(`[2] db/migrations/SUU-99_rag_keyword_search.sql`), `[{"chunk_key","node_key","score"}]`를 점수순으로 돌려준다(p50 ≈ 1초). `search_ms`에 RPC 시간이 포함되는 건 그대로 둔다. run_id는 기존 규칙대로 `f"{today}_hybrid_v1"`, `notes`에 `+ keyword RRF` 정도 덧붙인다. `args.config == "rerank"` 비교가 여러 곳에 있으니 `args.config in ("rerank", "hybrid")`로 바꾼다. `contextual`·`rerank`는 지금과 완전히 같은 동작·출력.
