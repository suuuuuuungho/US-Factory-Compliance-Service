## Codex 메모

### `ecfr_answer.py`
- `ANSWER_MODEL = "gpt-5-mini"`, `MAX_COMPLETION_TOKENS = 6000`(추론 토큰 포함, 답 JSON이 길다).
- `ANSWER_SYSTEM`(영어): 너는 EPA NESHAP(40 CFR 63) 전문가. 공장 질문과 관련 조문 전문을 준다. **판정 기준표**를 JSON으로 만들라. 스키마를 그대로 적어라:
  `{"candidates": [{"subpart": "PPPP", "title": "...", "criteria": [{"criterion": "...", "citations": ["40 CFR 63.xxxx(a)"]}]}], "checklist": ["..."]}`
  규칙: candidates 1~3개, 넘겨준 조문의 Subpart만. criterion은 한 문장 "if … then subject / if … then not". citations는 **넘겨준 조문에서만**, `40 CFR 63.xxxx(para)` 형식. checklist는 공장이 확인할 사실. **Do NOT give a verdict or conclusion on whether the rule applies** — 기준만. 다른 필드 금지. JSON만 출력.
- `build_answer_request(question, sections) -> dict`: `sections = [{"section_key", "subpart", "text"}]`. user = `QUESTION:\n...\n\nSECTIONS (N):\n\n[1] section-63.4481 (Subpart PPPP)\n<text>\n\n[2] ...`. 반환 dict는 `ecfr_answer_score.build_judge_request`와 같은 꼴(`model`, `max_completion_tokens`, `messages`).
- `parse_answer(text, given_section_keys) -> tuple[dict, list[str]]`:
  1. ```json 펜스 벗기고 `json.loads`. 실패 → `ValueError`.
  2. 필수: `candidates`(비어 있지 않은 list), `checklist`(비어 있지 않은 list). 각 candidate: `subpart`(str), `criteria`(비어 있지 않은 list). 각 criterion: `criterion`(str), `citations`(비어 있지 않은 list). 하나라도 빠지면 `ValueError`. `title`은 선택(없으면 그대로).
  3. 허용 키 밖(최상위: candidates/checklist, candidate: subpart/title/criteria, criterion: criterion/citations)은 **떼어내고** `issues.append(f"unknown field: {key}")`.
  4. 인용마다 `ecfr_eval.citation_section_key`로 조문 키 → given에 없으면 `issues.append(f"citation outside given sections: {key}")`. 인용은 지우지 않는다(근거율이 잡는다). `citation_section_key`가 `ValueError`를 내면(63.xxxx 아님) 그것도 issue로.
- `call_openai_chat(request, *, client=None) -> dict`: `ecfr_llm_rerank.call_openai_rerank_api`와 같은 방식. `client.chat.completions.create(**request)` → `{"text", "prompt_tokens", "completion_tokens"}`. 답 생성과 심판 둘 다 이걸로 부른다.

### `run_answer.py`
- 상수: `TOP_N = 5`, `ANSWER_RUNS = HERE / "answer_runs.jsonl"`, `TEXTS_CACHE = HERE / "cache" / "section_texts.json"`, `SEARCH_RUN_ID = "2026-09-18_hybrid_v2_llm_gpt-5-mini"`, `PRICE_PER_M`은 `llm_rerank.py` 것을 import.
- `join_section_text(rows) -> str`: `chunk_key` 마지막 조각으로 정렬 — 본문 `0`, `0-1`, `0-2`…(숫자 순) 먼저, 표 `1`, `2`… 뒤. `chunk_text`만 `"\n\n"`으로 잇는다(context_text는 넣지 않는다 — 원문만). 정렬 키 예: `piece = key.rsplit("/", 1)[1]; (0, int(piece.split("-")[1]) if "-" in piece else 0) if piece.startswith("0") else (1, int(piece))`.
- `fetch_texts(section_keys) -> dict[str, str]`: `llm_rerank.fetch_heads`를 본떠 캐시 우선. Supabase `rag_chunk`에서 `.like("chunk_key", f"%/{key}/%")`로 그 조문 청크 전부(`chunk_key,chunk_text`) → `join_section_text`. `release_id`는 `common_dataset_current`에서. 캐시 파일에 저장.
- `top_sections(line) -> list[dict]`: `line["llm_order"][:TOP_N]`, subpart는 `line["ranked_all"]`의 `[key, subpart]`에서 찾는다.
- `score_line(case, answer, *, given, issues, judge_score, judge_text) -> dict`: `ecfr_answer_score`의 세 함수로 점수, 키 = `case_id, answer, given, issues, subpart, citation_recall, citation_grounded, outside_citations, judge, judge_text`.
- `answer_run_record(run_id, outs, *, search_run_id, model, judge_model, top_n, cost) -> dict`: 키 = `run_id, run_at(UTC …Z), search_run_id, eval_set_version="v2", n_cases, top_n, answer_model, judge_model, metrics=aggregate(outs), cost_usd={"per_query","total"}`.
- `main()`: `--model gpt-5-mini --judge-model gpt-5-mini --limit N --workers 8 --replay --retry-empty`.
  1. `load_env()`(run_eval). 검색 결과 `results/<SEARCH_RUN_ID>.jsonl` + 케이스 `rag_eval_case_v2.jsonl`.
  2. 케이스마다: `top_sections` → 전문 → `build_answer_request` → 호출 → `parse_answer`. `ValueError`면 그 케이스는 `answer=None, issues=["parse error: ..."]`, 점수 전부 0, judge 0 (심판 안 부름). 원문 응답은 `raw_answer`로 저장.
  3. 답이 있으면 `build_judge_request` → 호출 → `parse_judge`. 파싱 실패면 judge 0 + issue.
  4. `--replay`: 저장된 results jsonl의 `raw_answer`·`judge_text`를 다시 파싱·채점($0). `--retry-empty`: 저장 결과 중 `answer is None`인 케이스만 다시 부른다.
  5. 결과 `results/<날짜>_answer_v2_<model>.jsonl` 저장. `--limit` 없을 때만 `answer_runs.jsonl`에 한 줄 append. 점수판·토큰·비용 출력.
- `.gitignore`에 `cache/`가 이미 있는지 확인. 없으면 `section_texts.json`은 커밋하지 않는다.
