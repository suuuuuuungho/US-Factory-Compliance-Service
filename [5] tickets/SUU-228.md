# SUU-228 feat(db): 2024년 이후 Rule의 섹션별 eCFR 전후 diff를 JSON으로 만든다

## 목표
FR 문서에는 "고친 후" 글만 있어 뺀 부분(빨간 줄)을 못 만든다. 규칙마다 고친 섹션(FR XML `<SECTNO>`)을 뽑고, eCFR 섹션 API로 시행 전날(D-1)·시행일(D) 본문을 받아 문단 단위로 비교해 **바뀐 문단만** JSON 한 파일로 쓴다. 프론트(SUU-229)가 읽고, DB(SUU-230)가 적재한다.

## 건드린 파일
- 만듦 `[2] db/pipeline/2_Federal Register/fr_diff.py` — `amended_sections`(SECTNO → 63.x 목록), `section_blocks`(DIV8 → 문단, 제목·CITA 제외), `diff_blocks`(difflib, 바뀐 행 + 앞뒤 맥락 1행), `build`(문서 순회·캐시·JSON), CLI
- 만듦 `[2] db/tests/2_Federal Register/test_fr_diff.py` — 6개, 네트워크 없음(fetch 주입)
- 만듦 `[4]frontend/public/fr-diff.json` — 실행 결과 (2024-01-01 이후 Rule 43건)

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 |
|---|---|
| 작은 전/후 XML로 added·removed·changed 각 1개, 안 바뀐 문단 없음 | `test_diff_blocks_keeps_only_changed_rows_plus_one_line_of_context`, `test_diff_blocks_identical_returns_nothing` |
| SECTNO 개수(중복 제외, Part 63만) = amended_sections | `test_amended_sections_reads_part63_sectno_in_order_without_duplicates`, `test_build_fetches_day_before_and_effective_day_per_amended_section` |
| 시행일 없음·XML 없음은 빈 diff + reason | `test_build_marks_documents_without_effective_date_or_xml` |

## 실행
```
python "[2] db/pipeline/2_Federal Register/fr_diff.py" --fr-root "<root>/[2] db/2) Federal Register" --parsed "<root>/[2] db/2) Federal Register/parsed/2026-09-21" --ecfr-nodes "<root>/[2] db/1) eCFR/parsed/2026-09-11/v1/nodes.jsonl" --out "[4]frontend/public/fr-diff.json"
```

## 메모
- eCFR 섹션 API는 `Accept-Encoding: gzip` 없으면 406 → 기존 `ecfr_fetch.fetch` 재사용
- 같은 날 시행된 규칙도 SECTNO로 섹션이 갈려서 diff가 섞이지 않는다
- 개정 이력 줄(`<CITA>`)은 항상 바뀌므로 비교에서 뺀다. 표(Table 1 to Subpart …)는 SECTNO가 아니라 이번 범위 밖
- 문단 번호 이동((b)→(c))은 removed+added로 보인다. 진짜 이동 감지는 안 함
- reason: `no_effective_date` / `no_xml` / `no_sectno` / `no_text_change`
- 사용자 지시로 Claude가 직접 구현 (Codex 미사용)
