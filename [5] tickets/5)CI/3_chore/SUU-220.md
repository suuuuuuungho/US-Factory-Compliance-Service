# SUU-220 chore(ci): Vercel 미리보기 배포를 끄고 main만 배포한다

## 목표
Vercel Hobby는 굴러가는 24시간에 배포 100번까지. PR마다 미리보기 배포가 나가 한도를 다 써서(9/21 저녁부터 "Deployment rate limited") main 배포까지 막혔다. main 외 브랜치는 배포를 만들지 않게 한다.

## 건드린 파일
- 만듦 `[4]frontend/vercel.json` — `git.deploymentEnabled: { "main": true, "**": false }` (Vercel Root Directory가 `[4]frontend`라 여기)
- 고침 `[4]frontend/tests/test_vercel_cd.py` — vercel.json 검사 1개 추가

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 |
|---|---|
| main true, ** false | `test_vercel_cd.py::test_vercel_json_deploys_only_main` |
| 다음 PR부터 Vercel 체크가 안 생김 | merge 후 눈으로 확인 |

## 메모
- 근거: https://vercel.com/docs/project-configuration/git-configuration (glob 지원, 여러 규칙 중 하나라도 true면 배포)
- 미리보기가 필요하면 `vercel` CLI로 수동 배포하거나 이 파일에서 브랜치를 true로 추가
