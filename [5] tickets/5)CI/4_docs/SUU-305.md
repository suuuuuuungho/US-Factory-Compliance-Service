# SUU-305 docs(ci): README를 project 폴더로 옮기고 /report가 갱신

## 왜
포트폴리오 폴더를 여는 사람이 파일마다 무엇인지 바로 알게 하고, 문서가 바뀌어도 README가 뒤처지지 않게 한다.

## 변경 범위
- 지움: `[1] docs/README.md` (내용이 비어 있었음)
- 만듦: `[1] docs/1) project/README.md` — 이 폴더 파일(summary·full md와 Word·PDF)마다 한 줄 설명
- 고침: `.claude/commands/report.md` — 4단계 "README 갱신" 추가

## 완료 기준
- README가 project 폴더에 있고, 폴더 안 파일 설명이 빠짐없이 있다
- `/report` 순서에 README 갱신 단계가 있다
- 코드·테스트 변경 없음
