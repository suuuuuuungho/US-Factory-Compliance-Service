## Codex 메모
- 공개 함수 2개
  - `build(text: str, toc: bool = False) -> docx.document.Document`: md 글을 Word 문서 객체로 바꾼다. 저장은 하지 않는다.
  - `main(paths: list[str], pdf: bool = True) -> int`: 파일마다
    1. `md_check.main([path])`를 부른다 (자동 수정 저장 + 오류 출력). 0이 아니면 그 파일은 Word를 만들지 않고 다음 파일로.
    2. 고쳐진 md를 다시 읽어 `build(text, toc=path.stem.endswith("_full"))` → md 옆 `같은이름.docx`로 저장.
    3. `pdf=True`면 `to_pdf(docx_path)`로 같은 이름 `.pdf`를 만든다.
    4. 하나라도 실패하면 1, 아니면 0.
  - `if __name__ == "__main__"`: `python md_to_docx.py [--no-pdf] <md>...`
- `to_pdf(docx_path)`: 로컬 Word COM으로 연다 → 필드(목차) 갱신 → docx 다시 저장 → PDF 저장(`wdFormatPDF = 17`) → 닫기. pywin32는 설치돼 있지 않으니 `subprocess`로 PowerShell `New-Object -ComObject Word.Application`를 부른다 (새 의존성 추가 금지). 테스트는 없다. 로컬에서 한 번 직접 돌려 확인.
- md 구조 (규칙 원본은 `3_doc_rules.md`. md는 이미 `md_check`를 통과한 상태라고 가정해도 된다)

| md | Word |
|---|---|
| `# 제목` | 스타일 `Title`, 문서 첫 문단 |
| `#` ~ 첫 `##` 전 | 표지 (문단·목록) |
| `## 장` | `Heading 1`, 글자 `01  장` (두 자리, 장마다 +1), 앞에서 쪽 나눔 |
| `### 절` | `Heading 2`, 글자 `1.1  절` (장 번호.절 번호, 장이 바뀌면 절은 1부터) |
| `#### 소절` | `Heading 3`, 번호 없음 |
| `> 문장` | 문단 배경 `#EAF6FF`, 왼쪽 테두리 `#0099FF` (굵기 약 3pt) |
| `1. 가` / `    1. 가1` | 글자 `1. 가` / `(1) 가1`. 2단계는 1단계보다 왼쪽 들여쓰기가 크다 |
| `- 하나` / `    - 둘` | 글자 `• 하나` / `– 둘` (en dash U+2013) |
| `**굵게**` | 굵게 + `#0072C6` |
| `` `코드` `` | 백틱 없이, 글꼴 `Consolas` |
| `**Q.** …` / `**A.** …` | 글자 `Q. …` / `A. …`, `Q.`·`A.`는 굵게. 문단 배경 `#F2F2F2` |
| `근거: …` | 모든 run 9pt, `#6B6B6B` (목록 안 `    - 근거: …`도 같은 모양, 기호는 붙여도 됨) |
| `①`로 시작하는 문단 | 첫 run이 `①`로 시작하고 굵게 |
| md 표 | 머리행 셀 배경 `#F2F2F2`, 테두리 `#D9D9D9`. 셀 글이 `채택`으로 시작하면 `#15803D`, `기각`으로 시작하면 `#B91C1C` |
| ```` ```text ```` | 줄마다 한 문단, 앞 공백 그대로, 글꼴 `Consolas`, 배경 `#F2F2F2` |

- 목록 번호는 Word 자동 번호가 아니라 **글자로** 넣는다 (테스트가 `p.text`로 확인).
- 스타일 (테스트가 스타일 자체를 확인한다)
  - `Normal`, `Title`, `Heading 1~3`: `w:rFonts`의 `ascii`·`hAnsi`·`eastAsia` 모두 `Pretendard` (기본 템플릿 제목 스타일은 테마 글꼴을 쓰므로 직접 덮어써야 한다)
  - `Normal`: 10.5pt, 글자색 `#1A1A1A`, 뒤 간격 6pt
  - `Heading 1`: 앞 24pt / 뒤 12pt, 앞에서 쪽 나눔. `Heading 2`: 18 / 6. `Heading 3`: 12 / 4
  - 제목 글자색은 `#1A1A1A`. 번호 부분만 `#0072C6`로 해도 된다
- 표지·목차·쪽 번호
  - 표지 = `Title` ~ 첫 `Heading 1` 전. `Heading 1`이 앞에서 쪽을 나누므로 표지는 따로 한 쪽이 된다
  - `toc=True`면 표지 뒤, 첫 장 앞에 쪽 나눔 + "목차" + `TOC \o "1-2" \h \z \u` 필드. 목차 내용은 Word가 PDF 만들 때 갱신한다
  - 쪽 번호: 바닥글에 `PAGE` 필드, 가운데 정렬. 쪽 번호만 넣는다
- 용지 A4, 여백은 적당히 (25mm 안팎).
- `.claude/commands/report.md` (`/report`): 인자 없으면 `[1] docs/1) project/0_Project_summary.md`, `1_Project_full.md` 두 파일. 순서
  1. `python "[1] docs/4) workflow/report/md_to_docx.py" <두 md>` 실행
  2. 자동으로 고친 것과 오류 목록을 쉬운 한국어로 보여 준다. 오류가 있으면 Word를 안 만들었다고 말하고 멈춘다
  3. 성공하면 만든 .docx/.pdf 경로 4개를 알려 준다
- 로컬 실행: 폴더 이름에 `[]`가 있어 경로 지정이 안 되므로 루트에서 `python -m pytest -k md_to_docx`. venv에 pip가 없으니 설치는 `uv pip install python-docx==1.2.0`
