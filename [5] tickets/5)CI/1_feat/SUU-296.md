## Codex 메모
- 공개 함수 3개
  - `fix(text: str) -> str`: 자동으로 고친 글을 돌려준다. 줄바꿈은 `\n` 기준.
  - `check(text: str) -> list[Issue]`: 알려 줄 문제 목록. `Issue`는 `line`(1부터), `code`(아래 표), `message`(한국어 한 줄)를 가진다. 문제가 없으면 `[]`.
  - `main(paths: list[str]) -> int`: 파일마다 `fix`를 적용해 **바뀐 경우에만** 저장하고, `check` 결과를 `파일:줄: 메시지`로 출력한다. 문제가 하나라도 있으면 1, 없으면 0. `if __name__ == "__main__": sys.exit(main(sys.argv[1:]))`
- 파일의 줄바꿈(CRLF/LF)은 읽은 그대로 유지해서 저장한다.
- ```` ``` ```` 코드 블록 안은 고치지도, 검사하지도 않는다.
- 보고 코드

| code | 뜻 |
|---|---|
| `heading_too_long` | `#` 30자, `##`~`####` 20자 초과 (공백 포함) |
| `missing_callout` | `##` 다음 첫 블록이 `> `가 아님 (줄 = 제목 줄) |
| `heading_level` | 단계 건너뜀(`##` 아래 바로 `####`) 또는 `#####` 이상 |
| `duplicate_heading` | 같은 제목 두 번 (줄 = 두 번째) |
| `q_without_a` | `**Q.**` 블록 다음 블록이 `**A.**`로 시작하지 않음 |
| `list_depth3` | 목록 3단계 (공백 8칸 이상 들여쓴 항목) |
| `circled_multi_chapter` | 원 숫자 `①`~`⑩`로 시작하는 문단이 두 번째 `##` 장에도 있음 (줄 = 다른 장의 첫 원 숫자) |
| `paragraph_linebreak` | 문단 안 줄바꿈 (줄 = 이어진 둘째 줄). 목록·표 줄은 제외 |
| `multi_emphasis` | 한 줄에 `**…**` 두 곳 이상. `**Q.**`, `**A.**`는 세지 않음. 문단은 한 줄, 목록은 항목 한 줄이 한 블록 |
| `stray_quote` | 장의 첫 블록이 아닌 곳의 `>` |
| `manual_numbering` | 줄 맨 앞(들여쓰기 뒤 포함)의 `1)`, `(1)`, `가.`, `a.`, `0)`, `STEP 1`, `Sol_1`, `1st.` |
| `bracket_label` | `[`로 시작하는 줄 (`[근거]`는 fix가 먼저 `근거:`로 바꿈) |
| `horizontal_rule` | `---` 한 줄 (표의 `|---|`는 아님) |

- 제목 번호 지우기: `1.`, `1)`, `1.1`, `①`, `Sol_1`, `1st.` 뒤에 공백이 올 때만. `1인 개발…`처럼 숫자 뒤에 글자가 바로 붙으면 번호가 아니다.
- `1.` 목록 번호 다시 매기기: 같은 들여쓰기 단계에서 1부터. 2단계는 부모 항목마다 1부터. 빈 줄로 나뉘면 새 목록이라 다시 1부터.
- `**Q.**`처럼 `**`로 시작하는 줄은 `*` 목록이 아니다.
- 규칙 원본은 `3_doc_rules.md`. 테스트에 없는 애매한 경우는 규칙 문서를 따른다.
- 로컬 실행: 폴더 이름에 `[]`가 있어 경로 지정이 안 되므로 루트에서 `python -m pytest -k md_check`
