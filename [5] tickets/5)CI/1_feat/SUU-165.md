## Codex 메모

### `render.yaml`
- 마지막 두 줄만:
```yaml
      - key: FRONTEND_ORIGIN
        value: "http://localhost:3000,https://us-factory-compliance-service.vercel.app"
```
- 테스트는 `- key: FRONTEND_ORIGIN\n  value: ...` 다음 줄을 쉼표로 쪼갠다. 따옴표 있어도 됨, 쉼표 뒤 공백 없이. Blueprint `value:`라 대시보드에서 바꿔도 sync 때 덮인다 → 파일에 넣는 게 맞다
- `[3] backend/tests/test_render.py`가 `- key: X` 6개를 그대로 세니 키 추가·삭제 금지

### `slack.yml`
- Vercel은 GitHub Deployment를 만들고, 상태가 바뀔 때마다 `deployment_status` 이벤트가 온다(Render는 안 만든다 — SUU-160). environment 이름은 `Production` / `Preview`. state는 `pending` → `in_progress` → `success` | `failure` | `error`
- `on:`에 한 줄 추가(types 없이. 기본이 created뿐):
```yaml
  deployment_status:
```
- `if: >-` 블록에 셋째 분기(들여쓰기 6칸 유지, 테스트는 `      `로 시작하는 줄을 잡는다):
```yaml
      (github.event_name == 'deployment_status' &&
        github.event.deployment.environment == 'Production' &&
        (github.event.deployment_status.state == 'success' ||
         github.event.deployment_status.state == 'failure'))
```
- env 두 줄 추가(글자 그대로):
```yaml
      DEPLOY_STATE: ${{ github.event.deployment_status.state }}
      DEPLOY_URL: ${{ github.event.deployment_status.environment_url }}
```
- 스크립트 맨 앞에 분기 하나(`"$EVENT" = deployment_status` 그대로):
```bash
          if [ "$EVENT" = deployment_status ]; then
            if [ "$DEPLOY_STATE" = success ]; then
              text="🚀 *Vercel 배포 완료* — <$DEPLOY_URL|열기>"
            else
              text="🔴 *Vercel 배포 실패* — <$DEPLOY_URL|Vercel 보기>"
            fi
          elif [ "$EVENT" = workflow_run ]; then
```
- 실패 때 `environment_url`은 비어 있을 수 있다. 그래도 링크 없이 메시지는 간다. 따로 처리 안 함
- `error` state는 안 잡는다(Vercel 내부 문제, 드묾)
