# SUU-196 feat(frontend): Ask 뒤 제목이 사라지고 질문 칸이 위로 붙는다

## 목표
Ask 버튼은 처음부터 textarea 오른쪽에 같은 높이로 붙어 있고, Ask를 누르면 h1 "Applicability"와 파란 설명 p가 사라져 질문 칸이 맨 위로 올라가고 Workspace 칸이 더 길어진다.

## 건드릴 파일
- `[4]frontend/src/app/applicability/page.tsx`
  - `asked` state 하나 추가. `onSubmit`에서 `true`. h1·p는 `!asked`일 때만 렌더
  - form: `flex flex-col gap-2` → `flex flex-row gap-2`. textarea에 `flex-1`, 버튼은 `self-start` → `self-stretch` + 고정 너비(`shrink-0`, `px-6`)
- `[4]frontend/tests/ask_inline_form.test.tsx` — 검사 2개

## 안 하는 것
- Workspace·카드 모양, TopNav, 다른 페이지, 첫 화면(/)의 h1
- 에러가 나도 h1·p를 다시 보여주지 않는다 (한 번 물어보면 계속 숨김)

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 |
|---|---|
| 처음 렌더에서 버튼이 textarea 바로 오른쪽 형제, form `flex-row`, textarea `flex-1`, 버튼 `self-stretch` | `ask_inline_form.test.tsx` — 처음부터 Ask 버튼이 textarea 바로 오른쪽 형제이고… |
| Ask 누르면 로딩 중·답 도착 후 모두 h1·p가 DOM에 없다 | `ask_inline_form.test.tsx` — Ask를 누르면 로딩 중에도, 답이 온 뒤에도 h1과 설명 p가 사라진다 |
| 처음엔 h1이 Applicability | 기존 `applicability_page.test.tsx` 그대로 통과 |

## Codex 메모
- `rounded-full` 버튼이 textarea 높이(3줄)만큼 늘어나면 알약이 아니라 캡슐 모양이 된다. `rounded-md`로 textarea와 맞춘다
