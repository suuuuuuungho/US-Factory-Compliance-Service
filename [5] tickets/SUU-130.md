# SUU-130 chore(rag): RRF 가중치별 후보 풀 Recall@150을 잰다

## 목표
리랭커 앞 단계(vector + BM25 → RRF)의 후보 풀에 정답이 얼마나 들어가는지 가중치·k·depth별로 재고, SUU-129 실패를 pool-miss / rank-miss로 나눈다. rerank 없음, $0. C-7.

## 건드린 파일
- 고침: `[2] db/pipeline/5_rag/ecfr_search.py` — `rrf_merge(weights=...)` 선택 인자. 없으면 예전과 같음, 0이면 그 목록은 건너뜀
- 만듦: `[6] rag/eval/sweep_rrf.py`(진단 + 132조합 스윕), `results/rrf_sweep.csv`
- 만듦: `[2] db/tests/5_rag/test_ecfr_rrf_weights.py`, `[6] rag/tests/test_sweep_rrf.py`
- 고침: `results/rag_eval_result.md`(SUU-130 절 맨 앞), `rag_eval_plan.md` [9]·[14] C-7

## 안 하는 것

## 결과
- recall@150: 기본(w 0.5, k 60, depth 150) 0.889 → 최고(w 0.3, k 60, depth 300) 0.900. +1.1%p = 동점 → **가중치 튜닝 안 함**, Kanon 확인도 안 함.
- k는 영향 없음(depth 150에선 k 10~200 전부 0.889). depth 300이 +1.1%p.
- BM25 단독 풀 0.873 > vector 단독 0.842. 섞으면(w 0.3~0.5) 0.89~0.90.
- 진단: reranker miss 8 = pool 5 + rank 3, **hybrid miss 7 = pool 2 + rank 5** → 병목은 리랭커.
- adi-M200005는 vector 150 후보 안에 있다 — SUU-119의 "후보 밖" 판단 정정.
