# SUU-215 feat(frontend): 질문 칸 아래 예시 질문 3개, 제목은 28px

## 목표
/applicability 제목을 About·Amendment·Community 와 같은 `text-[28px] font-bold text-ink` 로. PromptBar 는 640px. 그 아래 예시 질문 3개(A-1·A-2·A-3 EN)를 누르면 PromptBar 에 그 글이 올라가 Send 할 수 있다.

## 건드릴 파일
- 고칠 것 `[4]frontend/src/app/applicability/page.tsx` — h1 클래스, `width={640}`, `value={preset}`, `<ul aria-label="Example questions">` 버튼 3개 (`EXAMPLES` 상수). 설명 p 는 그대로
- 고칠 것 `[4]frontend/src/components/PromptBar.tsx` — `value?: string` prop 추가: 바뀌면 `setDraft(value)`. 이것 말고는 원본 그대로

## 안 하는 것
- 예시 질문 자동 전송 (누르면 글만 올라간다)
- 답 뒤 Workspace 화면, 다른 페이지

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 (`example_questions.test.tsx`) |
|---|---|
| h1 클래스 = About h1 클래스 | `h1 클래스가 About 페이지 h1 과 같다` |
| `.prompt-bar` style 에 `--pb-w: 640px` | `PromptBar 너비가 640px 다` |
| 예시 3개, 누르면 Prompt 값 = 그 글, Send 켜짐 | `예시 질문 3개가 있고, 누르면 Prompt 칸에 그 글이 들어가고 Send 가 켜진다` |

## 메모
- 예시 출처: `[6] rag/eval/manual_test_questions.md` A-1(PPPP 솔벤트 접합), A-2(M 드라이클리닝), A-3(ZZZZ 외딴 엔진). EN 전문 그대로
- PromptBar 는 draft 를 자기 state 로 가지므로 `value` 를 useEffect 로 흘려 넣는다(page 의 `preset` state). 같은 예시를 연달아 두 번 누르면 두 번째는 아무 일도 없다(값이 같아서) — 허용
