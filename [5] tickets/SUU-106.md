## Codex 메모

테스트가 부르는 것:

```python
def program_row(row: dict[str, str]) -> dict
def subpart_row(row: dict[str, str], code_map: dict[str, dict]) -> dict
def pollutant_row(row: dict[str, str], source_row_no: int) -> dict
```

- 실제 헤더 (2026-09-17 ZIP):
  - PROGRAMS 7열: `PGM_SYS_ID, PROGRAM_CODE, PROGRAM_DESC, AIR_OPERATING_STATUS_CODE, AIR_OPERATING_STATUS_DESC, BEGIN_DATE, UPDATED_DATE`. 날짜는 전부 `MM/DD/YYYY`.
  - PROGRAM_SUBPARTS 5열: `PGM_SYS_ID, PROGRAM_CODE, PROGRAM_DESC, AIR_PROGRAM_SUBPART_CODE, AIR_PROGRAM_SUBPART_DESC`. 코드 앞 7글자 분포: CAANSPS 94k, CAAMACT 70k, **CAAGACT 20k(공식 사전에 없음 → 전부 unresolved, 정상)**, CAANESH 5k.
  - POLLUTANTS 7열: `PGM_SYS_ID, POLLUTANT_CODE, POLLUTANT_DESC, SRS_ID, CHEMICAL_ABSTRACT_SERVICE_NMBR, AIR_POLLUTANT_CLASS_CODE, AIR_POLLUTANT_CLASS_DESC`. 지금 데이터엔 빈 코드가 0건이지만 규칙은 둔다.
- 키 순서 (테스트가 dict 통째 `==`):
  - program: `pgm_sys_id, program_code, description, status_code, status_desc, begin_date, updated_date, raw_dates`. `raw_dates = {"BEGIN_DATE": row["BEGIN_DATE"], "UPDATED_DATE": row["UPDATED_DATE"]}` 원문 그대로.
  - subpart: `pgm_sys_id, program_code, subpart_code, subpart_desc, cfr_title, cfr_part, cfr_subpart, mapping_status`.
  - pollutant: `pgm_sys_id, pollutant_key, pollutant_code, description, srs_id, cas_number, class_code, class_desc, source_locator, review_status`.
- `code_map`은 `{raw_subpart_code: code_map행}` (SUU-104 jsonl 행 그대로: `cfr_title="40"` 문자열, `review_status` ok/unresolved/conflict). `subpart_row` 규칙:
  - 없음 → `mapping_status="unresolved"`, cfr 셋 None
  - 있고 `review_status == "ok"` → `"mapped"`, `cfr_title=int(entry["cfr_title"])`, `cfr_part`·`cfr_subpart`는 문자열 그대로
  - 있고 `review_status != "ok"` → `mapping_status=entry["review_status"]` (`conflict`/`unresolved`), cfr 셋 None
- `""` → `None`: `echo_values.is_missing`. 대상은 `status_code, status_desc, pollutant_code, srs_id, cas_number, class_code, class_desc`. `description`·`subpart_desc`는 그대로.
- 날짜는 `echo_values.parse_date`. 값 `strip()` 안 함. 표준 라이브러리만, 60줄 안팎. `from echo_values import is_missing, parse_date` (평면 import — `echo_facility.py`와 같은 방식).
