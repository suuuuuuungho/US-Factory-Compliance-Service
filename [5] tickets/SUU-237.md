## Codex 메모

### 데이터 (`public/echo-stats.json`, 이미 main에 있음)
```ts
type EchoStats = {
  summary: { facilities: number; mfg_facilities: number; violation_facility_pct: number;
             penalty_count: number; penalty_median_usd: number | null; deviation_y_pct: number };
  subparts: { code: string; desc: string; facilities: number; mfg_facilities: number;
              violation_facility_pct: number; penalty_count: number;
              penalty_median_usd: number | null; deviation_y_pct: number }[];   // 131개, facilities 내림차순
  yearly: { year: number; violations: number; penalties: number }[];            // 2000~2026
};
```
- `penalty_median_usd`는 null 인 Subpart가 8개 있다. 표엔 `—`, 정렬하면 맨 뒤
- `desc`는 `"MACT Part 63 - Subpart ZZZZ - STATIONARY ..."` 처럼 길다. 앞의 `MACT Part 63 - Subpart X - ` 를 떼고 보여줘도 되고, truncate 해도 됨

### 테스트가 찾는 DOM (이 이름을 꼭 써야 한다)
- 타일: `data-testid="tile-facilities" | "tile-violation-pct" | "tile-penalty-median" | "tile-deviation-pct"`. 텍스트에 `49,618` / `27.9` / `9,098` / `18.5` 가 들어가면 됨 (천 단위 콤마는 `toLocaleString("en-US")`. 중앙값 9098.5 → `$9,098` 또는 `$9,098.5` 둘 다 통과)
- Subpart 행: `<tr data-testid="subpart-row" data-code={code}>`
- 제조업 토글: `<input type="checkbox">` + `<label>제조업만</label>` (getByRole("checkbox", { name: "제조업만" }))
- 정렬 헤더: `<th>` 안에 `<button>` 이고 이름에 `위반 시설`, `벌금 중앙값` 이 들어감. 클릭하면 그 열 **내림차순**. (같은 열 다시 클릭 시 오름차순 토글은 자유. 테스트는 첫 클릭만 본다)
- 첫 화면 정렬은 JSON 순서 그대로 (정렬 상태 없음)
- 연도별 차트: `<div data-chart="yearly">` 안에 Bklit `<BarChart>` (또는 AreaChart). 테스트는 ResizeObserver 가짜로 600×300 을 주니 `<svg>` 가 나온다

### 차트 쓰는 법 (SUU-235 설치본)
```tsx
import { BarChart } from "@/components/charts/bar-chart";
import { Bar } from "@/components/charts/bar";
<div data-chart="yearly">
  <BarChart data={stats.yearly} xDataKey="year">
    <Bar dataKey="violations" />
    <Bar dataKey="penalties" />
  </BarChart>
</div>
```
- `tests/bklit_chart_install.test.tsx` 가 실제 사용 예. `Bar` 두 개가 안 예쁘면 위반·벌금 차트 두 개로 나눠도 됨
- 색은 `globals.css` 의 `--chart-1`~`--chart-5` 를 쓴다

### 스타일
- Federal Register 페이지(`src/app/federal-register/page.tsx`)를 따라간다: `<main className="flex flex-1 flex-col px-6 py-6">`, 제목 `text-[28px] font-bold text-ink`, 표는 `w-full border-collapse text-left text-sm`, thead `border-b border-hairline text-ink-muted`, 셀 `px-3 py-3`
- 타일은 4열 그리드(`grid grid-cols-2 md:grid-cols-4 gap-4`), 테두리 `border border-hairline rounded-xl p-4`, 숫자 크게·라벨은 `text-ink-muted text-sm`

- 표 열: Subpart / 설명 / 시설 수 / 제조업 / 위반 시설 % / 벌금 건수 / 벌금 중앙값 / deviation %
