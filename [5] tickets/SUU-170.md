## Codex 메모

### `globals.css`
- 현재 파일: `@import "tailwindcss"` + `:root {--background, --foreground}` + `@theme inline` + dark media query + `body`. 전부 갈아엎어도 된다(다른 파일이 `--background`/`--foreground`를 쓰는지 `grep`으로 확인 후).
- `DESIGN.md`의 `colors:` 17개(`primary`, `on-primary`, `accent-blue`, `ink`, `ink-muted`, `canvas`, `surface-1`, `surface-2`, `hairline`, `hairline-soft`, `inverse-canvas`, `inverse-ink`, `gradient-magenta`, `gradient-violet`, `gradient-orange`, `gradient-coral`, `semantic-success`)와 `rounded:` 8개(`xs 4px`, `sm 6px`, `md 10px`, `lg 15px`, `xl 20px`, `xxl 30px`, `pill 100px`, `full 9999px`)를 그대로 옮긴다. 이름은 `--color-<이름>`, `--radius-<이름>`.
- 테스트는 `--color-canvas: #090909;` 처럼 `이름: 값;` 정규식으로 찾고, `@theme` 블록(첫 번째 `{ }`)에 `--color-canvas`, `--radius-pill` 문자열이 있는지 본다. 가장 단순한 형태는 **`@theme { ... }` 안에 변수를 직접 선언**하는 것 — Tailwind v4는 `@theme` 변수를 `:root`에도 내보내므로 두 번 쓸 필요 없다. 예:
```css
@import "tailwindcss";

@theme {
  --color-canvas: #090909;
  --color-accent-blue: #0099ff;
  --color-surface-1: #141414;
  ...
  --radius-pill: 100px;
  ...
  --font-sans: var(--font-inter);
}

body {
  background: var(--color-canvas);
  color: var(--color-ink);
  font-family: var(--font-sans);
}
```
- `@theme` 안에 `--font-geist-sans`, `--font-geist-mono`가 남아 있으면 실패한다. dark media query는 지운다(항상 다크 캔버스).
- 색 값은 소문자 hex 그대로(`#0099ff`). 테스트는 문자열 비교다.

### `layout.tsx`
- `import { Geist, Geist_Mono } from "next/font/google"` → `import { Inter } from "next/font/google"`. `const inter = Inter({ variable: "--font-inter", subsets: ["latin"] })`, `<html className={\`${inter.variable} h-full antialiased\`}>`.
- 파일 안에 `Geist` 글자가 하나라도 남으면 실패(변수 이름 `geistSans` 포함).
- body 배경/글자색은 globals.css `body`에서 처리하므로 layout에는 className 안 붙여도 된다.
