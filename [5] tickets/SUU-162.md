# SUU-162 chore(ci): [4] frontend를 만들고 vitest가 CI에서 돈다

## 목표
`[4]frontend/`에 Next.js(App Router, TS, Tailwind) 뼈대 + vitest. PR마다 CI `frontend` job이 `npm ci && npm test`. 화면은 create-next-app 기본 그대로. $0.

## 건드릴 파일
- 만듦: `[4]frontend/` — `create-next-app` 결과 + `vitest.config.ts` + `package-lock.json` (폴더 이름에 공백 없음: SUU-143 교훈, Vercel Root Directory 공백 불가)
- 고침: `.github/workflows/ci.yml` — `frontend` job 추가(`rules`·`tests` job은 그대로)
- 고침: `[1] docs/4) workflow/2_rules.md` 8번 — 한 줄 추가: "프론트는 **vitest**. 위치 `[4]frontend/tests/*.test.tsx`, 실행 `[4]frontend`에서 `npm test`. Codex는 여기도 수정하지 않는다"
- 테스트(이미 있음, 수정 금지): `[4]frontend/tests/test_frontend_scaffold.py`(pytest 4개), `[4]frontend/tests/smoke.test.tsx`(vitest 1개)

## 안 하는 것
- 화면·테마·백엔드 호출(SUU-163), Vercel(SUU-165), `npm run build` 단계(163에서 화면 생기면)
- `[4] frontend/**` 바뀔 때만 돌리기 — 티켓엔 있지만 안 한다. job 단위 경로 필터는 외부 액션(dorny/paths-filter)이 필요하고, 나중에 필수 체크로 걸면 "건너뜀"이 merge를 막는다. 항상 돈다(npm 캐시로 1분 안)

## Codex 메모

### 만들기
```
cd "[4]frontend"   # .gitkeep 있음. create-next-app은 빈 폴더가 아니면 거부하니 .gitkeep을 잠깐 빼고 만든 뒤 지운다(대신 생긴 파일들이 있으니 .gitkeep은 안 되돌려도 됨)
npx create-next-app@latest . --ts --tailwind --app --src-dir --eslint --no-import-alias --use-npm
npm i -D vitest @vitejs/plugin-react jsdom @testing-library/react @testing-library/dom
```
- `tests/` 폴더는 이미 있다(내 테스트 2개). create-next-app이 `tests/`가 있다고 거부하면 폴더를 잠깐 옮겼다가 되돌린다. **내용은 손대지 않는다**
- `package.json` scripts: `"test": "vitest run"` (정확히 이 문자열)
- Node 로컬 24, CI 22. 둘 다 되는 버전이면 된다

### `vitest.config.ts`
```ts
import react from "@vitejs/plugin-react";
import { defineConfig } from "vitest/config";

export default defineConfig({
  plugins: [react()],
  test: { environment: "jsdom", include: ["tests/**/*.test.tsx"] },
});
```
- `smoke.test.tsx`는 `../src/app/page`를 import → `src/app/page.tsx`의 default export가 `<main>`을 렌더해야 한다. create-next-app 기본 page.tsx가 `<main>`을 쓰면 그대로, 아니면 `<main>` 하나로 감싼다(화면은 안 만든다)
- `tsconfig.json`의 `include`에 `tests/**/*.tsx`가 안 들어가면 IDE만 빨갛고 vitest는 돈다. `"tests/**/*.tsx"` 추가해도 됨
- jsdom에서 `import.meta.url`은 `http:` (SUU-144 메모). 이번엔 안 씀

### `ci.yml` `frontend` job (SUU-140 때 것과 같음, build 제외)
```yaml
  frontend:
    name: 프론트 (vitest)
    runs-on: ubuntu-latest
    timeout-minutes: 10
    defaults:
      run:
        working-directory: "[4]frontend"
    steps:
      - uses: actions/checkout@v6
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
          cache-dependency-path: "[[]4]frontend/package-lock.json"
      - run: npm ci
      - run: npm test
```
- `cache-dependency-path`는 glob이라 `[4]`를 `[[]4]`로 이스케이프. `working-directory`는 glob 아님
- pytest 쪽 `test_ci_frontend_job_*`는 `^  frontend:\n` 뒤 4칸 들여쓴 줄들을 body로 잡는다. 위 모양 그대로면 통과
