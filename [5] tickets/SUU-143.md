# SUU-143 chore(frontend): 폴더를 [4]frontend로 바꿔 Vercel 배포를 고친다

## 목표
프론트 폴더 이름의 공백을 없애 Vercel 프로덕션 배포가 성공하게 한다.

## 왜
SUU-141 merge 후 첫 배포가 `invalid_function_name`으로 실패. Vercel은 서버 함수 이름을 Root Directory로 만드는데 공백이 있으면 안 된다.

## 건드린 파일
- `git mv "[4] frontend" "[4]frontend"`
- `.github/workflows/ci.yml` — `working-directory`, `cache-dependency-path`
- `[4]frontend/tests/test_frontend_scaffold.py` — 경로 상수·검사 문자열
- `[1] docs/4) workflow/1_workflow.md` — 7번 표 6행에 Vercel 연결 상태
- Vercel 프로젝트 설정 Root Directory → `[4]frontend` (API, 코드 아님)

## 안 하는 것
- 다른 폴더 이름, 코드 내용, 폰트(SUU-142에서)

## 완료 기준 ↔ 테스트
| 완료 기준 | 확인 |
|---|---|
| `[4]frontend/package.json` 있음, ci.yml이 `[4]frontend` | `test_frontend_scaffold.py` (경로 바뀐 채로 통과) |
| Vercel 프로덕션 배포 READY | merge 후 `vercel api /v6/deployments` |
