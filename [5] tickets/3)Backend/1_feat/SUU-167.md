# SUU-167 feat(backend): 포트를 먼저 열고 색인은 뒤에서 올린다

## 목표
서버가 켜지자마자 포트가 열리고(Render 포트 검사 통과), 색인은 스레드가 뒤에서 올린다. 준비 전엔 `/health`·`/ask`가 503. API 호출 없음, $0.

## 건드릴 파일
- 고침: `[3] backend/app/main.py` — `lifespan`, `/health`, `/ask` 앞부분
- 테스트(이미 있음, 수정 금지): `[3] backend/tests/test_ready.py`. `test_main.py`·`test_log.py`도 그대로 초록이어야 한다

## 안 하는 것
- 색인 내용·검색 로직(`index.py`·`answer.py`·`log.py`). `render.yaml`
- 재시도·타임아웃·로딩 진행률. 색인이 실패하면 스레드가 죽고 `/health`는 계속 503 → Render 로그로 본다

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| `STATE["index"]`가 None이면 `/health` 503 `{"ready": false}`, `/ask` 503, `answer_question` 안 부름 | `test_not_ready_gives_503_on_health_and_ask` |
| lifespan이 바로 yield 해서 색인이 느려도 요청을 받는다. 색인이 끝나면 `/health` 200 `{"release_id"}`, `STATE["client"]`도 찬다 | `test_lifespan_opens_port_before_index_is_loaded` |

## Codex 메모

### `lifespan`
```python
def _load():
    from supabase import create_client
    client = create_client(os.environ["SUPABASE_URL"], os.environ["SUPABASE_SECRET_KEY"])
    release_id = client.table("common_dataset_current").select("release_id").eq("dataset", "ecfr").execute().data[0]["release_id"]
    STATE["client"] = client
    STATE["index"] = load_index(client, release_id)  # 마지막에 넣는다. index가 차면 "준비됨"

@asynccontextmanager
async def lifespan(app):
    threading.Thread(target=_load, daemon=True).start()
    yield
```
- `create_client`는 `_load` 안에서 `from supabase import create_client`로 부른다(지금과 같음). 테스트는 `supabase.create_client`를 monkeypatch 한다 → 모듈 위로 올리면 패치가 안 먹는다
- 테스트는 `main.load_index`를 바꿔치기한다 → `from app.index import load_index`(이미 그렇다) 그대로 두고 `load_index(...)`로 부른다
- `STATE["index"]`는 **맨 마지막**에 넣는다. `/ask`가 `STATE["client"]`를 쓰므로 client를 먼저

### 핸들러
- `/health`: `if STATE["index"] is None: return JSONResponse({"ready": False}, status_code=503)`. 준비되면 지금처럼 `{"release_id"}`
- `/ask`: 공백 검사 **앞**에 `if STATE["index"] is None: raise HTTPException(503, "index not ready")`. `test_main.py`의 `test_blank_question_is_400`은 index가 있으니 400 그대로
- `from fastapi.responses import JSONResponse`, `import threading` 추가
