## Codex 메모

### 테스트가 기대하는 모양
- 테스트는 `monkeypatch.setenv("FRONTEND_ORIGIN", ...)` 뒤 `importlib.reload(app.main)` 한다 → `ORIGINS`는 **모듈 import 시점**에 `os.environ`에서 읽는다. `[o.strip() for o in os.environ.get("FRONTEND_ORIGIN", "http://localhost:3000").split(",") if o.strip()]`
- `STATE: dict = {"index": None}` 모듈 전역. 테스트는 lifespan을 안 돌리고 `STATE["index"]`를 직접 넣는다(`TestClient(app)`를 `with` 없이 쓰면 startup이 안 돈다). 핸들러는 `STATE["index"]`만 본다
- 테스트는 `app.main.answer_question`을 바꿔치기한다 → `from app.answer import answer_question`으로 **이름을 모듈에 들여오고** 핸들러에서 `answer_question(...)`으로 부른다(`answer.answer_question` 같은 속성 접근이면 패치가 안 먹는다)
- `/ask` 몸통: pydantic `class Ask(BaseModel): question: str`. `if not body.question.strip(): raise HTTPException(400, "question is empty")`. 응답은 `answer_question` 반환 dict 그대로(`return result`)

### `lifespan` (실제 서버에서만 돈다)
```python
@asynccontextmanager
async def lifespan(app):
    from supabase import create_client
    client = create_client(os.environ["SUPABASE_URL"], os.environ["SUPABASE_SECRET_KEY"])
    release_id = client.table("common_dataset_current").select("release_id").eq("dataset", "ecfr").execute().data[0]["release_id"]
    STATE["index"] = load_index(client, release_id)
    yield
```
- release_id 조회는 `[6] rag/eval/run_answer.py:62`와 같은 한 줄

### 실제 API 연결 (`/ask` 안에서)
- `embed=call_kanon2_api` (`ecfr_chunk_index`) — `request -> list[float]`
- `rerank=lambda q, chunks: call_isaacus_rerank_api(build_rerank_request(q, chunks))["scores"]` (`ecfr_chunk_index`, `ecfr_search`)
- `llm=call_openai_rerank_api` (`ecfr_llm_rerank`, 기본 gpt-5-mini) — `prompt -> {"text", "prompt_tokens", "completion_tokens"}`
- `chat=call_openai_chat` (`ecfr_answer`) — 같은 반환 모양
- `[6] rag/eval/run_eval.py:181`·`run_answer.py:144`의 연결과 같다. 환경변수 `ISAACUS_API_KEY`, `OPENAI_API_KEY`

### CORS
- `app.add_middleware(CORSMiddleware, allow_origins=ORIGINS, allow_methods=["*"], allow_headers=["*"])`. 목록 밖 Origin의 preflight는 Starlette가 400으로 막고 헤더를 안 붙인다 — 테스트 마지막 줄이 그걸 본다
