## Codex 메모

### 인자 모양 (전부 이미 있는 호출 함수와 같은 모양)
- `embed(request) -> list[float]` — `ecfr_search.search_sections`가 부르는 그대로
- `rerank(question, chunks) -> list[float]` — 같음
- `llm(prompt) -> {"text", "prompt_tokens", "completion_tokens"}` — `ecfr_llm_rerank.call_openai_rerank_api`와 같은 반환. `search_sections`의 `llm`은 `str`을 받으니 안에서 `lambda p: _count(llm(p))["text"]`처럼 감싸 토큰을 더한다
- `chat(request) -> {"text", "prompt_tokens", "completion_tokens"}` — `ecfr_answer.call_openai_chat`과 같은 반환
- 실제 연결(SUU-158 main.py)은 `call_isaacus_rerank_api`·`call_openai_rerank_api`·`call_openai_chat`을 그대로 넣으면 된다

### `answer.py`
```python
TOP_N = 10                         # SUU-152·154 기준 조합
CHUNK_TOP_K = 150                  # run_eval.py: 리랭크 쓸 때 150
PRICE_PER_M = {"gpt-5-mini": (0.25, 2.00)}  # [6] rag/eval/llm_rerank.py 베낌(eval은 pythonpath에 없다)
```
- 검색: `search_sections(question, embed=embed, chunks=index.chunks, keyword=index.keyword, rerank=rerank, top_k=TOP_N, chunk_top_k=CHUNK_TOP_K, rules=True, llm=<감싼 llm>)`. `[6] rag/eval/run_eval.py:203`과 같은 호출. 결과 각 항목에 `section_key`, `chunk_key`, `subpart`, `score`가 있다
- `sections` 반환값은 `[{"section_key", "subpart"}]`만 (score·chunk_key 뺀다)
- 조문 전문 `section_text(index, section) -> str`: 티켓엔 `run_answer.fetch_texts`라 썼지만 그건 Supabase를 다시 간다. **색인에 이미 청크 전문이 있으니 메모리에서 만든다.** `prefix = section["chunk_key"].rsplit("/", 1)[0] + "/"`, `index.chunks` 중 `chunk_key.startswith(prefix)`인 것을 `[6] rag/eval/run_answer.py:43`의 `_piece_order`(본문 /0, /0-1… 먼저, 표 /1, /2… 뒤) 순서로 `chunk_text`를 `"\n\n"`으로 이어 붙인다. `_piece_order`·`join_section_text`는 베낀다(import 불가)
- 답: `request = build_answer_request(question, [{**s, "text": section_text(index, s)} for s in sections])` → `chat(request)` → `parse_answer(text, [s["section_key"] for s in sections])`. `ValueError`면 `answer=None, issues=[f"parse error: {e}"]` (`run_answer.py:161`과 같음)
- `tokens = {"prompt": 리랭크+답 prompt 합, "completion": 합}`, `cost_usd = prompt/1e6*0.25 + completion/1e6*2.00`, `ms = int((perf_counter()-t0)*1000)`
- 반환: `{"answer", "sections", "issues", "tokens", "cost_usd", "ms"}` 여섯 키만
