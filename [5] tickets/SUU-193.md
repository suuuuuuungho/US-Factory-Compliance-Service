# SUU-193 feat(frontend): 세 칸을 VSCode처럼 끌어서 크기·위치를 바꾼다

## 목표
답이 나오면 Subparts·Checklist·조문 세 칸을 dockview 패널로 보여준다. 경계선을 끌어 크기를 바꾸고, 탭을 끌어 다른 자리에 붙이거나 겹칠 수 있다. 배치는 localStorage에 남고 "Reset layout"으로 기본 3열로 돌아온다.

## 건드릴 파일
- `[4]frontend/src/app/Workspace.tsx` (새 파일) — `DockviewReact` + 패널 3개(`subparts`, `checklist`, `section`). 내용은 React context로 전달. `onDidLayoutChange` → `localStorage["workspace-layout"]` 저장, `onReady`에서 복원. Reset 버튼은 `api.clear()` 후 기본 3열
- `[4]frontend/src/app/page.tsx` — 고정 3열 grid → `<Workspace panels={{...}}>`. 카드 className(CARD/CARD_TITLE/CARD_LIST)은 그대로
- `[4]frontend/src/app/globals.css` — `.dockview-theme-dark` CSS 변수를 DESIGN 토큰으로 덮어씀
- `[4]frontend/package.json` — `dockview`, `dockview-react`
- `[4]frontend/tests/setup.ts`, `vitest.config.ts` — jsdom에 없는 `ResizeObserver` 가짜

## 안 하는 것
- 백엔드, 카드 내용·색 변경
- 배치를 서버에 저장하거나 사용자 간 공유
- 모바일(<md) 전용 배치 (높이 70vh로만 둔다)

## 완료 기준 ↔ 테스트 (`tests/workspace.test.tsx`)
| 완료 기준 | 테스트 함수 |
|---|---|
| 답이 오면 draggable 탭 3개(Subparts·Checklist·Section text)가 있다 | `답이 오면 dockview 안에 끌 수 있는 탭 세 개(...)가 있다` |
| 각 내용이 맞는 칸(region)에 있다 | `Subpart 카드는 Subparts 칸에, Checklist는 Checklist 칸에 있다`, `Section text 칸은 인용 클릭 전엔 안내 문구, 클릭 후엔 조문 패널이다` |
| 칸을 닫으면 localStorage에 저장되어 다시 열어도 닫혀 있다 | `칸 배치는 localStorage 'workspace-layout'에 저장되고, 닫은 칸은 다시 열어도 닫혀 있다` |
| Reset layout → 기본 3열 | `Reset layout을 누르면 닫았던 칸이 돌아오고 기본 3열이 된다` |

## 메모
- SUU-182의 `three_columns.test.tsx`(고정 grid 검사)는 이 티켓이 대체하므로 삭제. `single_subpart_card`·`card_title_band`는 탭 글자와 h2 글자가 겹쳐 `getByRole("heading")`으로 2줄 수정
- dockview 그룹이 이미 `role="region" aria-label=제목`을 붙이므로 page.tsx의 `<section aria-label>` 겉상자는 뺐다
- 구현·테스트를 이 티켓과 같은 세션(Claude)에서 끝냈다. Codex 단계 없음
