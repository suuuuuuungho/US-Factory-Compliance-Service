# SUU-193 feat(frontend): 세 칸을 VSCode처럼 끌어서 크기·위치를 바꾼다

## 목표
답이 나오면 2행이 dockview 작업공간이 된다. 기본 칸은 **Subparts | Checklist**. 인용을 클릭하면 그 조문이 **칸 하나(탭 `§63.4481`)로 열리고**, 다른 인용은 또 다른 칸으로 열려 조문 여러 개를 나란히 볼 수 있다(1x1·1x2·2x1·2x2 등 자유). 경계선을 끌어 크기를, 탭을 끌어 위치를 바꾼다. 배치는 localStorage에 남고 "Reset layout"으로 기본으로 돌아온다.

## 건드릴 파일
- `[4]frontend/src/app/Workspace.tsx` (새 파일) — `DockviewReact`. `panels: {id: {title, node}}`를 받아 내용은 React context로 패널에 전달. 새로 생긴 id(조문)만 칸으로 추가, 조문은 기존 조문 칸에 탭으로. `active`로 칸 포커스, 탭 ✕는 `onClose(id)`. Subparts·Checklist 켜고 끄는 버튼(aria-pressed) + Reset. `onDidLayoutChange` → `localStorage["workspace-layout"]`, `onReady`에서 복원(내용 없는 지난 조문 칸은 뺌)
- `[4]frontend/src/app/applicability/page.tsx` — 고정 3열 grid → `<Workspace>`. 조문 상태를 `opened: Record<section_key, {section, error, paragraph}>`로 바꿔 인용마다 칸 하나. SUU-189의 문단 보기/Show all은 칸마다 따로. 카드 className(CARD/CARD_TITLE/CARD_LIST)은 그대로
- `[4]frontend/src/app/globals.css` — `.dockview-theme-dark` CSS 변수를 DESIGN 토큰으로 덮어씀
- `[4]frontend/package.json` — `dockview`, `dockview-react`
- `[4]frontend/tests/setup.ts`, `vitest.config.ts` — jsdom에 없는 `ResizeObserver` 가짜

## 안 하는 것
- 백엔드, 카드 내용·색 변경
- 배치를 서버에 저장하거나 사용자 간 공유
- 모바일(<md) 전용 배치 (높이 70vh로만 둔다)

## 완료 기준 ↔ 테스트 (`tests/workspace.test.tsx`)
| 완료 기준 | 테스트 함수 |

| 각 내용이 맞는 칸(region)에 있다 | `Subpart 카드는 Subparts 칸에, Checklist는 Checklist 칸에 있다` |

| 조문 칸을 닫으면 사라지고 다시 클릭하면 다시 열린다 | `조문 칸을 ✕로 닫으면 사라지고, 인용을 다시 클릭하면 다시 열린다` |

| 닫은 칸은 localStorage에 저장되어 다시 열어도 닫혀 있다 | `칸 배치는 localStorage 'workspace-layout'에 저장되고, ...` |
| Reset layout → 기본(Subparts \| Checklist) | `Reset layout을 누르면 닫았던 칸이 돌아오고 기본(...)이 된다` |

## 메모
- SUU-182의 `three_columns.test.tsx`(고정 grid 검사)는 이 티켓이 대체하므로 삭제. `equal_card_height`(SUU-188)의 "칸은 overflow-hidden" 검사는 Workspace의 Panel(`div[data-panel]`)을 보도록, `single_subpart_card`·`card_title_band`는 탭 글자와 h2 글자가 겹쳐 `getByRole("heading")`으로 수정
- dockview 그룹이 이미 `role="region" aria-label=제목`을 붙이므로 page의 `<section aria-label>` 겉상자는 뺐다
- 둘째 조문은 첫 조문 칸에 **탭**으로 들어간다. 나란히 보려면 탭을 끌어 옆으로 뺀다
- 구현·테스트를 이 티켓과 같은 세션(Claude)에서 끝냈다. Codex 단계 없음
