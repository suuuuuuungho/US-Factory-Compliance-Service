# SUU-164 feat(frontend): 인용을 누르면 근거 조문 본문이 열린다

## 목표
기준 옆 인용 `40 CFR 63.4481(a)(1)`이 버튼. 누르면 `GET {NEXT_PUBLIC_API_URL}/section/section-63.4481` → 옆 패널(`<aside>`)에 조문 전문. 같은 조문은 다시 안 부른다. $0.

## 건드릴 파일
- 고침: `[4]frontend/src/lib/api.ts` — `citationToSectionKey(citation) -> string | null`, `getSection(key) -> Promise<Section>` + `Section` 타입
- 고침: `[4]frontend/src/app/page.tsx` — 인용을 `<button>`으로, `<aside>` 패널, 조문 캐시
- 테스트(이미 있음, 수정 금지): `[4]frontend/tests/section.test.tsx`(4개). `page.test.tsx`(5)·`smoke.test.tsx`(1)는 그대로 초록이어야 함

## 안 하는 것
- 문단 `(a)(1)` 위치로 스크롤·하이라이트, 패널 닫기 버튼, 디자인
- 백엔드·CI. 새 npm 패키지 없음

## Codex 메모

### `api.ts`
```ts
export type Section = { section_key: string; subpart: string; text: string };

/** "40 CFR 63.4481(a)(1)" → "section-63.4481". 63.숫자 가 없으면 null (표 인용 등). 색인의 section_key는 전부 section-63.<숫자> 꼴 */
export function citationToSectionKey(citation: string): string | null {
  const m = citation.match(/63\.(\d+)/);
  return m ? `section-63.${m[1]}` : null;
}

export async function getSection(key: string): Promise<Section> {
  const base = process.env.NEXT_PUBLIC_API_URL ?? "http://localhost:8000";  // ask()와 같이 호출 시점에 읽는다
  const r = await fetch(`${base}/section/${key}`);
  if (!r.ok) throw new Error(`Section not found (${r.status})`);
  return r.json();
}
```
- 테스트의 가짜 fetch는 `init?.method ?? "GET"`으로 기록 → `fetch(url)` 한 인자로 불러도 되고 `{ method: "GET" }`을 줘도 된다

### `page.tsx`
- state 추가: `section: Section | null`, `sectionError: string | null`, 캐시 `useRef<Record<string, Section>>({})`(또는 `useState`의 Map). 캐시에 있으면 fetch 안 하고 바로 `setSection`
- 인용 렌더: 지금 `<span>{cr.citations.join(", ")}</span>` → 인용마다 `<button type="button" onClick={() => open(c)}>{c}</button>`. `citationToSectionKey`가 null이면 `<span>`으로 그냥 글자
  - **주의**: `page.test.tsx`가 `getByText(/The plant coats plastic parts\./)`로 `<li>`를 찾는다. Testing Library `getByText`는 요소의 **직접 텍스트 노드**만 본다 → 기준 문장은 `<li>` 바로 안의 텍스트, 인용은 그 안의 `<button>`. 기준 문장을 `<span>`으로 한 번 더 감싸도 되지만 인용 글자가 `<li>`의 직접 텍스트로 새면 안 된다
  - 버튼 이름 = 인용 문자열 그대로(`getByRole("button", { name: "40 CFR 63.4481(a)(1)" })`)
- 패널: `section || sectionError`일 때만 `<aside aria-label="Section text">` 렌더(누르기 전엔 없어야 함 — `queryByRole("complementary")` null). 안에 `<h2>{section.section_key} (Subpart {section.subpart})</h2>` + `<pre className="whitespace-pre-wrap">{section.text}</pre>`. 에러면 `<p>{sectionError}</p>`
  - `<aside>`는 `role=complementary`. `<main>` 안에 두면 안 된다(암묵 role이 사라짐) → `<main>`과 형제로, 바깥을 `<div className="flex">`로 감싼다. smoke·page 테스트는 `<main>`만 본다
  - 본문의 `\n\n`은 `whitespace-pre-wrap`으로 그대로. 테스트는 `/\(a\) first piece/`, `/\(b\) second piece/`를 패널 안에서 찾는다
- 새 인용 누르면 이전 `sectionError` 지우고, 실패하면 `section`을 null로
