## Codex 메모

### 지금 코드 (`ecfr_answer.py`)
- `ANSWER_SYSTEM`: criteria 프롬프트. **한 글자도 바꾸지 않는다.** `test_ecfr_answer.py`가 "code only"·"every subpart"·"verdict" 문구를 본다.
- `build_answer_request(question, sections, *, model)`: user 메시지는 `QUESTION:` + `SECTIONS (n):` + 조문 전문. 이 부분은 두 모양이 같이 쓴다. `shape`에 따라 system 메시지만 바꾼다. `shape not in {"criteria", "gates"}` → `ValueError`.
- `parse_answer(text, given_section_keys)`: 펜스 제거 → JSON → `_keep`으로 모르는 키 떼며 issue → 후보마다 subpart 코드 정규화(`normalize_subpart`, `_SUBPART_CODE_RE`) → criteria 검증 → 인용마다 `citation_section_key`로 넘겨준 조문 안인지 표시. 공통 부분(펜스·JSON·subpart)은 재사용하고 `shape == "gates"`일 때 후보 안쪽 검증만 갈라지면 된다.

### 관문 모양 (계획 문서 [4]-3, 채점기 v2가 읽는 모양)
```
{"candidates": [{"subpart": "PPPP", "title": "...",
                 "gates": [{"type": "affected_source", "question": "...", "test": "...",
                            "citations": ["40 CFR 63.4581"], "quote": "20~40단어 원문 발췌"}],
                 "missing": ["..."]}],
 "checklist": [{"item": "...", "gate": "affected_source"}]}
```
- 허용 키: 최상위 `candidates, checklist` / 후보 `subpart, title, gates, missing` / 관문 `type, question, test, citations, quote` / 체크리스트 항목 `item, gate`. 그 밖의 키는 `_keep`처럼 떼고 `unknown field: ...` issue. 테스트는 issue 문장에 `applies`·`verdict`·`conclusion`이 들어 있는지만 본다.
- 관문 필수: `type question test quote`는 비어 있지 않은 문자열, `citations`는 비어 있지 않은 리스트. 하나라도 빠지면 그 관문만 버리고 issue(예: `candidates[0].gates[1]: missing 'quote'`). 버린 뒤 관문이 0개면 `ValueError`(criteria가 비었을 때와 같음).
- `type` 값은 여섯 가지 중 하나여야 한다고 프롬프트에 적지만, **파서는 값을 검사하지 않는다**(어떤 문자열이든 통과). 채점기도 그렇다.
- `missing`: 없으면 `[]`. 있으면 문자열 리스트 그대로.
- `checklist`: 비어 있지 않은 리스트, 항목마다 `item`·`gate` 문자열. 아니면 `ValueError`. `gate`가 실제 관문 type과 맞는지는 채점기 G4가 본다. 파서는 안 본다.
- 인용: criteria와 똑같이 `citation_section_key`로 확인. 넘겨준 조문 밖이면 issue만, 값은 그대로.

### `ANSWER_SYSTEM_GATES` 프롬프트에 꼭 들어갈 것
- 위 JSON 스키마 한 줄.
- `type`은 `source_category · affected_source · major_or_area · threshold · exemption · compliance_date` 중 하나, 이 순서가 적용 판단 순서(업종 → 설비 → major/area → 문턱값 → 예외 → 시점).
- `question`: 공장이 답할 수 있는 한 문장 질문. `test`: 예이면 어느 쪽, 아니오이면 어느 쪽.
- `quote`: 인용 조문에서 **그대로 복사한** 20~40 단어. 바꿔 쓰지 말 것. 원문에 없는 발췌는 관문을 아예 넣지 말 것.
- `citations`: 넘겨준 조문만, 문단까지(`40 CFR 63.4490(a)`).
- `missing`: 판단에 필요한데 넘겨준 조문에 없는 것. 없으면 빈 리스트.
- `checklist[].gate`는 그 항목이 어느 관문 type을 위한 것인지.
- 판정(`applies`/`verdict`/`conclusion`) 금지. subpart는 코드만("PPPP"), 넘겨준 조문에 나온 subpart만, 1~4개.
- JSON만 출력.
