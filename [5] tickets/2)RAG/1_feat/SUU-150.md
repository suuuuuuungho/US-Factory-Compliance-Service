## Codex 메모

### `ANSWER_SYSTEM`
Rules 목록의 `candidates:` 줄을 이렇게 바꾼다(정확한 문구는 자유, `code only`·`every subpart` 소문자 포함 필수):
- `candidates: list EVERY subpart that could apply to this plant, including the general provisions Subpart A when its sections were given (1 to 4). Only subparts that appear in the given sections.`
- `subpart: the subpart code only ("A", "M", "PPPP"). Never "Subpart M", never a section number like "40 CFR 63.460".`
- `1 to 3` → `1 to 4`로 늘린다(ZZZZ+PPPPP+A 같은 경우).

### `parse_answer`
- `from ecfr_answer_score import normalize_subpart` (같은 폴더, sys.path에 이미 있음).
- `subpart` 문자열 검사 뒤: `code = normalize_subpart(cand["subpart"])`. `re.fullmatch(r"[A-Z]{1,7}", code)`면 `cand["subpart"] = code`; 아니면 원문 유지 + `issues.append(f"candidates[{ci}].subpart is not a code: {cand['subpart']}")`.
- 순환 import 주의: `ecfr_answer_score`는 `ecfr_answer`를 import하지 않는다. 괜찮다.

### 실행
- 레포 루트에서 `python -m pytest --ignore=tmp` 초록 확인 후 `python "[6] rag/eval/run_answer.py" --run-id 2026-09-19_answer_v2_gpt-5-mini_prompt2` (`PYTHONIOENCODING=utf-8`, 8 workers, ~5분, ~$1.5). 빈 답이 있으면 `--retry-empty`.
- 점수판 비교는 SUU-149 정규화 후 baseline(0.912 / 0.685 / 1.000 / 1.667 / 실패 10)과.
- `answer_runs.jsonl` 새 줄 `notes`: "SUU-150 프롬프트 v2(subpart 코드만·복수 정답 다 적기)". 두 줄이 된다(baseline + prompt2). 이후 여러 실험이 쌓인다.
- 실패 표에서 `format`이 남으면 프롬프트가 안 먹은 것 → 어떤 표기였는지 문서에 적는다.

### 왜 이 순서인가
SUU-149 실패 10건 중 `format` 2 + `answer`(복수 정답 중 하나만) 3 = 5건이 이 프롬프트 한 줄로 잡힐 후보. `search` 3건은 A-5 ②(조문 수) 몫.
