# SUU-191 feat(frontend): 첫 화면을 히어로 랜딩 페이지로 만든다

## 목표
`/`에 들어가면 gradient 배경 히어로(제목·부제·Start 버튼)가 화면을 채우고, Start를 누르면 `/applicability`로 간다. 실제 이미지는 나중에 교체.

## 건드릴 파일
- `[4]frontend/src/app/page.tsx` — `<main>` 안에 `<section aria-label="Hero" className="bg-gradient-violet ...">`. 높이 `min-h-[calc(100dvh-60px)]`, 가운데 정렬. 안에 h1(기존 className 유지 + 글자 그대로), 설명문 p(text-accent-blue, 글자 그대로), `next/link` `<Link href="/applicability">Start</Link>` (rounded-full bg-primary text-on-primary 버튼 모양)

## 안 하는 것
- 이미지 파일 추가, TopNav·다른 페이지·globals.css 변경
- `tests/` 수정 금지

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |

| / 의 h1 = US Factory Compliance AI Service | `hero_landing.test.tsx` — `/ 의 h1이 US Factory Compliance AI Service 다` |
| Start 링크 href = /applicability | `hero_landing.test.tsx` — `Start 링크의 href가 /applicability 다` |
| region "Hero"에 bg-gradient-violet | `hero_landing.test.tsx` — `히어로 섹션(region=Hero)에 gradient 배경 클래스가 있다` |
| 기존 h1·설명문 검사 유지 | `topnav_hero.test.tsx`, `smoke.test.tsx` (기존) |

## Codex 메모
- `bg-gradient-violet`는 globals.css `--color-gradient-violet`에서 Tailwind가 만드는 유틸리티. 이미 카드 제목 띠에 쓰고 있다.
- h1은 `whitespace-nowrap`·`text-ink`·`text-accent-blue` 없음 조건을 topnav_hero 테스트가 본다. 기존 className 그대로 두면 된다.
- main의 p-8 패딩은 빼고 section이 꽉 차게 한다 (히어로는 가장자리까지).
