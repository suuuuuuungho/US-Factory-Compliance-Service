# SUU-259 feat(frontend): Decision Letter 표 Facility 좁히고 Title 넓힘

## 목표
`/decision-letter` 표에서 Facility 열은 최대 너비를 두고 `...` 으로 자르고, Title 열이 남는 폭을 다 쓰게 한다.

## 건드릴 파일
- 고칠 것 `[4]frontend/src/app/decision-letter/page.tsx` — Facility `<td>` 하나만
- 이미 있음 `[4]frontend/tests/decision_letter_col_width.test.tsx` — 테스트 2개

## 안 하는 것
- 열 너비 드래그 조절 (SUU-260)
- `federal-register/page.tsx`, 다른 열(#, Subpart, Date, PDF) 수정
- `tests/` 아래 수정·삭제

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| Facility `<td>` 에 `max-w-[Npx]` 가 있고 `whitespace-nowrap` 은 없다. 글자는 `truncate` 된 요소에 들어있고 그 요소의 `title` 속성이 전체 이름 | `Facility 셀은 최대 너비가 있고 글자가 truncate 되며 title 속성에 전체 이름이 있다` |
| Title `<td>` 는 지금처럼 `w-full max-w-0`, 글자는 `truncate` + `title` 속성 (기존 동작 유지) | `Title 셀은 남는 폭을 쓰고(w-full max-w-0) 넘치면 truncate 된다` |

## Codex 메모
- 지금 Facility 셀: `<td className="px-3 py-3 whitespace-nowrap">{letter.facility_name ?? "—"}</td>`
- 바꿀 모양 (Title 셀과 같은 패턴):
  ```tsx
  <td className="max-w-[180px] px-3 py-3">
    <span title={letter.facility_name ?? undefined} className="block truncate">
      {letter.facility_name ?? "—"}
    </span>
  </td>
  ```
- `truncate` 는 `overflow-hidden text-ellipsis whitespace-nowrap` 이라 `<td>` 에 `max-w-` 가 있어야 실제로 잘린다. 180px 는 예시. 화면 보고 150~200 사이로 조절해도 된다.
- 테스트는 `getByText(전체 이름)` 으로 글자 요소를 찾고 `.closest("td")` 로 셀을 본다. 글자를 감싸는 요소(span)에 `truncate` 와 `title` 이 있어야 한다.
- 테스트 실행: `cd "[4]frontend" && npx vitest run tests/decision_letter_col_width.test.tsx tests/decision_letter_list.test.tsx`
