# SUU-201 feat(frontend): 에칭 히어로 이미지와 굴뚝 연기 애니메이션

## 목표
`/` 히어로 뒤에 흑백 판화(에칭) 공장 그림을 깔고, 굴뚝 두 곳에서 연기가 위로 올라가게 한다.

## 건드릴 파일
- 만들 것 `[4]frontend/scripts/make_hero_etching.py` — 루트 `Hero Image.png` → `[4]frontend/public/hero-etching.png` (Pillow; 흑백 + 대비 + 에지 강조 + 가로 해칭). 폭 1600px, 500KB 이하
- 만들 것 `[4]frontend/public/hero-etching.png` — 스크립트 결과. 커밋한다
- 만들 것 `[4]frontend/src/app/HeroSmoke.tsx` — props `{ left: string; top: string }`. 루트 `<div data-testid="hero-smoke">` absolute, 안에 `<span className="animate-smoke ...">` 4개 (animation-delay 0/1.5/3/4.5s, 회색 반투명 blur 원 ~40px)
- 고칠 것 `[4]frontend/src/app/page.tsx` — section을 `relative overflow-hidden`으로, `next/image` fill + priority + `alt="Factory etching"` + `src="/hero-etching.png"` object-cover, 그 위 `bg-canvas/60` 레이어, 그 위 기존 h1/p/Start. `<HeroSmoke/>` 2개 (왼쪽 굴뚝 ≈ left 14% / top 18%, 오른쪽 ≈ left 29% / top 16% — 생성된 이미지를 보고 굴뚝 꼭대기에 맞춰 조정)
- 고칠 것 `[4]frontend/src/app/globals.css` — `@keyframes smoke-rise` (translateY 0→-160px, scale 0.6→1.8, opacity .5→0), `.animate-smoke { animation: smoke-rise 7s ease-out infinite }`, `@media (prefers-reduced-motion: reduce) { .animate-smoke { animation: none } }`

## Codex 메모
- 원본 사진: 루트 `Hero Image.png` (1569×880, 컬러). 굴뚝 두 개는 왼쪽 냉각탑 위(x≈14%)와 그 오른쪽 높은 굴뚝(x≈29%), 꼭대기 y≈18%.
- 에칭 알고리즘 예: grayscale → autocontrast → 원본과 `ImageFilter.FIND_EDGES`(반전) 곱하기 → 어두울수록 촘촘한 가로 줄(2~3px 간격, 밝기 기준 임계값) 곱하기. 하늘은 밝게 남긴다. Pillow만으로 충분. 파이썬은 루트 `pyproject.toml` 환경(3.12) 사용.
- next/image는 jsdom에서 `<img>`로 렌더된다. src에 `/hero-etching.png` 문자열이 그대로 들어가므로 테스트 통과. `fill`이면 부모가 `relative` 여야 한다.
- 테스트는 `[4]frontend`에서 `npm test`. 빌드는 `npm run build`.
- 기존 `hero_landing.test.tsx`의 `bg-gradient-violet` 없음 검사는 그대로 지켜야 한다.
