# SUU-149 chore(rag): 답변 실패를 세 가지 원인으로 분류

## 목표
SUU-147 baseline 결과(`results/2026-09-19_answer_v2_gpt-5-mini.jsonl`)의 실패 케이스를 원인별로 나눠 표로 남기고, 다음 실험(A-5)의 순서를 정한다. $0, API 호출 없음.

원인은 넷이다(티켓의 셋 + 형식):
| 태그 | 뜻 | 고칠 곳 |
|---|---|---|
| `fabricated` | 넘겨준 조문 밖 인용(`outside_citations` 있음) | 프롬프트 |
| `search` | 정답 조문이 상위 5(`given`)에 하나도 없음 | 검색·조문 수 |
| `format` | 정답 조문은 줬는데 `subpart` 칸이 코드가 아님(`"40 CFR 63.460"`, `"63.1065"`) | 프롬프트·파싱 |
| `answer` | 정답 조문은 줬는데 Subpart를 잘못 골랐거나 심판 0점 | 프롬프트·모델 |

`"Subpart M"`처럼 코드에 접두어만 붙은 것은 실패가 아니다 → 채점기가 정규화한다(아래).

## Codex 메모

### `ecfr_answer_score.score_subpart`
- `normalize_subpart(label) -> str`: `str(label).strip()`, 앞의 `subpart` 단어(대소문자 무관) 제거, `.strip().upper()`. 그 결과가 `^[A-Z]{1,7}$`이면 그대로, 아니면 원문 그대로 둔다(그래야 `"40 CFR 63.320"`은 계속 미적중).
- `score_subpart`는 후보마다 `normalize_subpart`한 집합에 `gold_subparts[0]`이 있는지 본다. 함수 시그니처는 바꾸지 않는다.

### `answer_failures.py`
- `SUBPART_CODE = re.compile(r"^[A-Z]{1,7}$")`, `TAGS = ("fabricated", "search", "format", "answer")` (이 순서가 우선순위이자 표 순서).
- `classify(out, case) -> str | None`:
  1. 실패 조건 = `out["subpart"] == 0 or out["judge"] == 0 or out["citation_grounded"] < 1`. 아니면 `None`.
  2. `out["outside_citations"]` 비어 있지 않으면 `"fabricated"`.
  3. `gold = {citation_section_key(c) for c in case["gold_citations"]}`; `gold & set(out["given"])`이 비면 `"search"`.
  4. `out["subpart"] == 0`이고 후보 subpart 중 하나라도 `normalize_subpart` 뒤 `SUBPART_CODE`에 안 맞으면 `"format"`. (`answer`가 None이면 후보 없음 → 이 단계 건너뜀)
  5. 나머지 `"answer"`.
- `summarize(outs, classify_fn) -> dict`: `{"n_failed": int, "counts": {tag: int for TAGS}, "cases": {tag: [case_id…]}}`. 태그 없는 케이스는 세지 않는다.
- `main()`: `--run-id 2026-09-19_answer_v2_gpt-5-mini`. results jsonl + `rag_eval_case_v2.jsonl` 읽어 태그 → 표 출력(태그 / 건수 / case_id들) + 케이스별 한 줄(`case_id, tag, gold_subparts, 후보 subpart, gold in given n/m, judge`). 파일에 쓰지 않는다(문서에 사람이 옮김).

### 순서
1. 채점기 정규화 → `python -m pytest --ignore=tmp` 초록.
2. `python "[6] rag/eval/run_answer.py" --replay --run-id 2026-09-19_answer_v2_gpt-5-mini` → 새 점수(Subpart 적중이 오를 것, 나머지 동일). `answer_runs.jsonl`은 append된 새 줄만 남기고 옛 줄을 지운다(한 줄 유지). `notes`에 "SUU-149 subpart 정규화 후 replay" 추가.
3. `python "[6] rag/eval/answer_failures.py"` → 표를 `4_` 문서 5절 아래 "실패 분류"로, 6절 배운 것에 2~3줄, 4절 A-5 순서를 이 표에 맞춰 조정(예: `format`이 많으면 프롬프트 수정이 1순위, `search`가 많으면 조문 수 확대가 1순위).
