# SUU-142 feat(frontend): 랜딩 히어로에 서비스 한 줄 소개와 판화 그림

## 목표
첫 화면(푸터 위)에 서비스 한 줄 소개 + 부제 + CTA 1개 + 큰 판화 그림(hero.png)이 보이고, 스크롤하면 그림이 살짝 느리게 따라온다. 폰트는 제목·본문 모두 Source Serif 4로 통일한다.

## 건드릴 파일
- 만듦: `[4]frontend/src/components/Hero.tsx`
- 고침: `[4]frontend/src/app/page.tsx` — `<main>` 안에 `<Hero />`. `<EngravedFooter />`는 그대로
- 고침: `[4]frontend/src/app/globals.css` — `.parallax` 규칙 추가 (아래). 폰트 줄은 이미 반영됨(이 브랜치에 커밋됨)
- 이미 됨(수정 금지): `layout.tsx` Source Serif 4, `globals.css` `--font-serif`·`--font-sans`
- 테스트(수정 금지): `src/components/Hero.test.tsx`

## 안 하는 것
- 검색/판정 기능, 로그인, 실제 CTA 목적지(`#`), 푸터 변경, 그림 수정, 새 의존성

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 |
|---|---|
| h1에 "규제 조항"과 "판정 기준" 포함 | `Hero > 서비스 한 줄 소개가 h1으로 렌더된다` |
| `hero.png`, alt 있음 (장식 아님 → `alt` 비우지 말 것) | `Hero > hero.png가 alt 텍스트와 함께 렌더된다` |
| `<a href="#">` CTA 1개 이상 | `Hero > CTA 버튼(링크)이 하나 있다` |
| 그림 `data-testid="hero-art"`에 `parallax` 클래스 | `Hero > 그림 요소에 시차(parallax) 클래스가 붙는다` |
| 루트 `<main>` 안에 h1 | `루트 페이지 > main 안에 Hero의 h1이 있다` |
| globals.css serif·sans = Source Serif 4 | `폰트 (Source Serif 4)` (이미 초록) |

## Codex 메모
- 문구 (`[1] docs/1) project/1_project.md` 서비스 정의 기반):
  - h1: `우리 공장에 적용될 규제 조항 후보와 판정 기준을, 근거 조문과 함께`
  - 부제: `미국 제조업 공장의 환경·규제 담당자를 위한 40 CFR Part 63 컴플라이언스 문서 작성 도우미. 답을 대신 정하지 않고, 어디를 봐야 하고 무엇을 확인해야 하는지를 근거와 함께 보여줍니다.`
  - CTA: `<a href="#">조항 후보 찾기</a>` — `bg-ink text-paper` 버튼 모양
- 레이아웃: `max-w-6xl mx-auto px-6 py-24`, 세로로 제목 → 부제 → CTA → 그림. 그림은 `<img src="/engraving/hero.png" alt="판화로 그린 공장 풍경" data-testid="hero-art" className="parallax w-full max-w-4xl mx-auto mt-16">`. `alt`는 비우지 않는다(테스트가 role=img로 찾음). eslint `no-img-element`는 그 줄에 disable 주석
- 시차(parallax)는 CSS만. globals.css에 추가:
  ```css
  /* 스크롤 시차 — 그림이 조금 느리게 따라온다. 지원 안 하는 브라우저는 그냥 정지 */
  @supports (animation-timeline: scroll()) {
    .parallax {
      animation: parallax-drift linear both;
      animation-timeline: scroll();
      animation-range: 0 100vh;
    }
    @keyframes parallax-drift {
      from { transform: translateY(0); }
      to { transform: translateY(-40px); }
    }
  }
  ```
  reduced-motion 블록(`@media (prefers-reduced-motion: reduce)`)에 `.parallax { animation: none; }`도 추가. 기존 블록의 `animation: none` 문자열은 그대로 두어야 EngravedFooter 테스트가 통과
- h1은 `font-serif text-4xl md:text-5xl font-semibold leading-tight`. 폰트 굵기 600은 layout.tsx에서 이미 로드함
- 확인: `npm test`, `npm run build`, `npm run dev` 후 스크롤하며 그림이 살짝 뒤처지는지 눈으로
