# SUU-211 feat(frontend): 랜딩 가운데 제목·카피를 New York 글꼴로

## 목표
랜딩(/) 가운데에 제목 "US Factory Compliance AI Service"(굵게) + 카피 한 줄(보통)을 Apple New York 세리프로. Start 버튼 없음.

## 건드릴 파일
- 만들 것 `[4]frontend/src/app/fonts/NewYork-latin.woff2` — `NY.dmg`의 가변 `NewYork.ttf`에서 fonttools로 wght 400~700, opsz 12~256(브라우저가 크기에 맞춰 자동), 라틴만. 62KB
- 고칠 것 `[4]frontend/src/app/layout.tsx` — `next/font/local` 로 `newYork` 추가, html 에 `${newYork.variable}`
- 고칠 것 `[4]frontend/src/app/globals.css` — `--font-serif: var(--font-new-york)`
- 고칠 것 `[4]frontend/src/app/page.tsx` — `z-30` 묶음: h1 `font-serif font-semibold tracking-tight text-3xl md:text-[44px]`, p `font-serif font-normal text-ink/70 text-base md:text-lg`
- 고칠 것 `[4]frontend/tests/hero_no_flag.test.tsx` — "h1 없음" 검사만 뺌 (옛 설명문·Start 없음은 유지)

## 안 하는 것
- Start 버튼, 상단바, 배경·연기, 다른 페이지, 본문 글꼴(SF Pro 그대로)

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 (`hero_title_new_york.test.tsx`) |
|---|---|
| h1 있음, font-serif·font-semibold | `/ 에 h1 제목이 있고 font-serif·font-semibold 다` |
| 카피 있음, font-serif·font-normal | `/ 에 카피 한 줄이 있고 font-serif·font-normal 다` |
| Start 없음 | `/ 에 Start 링크는 없다` |

## 메모
- 카피: `Know which 40 CFR Part 63 rules apply to your plant — and why.`
- 폰트 만들기는 SUU-204.md 메모와 같은 방법 (dmg → pkg → Payload → cpio, instancer + subset). New York 은 wght 최소가 400이라 300 은 못 만든다
- opsz 축을 남겨 두면 `font-optical-sizing: auto`(기본값)로 44px 제목은 Display, 18px 카피는 Text 컷이 자동으로 쓰인다
