## Codex 메모

### 설치 명령
`[4]frontend`에서:
```
npx shadcn@latest add @bklit/bar-chart @bklit/area-chart
```
- components.json에 레지스트리를 먼저 넣어야 `@bklit/...`가 풀린다
- 레지스트리 JSON은 `https://bklit.com/r/bar-chart.json`(ui.bklit.com은 301로 여기로 옴). 파일 target이 `components/charts/bar-chart.tsx`라서 alias `@/components` → **`src/components/charts/`** 에 들어간다. 티켓 본문의 `src/components/ui/`는 틀린 추측이었고 테스트는 `charts/`를 본다
- bar-chart 의존: `@visx/gradient`, `@visx/pattern`, `@visx/shape` (4.0.1-alpha.0), `motion`(이미 있음). registryDependencies: `@bklit/chart-context`, `@bklit/chart-animation`, `@bklit/grid`, `@bklit/chart-tooltip`, `@bklit/utils` — CLI가 같이 받는다
- CLI가 뭘 물으면(overwrite 등) 기본값. `--yes` 옵션 가능

### 컴포넌트 API (테스트가 쓰는 부분)
```tsx
import { BarChart } from "@/components/charts/bar-chart"; // export function BarChart, default도 있음
import { Bar } from "@/components/charts/bar";
<BarChart data={[{ year: "2023", violations: 10 }, …]} xDataKey="year">
  <Bar dataKey="violations" animate={false} />
</BarChart>
```
- BarChart는 `<div style={{aspectRatio}}><ParentSize>` 안에서 width/height를 재고 10px 미만이면 `null`을 돌려준다. 테스트는 ResizeObserver 가짜로 600×300을 바로 넣어주니 `<svg>`가 나와야 한다
- 테스트는 `await import("../src/components/charts/bar-chart")` 동적 import를 쓴다 (tests/setup.ts의 ResizeObserver stub과 별개로 테스트 안에서 가짜를 바꿔 끼운다)
