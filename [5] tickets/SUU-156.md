## Codex 메모

### import 경로
- 루트 `pyproject.toml`의 `pythonpath`에 `[3] backend`와 `[2] db/pipeline/5_rag`가 이미 있다. 테스트는 `from app.index import load_index`, 코드는 `from ecfr_keyword import build_keyword_search`로 쓴다. `sys.path` 조작 불필요.
- `[3] backend/app/__init__.py`가 있어야 `app.index`가 잡힌다.

### `index.py`
```python
@dataclass
class Index:
    release_id: str
    chunks: list[dict]
    keyword: Callable[[str, int], list[dict]]
```
- `fetch_chunks(client, release_id) -> list[dict]`: `[6] rag/eval/run_eval.py:59`의 `fetch_chunks`를 **베낀다**(import 하지 않는다 — eval 폴더는 pythonpath에 없고 print가 있다). 컬럼 `chunk_key,node_key,embedding,context_text,chunk_text`, `index_status = embedded`, `order("chunk_key")`, 500개씩 `range`. 임베딩이 `str`이면 `json.loads`.
- `load_index(client, release_id) -> Index`: 모듈 전역 `_CACHE: dict[str, Index]`. 있으면 그대로, 없으면 `fetch_chunks` → `build_keyword_search(chunks)` → `Index` 만들어 넣는다.
- 테스트의 `FakeSupabase`는 `table().select().eq().eq().order().range().execute().data` 체인만 흉내낸다. 그 밖의 메서드를 쓰면 테스트가 깨진다.

- 실제 5,625청크 × 1,792차원 ≈ 80MB + BM25 색인. Render 무료 512MB 안. 이 티켓에서 측정은 안 한다.
