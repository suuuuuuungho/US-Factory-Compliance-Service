# SUU-224 feat(db): ADI 등록·적재·검사·공개를 한 번에 실행한다

## 목표
명령 한 줄로 `parsed/{as_of}/` jsonl 9개를 release로 등록(원본 파일 포함) → COPY 적재 → 행 수·고아 FK 검사 → 통과하면 `common_dataset_current(adi)`로 공개한다. 실패하면 공개하지 않고 직전 release를 유지한다.

## Codex 메모
- 본보기: `[2] db/pipeline/2_Federal Register/fr_release.py`·`fr_load.py`·`fr_check.py`·`fr_ingest.py` (SUU-209). 구조를 그대로 따르되 아래 ADI 차이만 반영한다.
- **테스트 fixture** `conftest.py::adi`: 실제 `ecfr_raw.save_raw` + `adi_parse.parse_all` + `adi_enrich.enrich_all`로 `raw/`(목록 HTML 2 + PDF 4, 그중 1800013.pdf와 King PDF는 같은 파일·다른 URL)와 `parsed/2026-09-22/` jsonl 9개를 만든다. 기대 행 수: source_entry 275, document 2, document_version 2, entry_document 3, page 7, block 6, cfr_reference 4(2건은 `current_node_key` NULL), document_relation 1, facility_candidate 1. `adi.objects[이름] = (source_url, sha256)`.
- 표 9개 중 **release_id 열이 있는 표는 `adi_source_entry`·`adi_entry_document` 둘뿐**이다(SUU-223 DDL). 나머지 7표는 결정적 키(`document_id`·`version_id` = sha256 기반 uuid5)라서 release 마다 같은 행이 나온다 → "지우고 다시 넣기"를 **jsonl에 든 키 목록**으로 한다.

### adi_release.py
- `raw_as_of = json.load(parsed/{as_of}/quality_report.json)["raw_as_of"]`. 원본 목록: `sorted(root.glob(f"**/raw/{raw_as_of}/manifest.json"))` 의 모든 entry (실데이터: `raw/`, `caa_dashboard/`, `adi_letters/shard_*/`, `dashboard_letters/`). `adi_details/`엔 manifest가 없으니 자연히 제외.
- `role`: `entry["name"]`이 `.html`로 끝나면 `list`, 아니면 `letter`.
- `storage_uri` = ADI root 기준 상대경로. manifest의 `path`는 그 데이터셋 폴더(`manifest.parent.parents[1]`) 기준이므로 `(manifest.parent.parents[1] / entry["path"]).relative_to(root).as_posix()` → 예 `adi_letters/shard_1/raw/2026-09-17/{sha}/M170010.pdf`, `raw/2026-09-17/{sha}/adi-results.html`.
- `manifest_hash = sha256(":".join(sorted(모든 entry의 sha256)))` (중복 sha 포함 그대로). 같은 `(dataset, scope_key, manifest_hash, parser_version)` release가 있으면 그 `release_id` 반환, 아무것도 넣지 않는다.
- raw_object는 `unique (source_url, sha256)`. 등록 전 `client.table("common_raw_object").select("object_id,source_url,sha256").in_("sha256", [...])`(200개씩)로 조회, 있으면 재사용, 없으면 uuid4로 insert. 같은 sha256이라도 URL이 다르면 행 2개(테스트: 6개).
- insert는 목록으로 묶어서(500행씩; 테스트는 6행이 한 번에 들어오길 기대). raw_object 행: `object_id, run_id, source_url, final_url, storage_uri, sha256, byte_size, media_type, fetched_at, source_modified_at=None, etag=None`.
- ingest_run: `{"run_id", "dataset": "adi", "scope": {"as_of", "raw_as_of", "manifests": manifest 파일 수}, "status": "succeeded", "started_at", "finished_at", "counts": {"raw_objects": n}, "error_summary": None}`.
- release: `{"release_id", "dataset": "adi", "scope_key": "adi+caa_dashboard", "run_id", "source_as_of": as_of, "manifest_hash", "parser_version": "1", "status": "staging", "published_at": None}`. release_object: 이번 release 원본 전부(재사용 포함) `{"release_id", "object_id", "role"}`.

### adi_load.py
- `TABLES = adi_parse.TABLES + adi_enrich.TABLES` = `("adi_source_entry", "adi_document", "adi_document_version", "adi_entry_document", "adi_page", "adi_block", "adi_cfr_reference", "adi_document_relation", "adi_facility_candidate")` — 이 순서로 COPY(부모 먼저).
- 순서: `set statement_timeout = 0` → `set session_replication_role = replica` → 삭제(자식 먼저) → COPY 9표 → `conn.commit()`.
- 키 목록: `versions = [row["version_id"] for adi_document_version.jsonl]`, `documents = [row["document_id"] for adi_document.jsonl]`. 삭제 SQL은 정확히 이 모양(테스트 fake가 파싱한다), params는 `(release_id,)` 또는 `(list,)` 하나:
  1. `delete from adi_facility_candidate where document_id = any(%s)`
  2. `delete from adi_document_relation where from_document_id = any(%s)`
  3. `delete from adi_cfr_reference where version_id = any(%s)`
  4. `delete from adi_block where version_id = any(%s)`
  5. `delete from adi_page where version_id = any(%s)`
  6. `delete from adi_entry_document where release_id = %s`
  7. `delete from adi_document_version where version_id = any(%s)`
  8. `delete from adi_document where document_id = any(%s)`
  9. `delete from adi_source_entry where release_id = %s`
- 원본 연결: `select o.object_id, o.sha256 from common_raw_object o join common_release_object r using (object_id) where r.release_id = %s order by o.sha256, o.source_url` → `sha256 → object_id`(같은 sha256이 여럿이면 source_url이 작은 것, 결정적).
- 현재 release: `select dataset, release_id from common_dataset_current where dataset in ('ecfr', 'echo')` → `{"ecfr": id, "echo": id}`. 둘 중 하나라도 없으면 아무것도 쓰기 전에 `LookupError(f"common_dataset_current has no {dataset} release")` (commit 0).
- COPY 열 = jsonl 키 순서 + 아래 차이. jsonb(`categories`)는 `json.dumps(value, ensure_ascii=False)`, None은 None, 나머지는 값 그대로:
  - `adi_source_entry`: `release_id` + jsonl 키에서 **`text_status` 제외** + `source_object_id`(= objects[`list_sha256`])
  - `adi_document`: jsonl 키 그대로(`created_at`은 DB 기본값)
  - `adi_document_version`: jsonl 키 + `object_id`(= objects[`sha256`])
  - `adi_entry_document`: `release_id` + jsonl 키
  - `adi_page`·`adi_block`·`adi_document_relation`: jsonl 키 그대로
  - `adi_cfr_reference`: jsonl 키 그대로(`historical_*`·`current_ecfr_release_id` 키가 None으로 들어 있다). `current_node_key`가 None이 아니면 `current_ecfr_release_id = current["ecfr"]`, None이면 None 유지 (DDL check: 둘 다 NULL이거나 둘 다 값)
  - `adi_facility_candidate`: jsonl 키 + `echo_release_id`(= current["echo"])
- 반환: `{table: 넣은 행 수}` 9개 전부(0이어도 키는 둔다).

### adi_check.py
- 표 9개 행 수: release 표는 `select count(*) from {table} where release_id = %s`, 나머지는 `select count(*) from {table} where {key} = any(%s)` (key: adi_document `document_id`, adi_document_relation `from_document_id`, adi_facility_candidate `document_id`, 그 외 `version_id`; 목록은 load와 같은 versions/documents). jsonl 줄 수와 다르면 `f"{table}: db {n} != jsonl {m}"`.
- 고아 3개 (별칭 `c`·`p`/`n`, 테스트 fake가 `from (\w+) c left join (\w+)`로 읽는다):
  - `select count(*) from adi_entry_document c left join adi_document_version p using (version_id) where c.release_id = %s and p.version_id is null` → `orphan adi_entry_document.version_id: {n}`
  - `select count(*) from adi_page c left join adi_document_version p using (version_id) where c.version_id = any(%s) and p.version_id is null` → `orphan adi_page.version_id: {n}`
  - `select count(*) from adi_cfr_reference c left join ecfr_node n on n.release_id = c.current_ecfr_release_id and n.node_key = c.current_node_key where c.version_id = any(%s) and c.current_node_key is not null and n.node_key is null` → `orphan adi_cfr_reference.current_node_key: {n}` (못 이은 인용=NULL은 고아가 아니다)
- 반환 `{"ok": not problems, "problems": [...], "counts": {table: n}}`. quality_report 대조는 하지 않는다.

### adi_ingest.py
- `fr_ingest.py`를 그대로. `load_release(root, as_of, release_id, conn=conn)`. 검사 실패: `client.table("common_dataset_release").update({"status": "failed"}).eq("release_id", release_id).execute()` 후 `CheckFailed(release_id, problems)` — `common_dataset_current`는 건드리지 않는다(직전 release 유지). 성공: `publish_release(release_id, client=client)`.
- `__main__`: `pipeline_root = Path(__file__).resolve().parents[2] / "4) ADI+CAA"`, as_of는 argv[1] 또는 `_latest_as_of(pipeline_root / "parsed")`, 환경변수 `SUPABASE_URL`·`SUPABASE_SECRET_KEY`·`SUPABASE_DB_URL`.
- 네트워크·DB 없음. 실제 실행(4,061행·PDF 698건)은 SUU-225. 실행 전 조건: eCFR·ECHO가 `common_dataset_current`에 공개돼 있어야 한다.
