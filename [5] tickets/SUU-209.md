## Codex 메모
- 본보기: `[2] db/pipeline/3_ECHO/echo_release.py`·`echo_load.py`·`echo_check.py`·`echo_ingest.py`. 구조를 그대로 따르되 아래 FR 차이만 반영한다.
- **테스트 fixture**: `conftest.py`의 `fr` fixture가 실제 `fr_raw.store_raw` + `fr_parse.parse_all`로 `raw/`(문서 3건, 원본 8개 — 2003-08-28 정정문은 XML 없음)과 `parsed/2026-09-21/`을 만든다. 기대 행 수: document 3, identifier 4, cfr_reference 3, date_event 2.

### fr_release.py
- 원본 목록: `root/raw/{연도}/{발행일}_{문서번호}/manifest.json` 전부(`raw/lists/`는 제외, `fr_parse.py`와 같은 순회). manifest의 **모든 entry**(detail·xml·pdf)가 대상. `role = entry["kind"]`.
- `manifest_hash = sha256(":".join(sorted(모든 entry의 sha256)))`. 같은 `(dataset, scope_key, manifest_hash, parser_version)` release가 있으면 그 `release_id` 반환하고 아무것도 넣지 않는다.
- `common_raw_object`는 `unique (source_url, sha256)`. FR은 다음 as_of에도 같은 원본을 다시 쓰므로 **이미 있는 행은 재사용**: 등록 전에 `client.table("common_raw_object").select("object_id,source_url,sha256").in_("sha256", [...])`로 조회(sha256 200개씩 나눠서), `(source_url, sha256)`가 있으면 그 `object_id`, 없으면 새 uuid4로 insert.
- insert는 **목록으로 묶어서**: `client.table(...).insert([row, row, ...]).execute()` — raw_object·release_object 각각 500행씩 끊어도 되지만 테스트(원본 8개)는 한 번에 8행이 들어오길 기대한다(끊는 크기 ≥ 8). `common_release_object`는 재사용한 것 포함 이번 release의 원본 전부.
- raw_object 행: `object_id, run_id, source_url, final_url, storage_uri(=entry["path"]), sha256, byte_size, media_type, fetched_at`. `source_modified_at`·`etag`는 FR manifest에 없으니 None.
- ingest_run: `{"run_id", "dataset": "fr", "scope": {"as_of": as_of, "documents": 폴더 수}, "status": "succeeded", "started_at", "finished_at", "counts": {"raw_objects": n}, "error_summary": None}`.
- release: `{"release_id", "dataset": "fr", "scope_key": "part63_metadata", "run_id", "source_as_of": as_of, "manifest_hash", "parser_version": "1", "status": "staging", "published_at": None}`.

### fr_load.py
- 순서: `set statement_timeout = 0` → `set session_replication_role = replica` → 자식 3표 delete(`fr_identifier`, `fr_cfr_reference`, `fr_date_event`) → `fr_document` delete → COPY `fr_document` → 자식 3표 COPY → `conn.commit()`.
- 원본 연결: echo_load의 `_source_objects`와 같은 SQL(`select o.object_id, o.sha256 from common_raw_object o join common_release_object r using (object_id) where r.release_id = %s`)로 `sha256 → object_id`. fr_document 행마다 `source_object_id = objects[row["content_hash"]]`; `body_object_id`·`pdf_object_id`는 그 문서 폴더 `raw/{연도}/{publication_date}_{document_number}/manifest.json`에서 `kind == "xml"`/`"pdf"`인 **마지막** entry의 sha256으로 찾는다(없으면 None).
- COPY 열 = jsonl 키 순서 + 추가 열. `fr_document`: `release_id` + jsonl 키 25개 + `source_object_id, body_object_id, pdf_object_id`. `fr_cfr_reference`: `release_id, reference_id(uuid4)` + jsonl 키. `fr_date_event`: `release_id, event_id(uuid4)` + jsonl 키. `fr_identifier`: `release_id` + jsonl 키.
- jsonb 열은 `json.dumps(value, ensure_ascii=False)`: `agencies, docket_ids, regulation_id_numbers, raw_metadata`. date/integer/text는 값 그대로, None은 None.
- 반환: `{"fr_document": n, "fr_identifier": n, "fr_cfr_reference": n, "fr_date_event": n}`.

### fr_check.py
- 표 4개 `select count(*) from {table} where release_id = %s` vs jsonl 줄 수 → 다르면 `f"{table}: db {n} != jsonl {m}"`.
- 고아: 자식 3표마다 `select count(*) from {child} c left join fr_document p on p.release_id = c.release_id and p.document_key = c.document_key where c.release_id = %s and p.document_key is null` → 0이 아니면 `f"orphan {child}.document_key: {n}"`.
- `select count(*) from fr_document where release_id = %s and source_object_id is null` → 0이 아니면 `f"fr_document source_object_id is null: {n}"`.
- `parsed/{as_of}/quality_report.json`의 `rows[table]`이 DB count와 다르면 `f"quality_report {table}: report {r} != db {n}"`.
- 모든 SQL의 params는 `(release_id,)` 하나. 반환 `{"ok": not problems, "problems": [...], "counts": {table: n}}`.

### fr_ingest.py
- `echo_ingest.py`를 그대로, `code_map_version` 없이. `load_release(root, as_of, release_id, conn=conn)`.
- 검사 실패: `client.table("common_dataset_release").update({"status": "failed"}).eq("release_id", release_id).execute()` 후 `CheckFailed(release_id, problems)`. 성공: `publish_release(release_id, client=client)` (ecfr_publish — release 행의 dataset/scope_key를 읽어 `common_dataset_current`를 upsert한다).
- `__main__`: `pipeline_root = Path(__file__).resolve().parents[2] / "2) Federal Register"`, as_of는 argv[1] 또는 `_latest_as_of(pipeline_root / "parsed")`, 환경변수 `SUPABASE_URL`·`SUPABASE_SECRET_KEY`·`SUPABASE_DB_URL`.
- 네트워크·DB 없음. 실제 1,532건 실행은 SUU-210.
