# SUU-141 feat(frontend): 판화 푸터에서 기차와 굴뚝 연기가 계속 움직인다

## 목표
페이지 맨 아래 크림 배경 위에 판화 공장이 깔리고, 굴뚝 3개에서 연기가 피어오르며, 그 앞을 기차가 왼→오로 계속 지나간다. 그림은 이미 `public/engraving/`에 있다. 코드는 배치 + CSS 애니메이션만.

레퍼런스: https://recent.design/i/yq2q9mt-meridian-animated-train-footer

## Codex 메모
- 이미지는 `next/image` 대신 일반 `<img>`를 쓴다 (장식용, `aria-hidden`, 정적 파일). 테스트는 `role=img, hidden: true`로 찾고 `src`에 `engraving/파일명`이 들어 있으면 된다. eslint `@next/next/no-img-element`가 걸리면 그 줄에 `// eslint-disable-next-line @next/next/no-img-element`
- 구조 (아래에서 위로 쌓임):
  ```
  <footer class="relative overflow-hidden bg-paper border-t border-line">
    <div class="max-w-6xl mx-auto px-6 pt-16 pb-8 grid md:grid-cols-4 gap-8">  ← 링크 3열 + 브랜드 칸
      브랜드: "US Factory Compliance" (serif) + 한 줄 + © 2026
      <ul> 제품: 조항 후보 찾기 / 판정 기준 / 체크리스트
      <ul> 자료: 40 CFR Part 63 / EPA 판정 선례 / 개정 이력
      <ul> 회사: 소개 / 문의 / 개인정보
    </div>
    <div aria-hidden class="relative h-[40vw] max-h-[420px] min-h-[220px]">   ← 그림 무대
      <img factory  class="absolute bottom-0 left-1/2 -translate-x-1/2 w-[min(100%,1400px)]">
      <img smoke ×3 data-testid="footer-smoke" class="animate-smoke absolute w-[7%] ..." style="left: X%; bottom: Y%; animation-delay: …">
      <img train    data-testid="footer-train" class="animate-train absolute bottom-[3%] w-[36%] max-w-[520px]">
    </div>
  </footer>
  ```
- 굴뚝 꼭대기 위치 (factory.png 기준, 그림 가로를 100%로): x ≈ **25%, 50%, 73%**, 꼭대기 y ≈ 그림 높이의 90% (바닥에서). 연기는 그 위에서 시작. 세 연기에 `animation-delay` 0s / 1.3s / 2.6s, smoke-1/2/3을 하나씩
- 기차는 factory 바닥선(그림 bottom) 위에 놓는다. 그림은 오른쪽을 향하므로 **왼→오**로 이동
- globals.css에 추가할 것:
  ```css
  @theme {
    --animate-train: train-cross 28s linear infinite;
    --animate-smoke: smoke-rise 6s ease-out infinite;
  }
  @keyframes train-cross { from { transform: translateX(-110%); } to { transform: translateX(calc(100vw + 10%)); } }
  @keyframes smoke-rise {
    0%   { opacity: 0;   transform: translateY(0) scale(0.5); }
    15%  { opacity: 0.9; }
    100% { opacity: 0;   transform: translateY(-45%) scale(1.15); }
  }
  @media (prefers-reduced-motion: reduce) {
    .animate-train, .animate-smoke { animation: none; }
  }
  ```
  테스트가 정규식으로 읽으므로 `--animate-train:` `--animate-smoke:` 이름과 `infinite`, reduced-motion 블록 안의 `animation: none`은 글자 그대로 유지
- `train-cross`의 `translateX`는 요소 자기 폭 기준(%)과 뷰포트(vw)를 섞어 화면 밖에서 밖으로 간다. `overflow-hidden`은 footer에 있다
- 확인: `[4] frontend`에서 `npm test`, `npm run build`, `npm run dev` 후 http://localhost:3000 맨 아래에서 기차가 지나가는지 눈으로 본다
