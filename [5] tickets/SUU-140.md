# SUU-140 chore(frontend): Next.js 뼈대와 크림·세피아 테마를 세운다

## 목표
`[4] frontend`에 Next.js 앱을 세우고, 크림 배경·세피아 잉크 테마 토큰을 정하고, CI가 프론트 테스트와 빌드를 돌리게 한다. 판화(engraving) 랜딩(SUU-141, SUU-142)의 집이다.

## 건드릴 파일
- 만듦: `[4] frontend/` — `create-next-app` 결과물 (Next.js 16 App Router, TypeScript, Tailwind v4, ESLint, `src/` 사용, import alias `@/*`)
  - `package.json` — scripts: `dev`, `build`(`next build`), `start`, `lint`, `test`(`vitest run`)
  - devDependencies 추가: `vitest`, `@vitejs/plugin-react`, `jsdom`, `@testing-library/react`, `@testing-library/jest-dom`, `@types/react`, `@types/react-dom`
  - `vitest.config.ts` — `environment: "jsdom"`, `plugins: [react()]`, `include: ["src/**/*.test.{ts,tsx}"]`
  - `src/app/globals.css` — Tailwind v4 `@import "tailwindcss";` + `@theme { --color-paper: #F5F0E6; --color-ink: #4A2E1E; --color-line: #C9B99A; --font-serif: ...; --font-sans: ...; }`
  - `src/app/layout.tsx` — `<html>`에 `bg-paper text-ink`, `<body>`에 본문 산세리프. `next/font/google`로 세리프(예: Lora) + 산세리프(예: Inter) 로드
  - `src/app/page.tsx` — `<main>` 하나만 있는 자리표시 (문구는 SUU-142가 채움). `getByRole("main")`이 잡혀야 한다
  - `public/engraving/README.md` — 그림 조각 규약 표 (아래 Codex 메모)
  - `.gitignore` — `node_modules/`, `.next/`, `out/` (create-next-app 기본)
- 고침: `.github/workflows/ci.yml` — `frontend` job 추가 (아래)
- 테스트(이미 있음, 수정 금지): `[4] frontend/tests/test_frontend_scaffold.py`, `[4] frontend/src/app/page.test.tsx`

## Codex 메모
- 실행 위치: `[4] frontend/`에서 `npx create-next-app@latest . --ts --tailwind --eslint --app --src-dir --import-alias "@/*" --use-npm --yes` (폴더에 `.gitkeep`·`tests/`·`src/app/page.test.tsx`가 이미 있어 "비어있지 않다"고 거부하면, 임시 폴더에 만들고 파일을 옮긴다. **`tests/`와 `page.test.tsx`는 지우지 않는다**)
- Node 로컬 24.19 / npm 11. CI는 `actions/setup-node@v4` + `node-version: 22` + `cache: npm` + `cache-dependency-path: "[4] frontend/package-lock.json"`
- `page-lock.json`을 꼭 커밋한다 (`npm ci`가 필요로 함)
- vitest에서 `.tsx` 테스트가 JSX를 쓰므로 `@vitejs/plugin-react` 필요. `tsconfig.json`의 `jsx`는 create-next-app 기본(`preserve`)이면 vitest가 esbuild로 처리하니 그대로 둔다. 안 되면 `vitest.config.ts`에 `esbuild: { jsx: "automatic" }`
- ci.yml `frontend` job 모양 (pytest가 문자열로 검사하므로 job 이름은 정확히 `frontend`, 들여쓰기 2칸):
  ```yaml
  frontend:
    name: 프론트 (vitest + build)
    runs-on: ubuntu-latest
    timeout-minutes: 10
    defaults:
      run:
        working-directory: "[4] frontend"
    steps:
      - uses: actions/checkout@v6
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
          cache-dependency-path: "[4] frontend/package-lock.json"
      - run: npm ci
      - run: npm test
      - run: npm run build
  ```
