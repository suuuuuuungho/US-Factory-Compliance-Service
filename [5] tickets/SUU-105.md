# SUU-105 feat(db): 시설 CSV를 facility·industry 행으로 바꾼다

## 목표
`ICIS-AIR_FACILITIES.csv` 한 행(dict)을 `echo_facility` 1행 + `echo_industry` 자식 행 리스트로 바꾼다.

## 건드릴 파일
- 만들 것: `[2] db/pipeline/3_ECHO/echo_facility.py`
- 이미 있음 (수정 금지): `[2] db/tests/3_ECHO/test_echo_facility.py`, `echo_values.py`(`is_missing`, `split_codes` 가져다 쓴다)

## 안 하는 것
- 다른 CSV, jsonl 쓰기, `source_row_no`·`release_id` 붙이기 (SUU-111이 붙인다)
- 제조업 후보 판정, FRS 연결(`echo_facility_identifier`) — `registry_id`는 문자열 그대로만
- 값 정리(`strip`, 대소문자) — 원문 보존이 규칙
- `tests/` 수정

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| 실제 첫 행 → 17키 facility dict. `zip="06078"` 선행 0 유지, `address` 뒤 공백 그대로, `current_hpv` 원문. NULL 허용 열의 `""`는 `None`. `NAICS_CODES="445110"` → industry 1행 | `test_first_real_row_keeps_leading_zeros_and_raw_text` |
| `SIC_CODES="3541 3545"` → SIC 2행 + NAICS 1행 (SIC 먼저, 원문 순서). 둘 다 `""` → `[]` | `test_multi_value_codes_become_one_industry_row_each_and_empty_means_none` |
| `AIR_LOCAL_CONTROL_REGION_*`(사전)와 `LOCAL_CONTROL_REGION_*`(CSV) 어느 이름이 와도 같은 필드. `PGM_SYS_ID` 없으면 `KeyError` | `test_column_alias_and_missing_pgm_sys_id` |

## Codex 메모

테스트가 부르는 것:

```python
def facility_rows(row: dict[str, str]) -> tuple[dict, list[dict]]
```

- 실제 헤더 19열 (2026-09-17 ZIP): `PGM_SYS_ID, REGISTRY_ID, FACILITY_NAME, STREET_ADDRESS, CITY, COUNTY_NAME, STATE, ZIP_CODE, EPA_REGION, SIC_CODES, NAICS_CODES, FACILITY_TYPE_CODE, AIR_POLLUTANT_CLASS_CODE, AIR_POLLUTANT_CLASS_DESC, AIR_OPERATING_STATUS_CODE, AIR_OPERATING_STATUS_DESC, CURRENT_HPV, LOCAL_CONTROL_REGION_CODE, LOCAL_CONTROL_REGION_NAME`. 지금 ZIP은 `LOCAL_CONTROL_REGION_*`인데 EPA 사전은 `AIR_LOCAL_CONTROL_REGION_*`라 둘 다 받는다.
- facility 키 순서와 원본 열 (테스트가 dict 통째 `==` 비교):

  | 키 | 열 | `""` 처리 |
  |---|---|---|
  | `pgm_sys_id` | `PGM_SYS_ID` | 없으면 `KeyError` (`row["PGM_SYS_ID"]`로 그냥 꺼내면 된다) |
  | `registry_id` | `REGISTRY_ID` | `None` |
  | `name` `address` `city` `county` `state` `zip` `epa_region` | `FACILITY_NAME` `STREET_ADDRESS` `CITY` `COUNTY_NAME` `STATE` `ZIP_CODE` `EPA_REGION` | 그대로 (`""`도 `""`) |
  | `facility_type` `source_class` `source_class_desc` `operating_status` `operating_status_desc` `current_hpv` | `FACILITY_TYPE_CODE` `AIR_POLLUTANT_CLASS_CODE` `AIR_POLLUTANT_CLASS_DESC` `AIR_OPERATING_STATUS_CODE` `AIR_OPERATING_STATUS_DESC` `CURRENT_HPV` | `None` |
  | `local_control_region_code` `local_control_region_name` | `LOCAL_CONTROL_REGION_CODE` 또는 `AIR_LOCAL_CONTROL_REGION_CODE` (NAME도 같은 식) | `None`; 두 이름 다 없으면 `None` |

- `None` 판정은 `echo_values.is_missing`. 값은 `strip()` 하지 않는다 (`"68 BRIDGE ST "` 그대로).
- industry 행: `{"pgm_sys_id", "code_system": "SIC"|"NAICS", "code", "source_locator": "SIC_CODES"|"NAICS_CODES"}`. `echo_values.split_codes`로 나눈다. SIC 전부 → NAICS 전부 순.
- 별칭은 모듈 상수 하나면 충분: `ALIASES = {"local_control_region_code": ("LOCAL_CONTROL_REGION_CODE", "AIR_LOCAL_CONTROL_REGION_CODE"), ...}` 처럼 두고 처음 있는 열을 쓴다. 클래스·설정 파일 없음. 표준 라이브러리만, 50줄 안팎.
- `from echo_values import is_missing, split_codes` — 테스트는 `--import-mode=importlib`로 `3_ECHO` 폴더가 path에 있어 평면 import가 된다 (`echo_collect.py`가 `echo_fetch` 등을 같은 방식으로 import).
