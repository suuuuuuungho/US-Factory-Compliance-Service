# SUU-199 feat(frontend): Memo 2분할을 넓게 쓰고 끌어서 크기를 바꾼다

## 목표
1. Memo pane이 열리면 `main`의 `max-w-7xl`을 풀고 좌우 여백을 `p-8` → `px-4 py-8`로 줄여 2분할이 화면 폭을 넉넉히 쓴다. 닫으면 원래대로.
2. 왼쪽 열과 Memo pane 사이에 세로 손잡이(`role="separator"`). 끌면 Memo pane 폭(px)이 바뀐다. 기본 480px, 최소 280px.

## 건드릴 파일
- `[4]frontend/src/app/applicability/page.tsx` — `main` className을 `memoOpen`에 따라 바꾼다. `memoWidth` state + separator(pointer 이벤트로 드래그). MemoPane에 `style={{width}}`
- `[4]frontend/src/app/MemoPane.tsx` — `style` prop 받아 aside에 적용, `flex-1` → `shrink-0`
- `[4]frontend/tests/memo_pane.test.tsx` — 검사 2개 추가

## 안 하는 것
- 다른 페이지 폭, 폭을 localStorage에 기억하기, 라이브러리 추가

| 완료 기준 | 확인 |
|---|---|
| 닫힘: `max-w-7xl p-8`. 열림: `max-w-7xl` 없음 + `px-4`. 다시 닫으면 복귀 | `Memo가 열리면 main의 최대 폭이 풀리고 좌우 여백이 줄어든다` |
