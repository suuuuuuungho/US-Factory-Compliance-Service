# SUU-199 feat(frontend): 질문·메모도 끌어서 크기를 바꾸는 칸이 된다

## 목표
Ask 뒤에는 질문 폼과 Memo도 dockview 칸이 되어 네 칸(질문·Subparts·Memo·Checklist)을 전부 끌어서 크기·위치를 바꿀 수 있다.

```
1 3 4     1 = 질문   2 = Subparts
2 3 4     3 = Memo   4 = Checklist
```
기본 배치 = 왼쪽 열 질문(위)/Subparts(아래), 오른쪽 Checklist. Memo 버튼을 누르면 Checklist 왼쪽(3)에 Memo 칸.
Ask 전 첫 화면(제목 + 폼)은 그대로. Ask 뒤에는 main의 `max-w-7xl`을 풀고 `px-4`로 넓게 쓴다.
