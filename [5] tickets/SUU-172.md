# SUU-172 feat(frontend): 질문창·결과 카드가 Framer 스타일로 바뀐다

## 목표
질문 입력칸, Ask 버튼, 후보 Subpart 카드, 체크리스트, 조문 패널(aside)이 `DESIGN.md`(Framer) 모양 — 검정 바탕, 흰 알약 버튼, 차콜 카드 — 으로 바뀐다. 기능은 그대로.

## 건드릴 파일
- 고침: `[4]frontend/src/app/page.tsx` — className만 바꾼다
- 테스트(이미 있음, 수정 금지): `[4]frontend/tests/framer_style.test.tsx`

## 안 하는 것
- 기능·상태·API 호출 변경 (`ask`, `getSection`, 캐시, 에러 처리)
- 문구 변경 (placeholder, 로딩 문구, "not a final" 문구, h1)
- `layout.tsx`, `TopNav.tsx`, `globals.css`, `lib/api.ts`
- 새 컴포넌트 분리 — page.tsx 한 파일 안에서 끝낸다
- `tests/` 아래 수정

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| Ask 버튼에 `rounded-full` `bg-primary` `text-on-primary` 클래스가 있다 | `Ask 버튼은 흰 알약이다` |
| textarea에 `bg-surface-1` `border-hairline` 클래스가 있다 | `질문 입력칸은 차콜 바탕 + hairline 테두리다` |
| 후보 Subpart `<section>`에 `bg-surface-1` `border-hairline` `rounded-lg` 클래스가 있다 | `후보 Subpart 카드는 차콜 카드다` |
| 인용 `<button>`에 `text-accent-blue` 클래스가 있다 | `인용 버튼은 accent-blue 링크다` |
| 기존 테스트 전부 통과 (기능 그대로) | `page.test.tsx`, `section.test.tsx`, `smoke.test.tsx`, `topnav_hero.test.tsx` |

## Codex 메모

### 토큰 → Tailwind 클래스
SUU-170에서 `globals.css` `@theme`에 등록된 값이라 아래 클래스가 바로 먹는다. **테스트는 `classList.contains`로 클래스 이름 문자열을 본다** — 아래 이름을 정확히 쓸 것 (`bg-[var(--color-surface-1)]` 같은 임의값 문법은 실패).

| 토큰 | 클래스 |
|---|---|
| `--color-primary` #fff | `bg-primary` |
| `--color-on-primary` #000 | `text-on-primary` |
| `--color-surface-1` #141414 | `bg-surface-1` |
| `--color-hairline` #262626 | `border-hairline` |
| `--color-accent-blue` #0099ff | `text-accent-blue` |
| `--color-ink-muted` #999 | `text-ink-muted` |
| `--radius-md` 10px | `rounded-md` |
| `--radius-lg` 15px | `rounded-lg` |
| `--radius-pill` | `rounded-full` (테스트가 이 이름을 본다. `rounded-pill` 아님) |

### `page.tsx` 바꿀 곳 (className만)
- **textarea** (지금 `rounded border p-2`): `rounded-md border border-hairline bg-surface-1 p-3 text-ink placeholder:text-ink-muted focus:outline-none focus:border-accent-blue`
- **Ask 버튼** (지금 `self-start rounded border px-4 py-2 disabled:opacity-50`): `self-start rounded-full bg-primary px-5 py-2.5 text-sm font-medium text-on-primary disabled:opacity-50` — `disabled` 속성·`type="submit"`은 그대로 (page.test가 잠김을 본다)
- **후보 `<section>`** (지금 `rounded border p-4`): `rounded-lg border border-hairline bg-surface-1 p-5`
- **체크리스트 `<section>`** (지금 클래스 없음): 위와 같은 카드 클래스
- **인용 `<button>`** (지금 `mr-2 text-sm text-blue-700 underline`): `mr-2 text-sm text-accent-blue underline` — `type="button"`, `onClick`, 텍스트 그대로 (section.test가 `getByRole("button", { name: "40 CFR 63.4481(a)(1)" })`로 찾는다)
- **인용 아닌 `<span>`** `text-zinc-500` → `text-ink-muted`
- **"not a final" `<p>`** `text-zinc-500` → `text-ink-muted`
- **aside** (지금 `w-full max-w-md border-l p-8`): `w-full max-w-md border-l border-hairline bg-surface-1 p-8` — `aria-label="Section text"` 유지 (role=complementary로 찾는다)
- **에러 `<p>`** `text-red-700` → 빨강 유지. 검정 바탕에서 보이게 `text-red-400` 정도로 바꿔도 됨
- `<ul className="list-disc pl-6">`는 그대로
