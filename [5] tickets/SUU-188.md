# SUU-188 feat(frontend): 2행 세 카드 높이를 같게 하고 카드 안에서 스크롤

## 목표
Subpart 카드·Checklist 카드·조문 카드가 칸(열) 높이를 꽉 채워 세 카드 높이가 같다. 내용이 넘치면 카드 안에서 스크롤된다.

## 건드릴 파일
- `[4]frontend/src/app/page.tsx` — `CARD`에 `flex-1`, `COLUMN`은 `overflow-y-auto` → `overflow-hidden`
- `[4]frontend/tests/equal_card_height.test.tsx` — 새 테스트
- `[4]frontend/tests/three_columns.test.tsx` — "칸이 스크롤" 기대를 "칸은 min-h-0"로 (스크롤 주체가 카드로 바뀜)

## 안 하는 것
- 기능·API·문구, 모바일(<md) 세로 쌓임

## 왜 바꾸나
카드가 내용만큼만 커져서 세 카드 높이가 제각각이고, 짧은 카드는 스크롤도 안 생긴다. 카드가 칸을 다 채우면 높이가 같아지고 스크롤이 카드 안에서 난다.

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| 세 카드 모두 `flex-1` + `min-h-0` + `overflow-y-auto` | `equal_card_height.test.tsx` > "세 카드 모두 칸을 꽉 채우고(flex-1 min-h-0) 카드 안에서 스크롤된다" |
| 세 칸(열)은 `overflow-hidden`, `overflow-y-auto` 아님 | "세 칸(열) 자체는 스크롤하지 않는다 (overflow-hidden)" |
