# SUU-253 feat(frontend): Decision Letter 목록 표와 EPA 원본 PDF 링크

## 목표
`/decision-letter`가 `public/decision-letters.json`(SUU-252, 132건)을 읽어 Federal Register와 같은 모양의 표로 보여주고, 행마다 EPA 원본 PDF를 새 탭으로 여는 링크를 단다.

## 건드릴 파일
- 고칠 것 `[4]frontend/src/app/decision-letter/page.tsx` — 제목만 있는 빈 페이지 → fetch + 표 + 페이지 바
- 이미 있음 `[4]frontend/tests/decision_letter_list.test.tsx` — 테스트 5개

## 안 하는 것
- 검색·정렬·상세 화면, PDF 미리보기, 우리 서버 프록시
- `federal-register/page.tsx` 수정 (모양만 베끼고 공용 컴포넌트로 빼지 않는다)
- `tests/` 아래 수정·삭제

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| letters 2개 → 행 2개, Facility·Title·Subpart(`, ` 로 합침)·Date 표시 | `letters 2개면 행 2개, Facility·Title·Subpart·Date 가 보인다` |
| `pdf_url` 있으면 `<a href=pdf_url target="_blank" rel="noopener">PDF</a>` | `pdf_url 있는 행은 새 탭으로 여는 PDF 링크가 있다` |
| `pdf_url` null 이면 링크 없이 "원문 없음" | `pdf_url null 인 행은 링크 없이 '원문 없음' 이 보인다` |
| fetch 실패 → "불러오지 못했습니다." | `fetch 실패 시 '불러오지 못했습니다.' 가 보인다` |
| 10개씩 Prev/Next, `n / m` 표시, 끝 페이지에서 Next 비활성 | `10개씩 Prev/Next 로 넘긴다 (FR 과 같은 모양)` |

## Codex 메모
- 베낄 원본: `[4]frontend/src/app/federal-register/page.tsx`. `main`·`h1`·`data-pane="list"` 상자·`table`·`data-pager` 페이지 바의 className을 그대로 쓴다. 다른 점은 (1) 선택/뒤로/diff 없음 (2) 열 구성.
- 데이터 모양: `{ letters: { source_key, facility_name, title, subparts: string[], date, pdf_url: string | null }[] }`. `fetch("/decision-letters.json")`.
- 열 순서: `#`, `Facility`, `Title`, `Subpart`, `Date`, `PDF`. 머리글은 영어(SUU-232 관례).
- `#` 는 `page * 10 + index + 1`. Subpart 는 `subparts.join(", ") || "—"`. Title 은 FR처럼 `w-full max-w-0` + `truncate` + `title=` 속성으로 한 줄.
- 행은 클릭할 게 없으니 `cursor-pointer`·`onClick` 은 넣지 않는다. Title 도 `<button>` 이 아니라 `<span>`.
- PDF 열: `pdf_url ? <a href={pdf_url} target="_blank" rel="noopener noreferrer">PDF</a> : <span className="text-ink-muted">원문 없음</span>`. 링크 접근성 이름이 정확히 "PDF" 여야 한다.
- h1 은 지금 그대로(`text-center font-serif text-[28px] font-bold text-ink`, 글자 "EPA Decision Letter").
- 테스트 실행: `cd "[4]frontend" && npx vitest run tests/decision_letter_list.test.tsx`
