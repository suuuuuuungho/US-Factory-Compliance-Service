## Codex 메모
- 입력 한 행의 모양은 테스트 파일의 `_entry()` 참고. 실제 파일: `[2] db/4) ADI+CAA/parsed/2026-09-22/adi_source_entry.jsonl` (레포에 없음, 로컬 전용)
- 고르는 조건: `source_system == "caa_dashboard"` and `scope_status == "part63_candidate"`
- 출력 한 건: `{"source_key", "facility_name", "title", "subparts": [...], "date": link_text, "pdf_url": canonical_url 또는 None}` — 이 6개 키만
- `part63_subparts`: `affected_subpart_raw`를 `;`로 나누고 각 조각에서 `Part 63, <대문자>:` 패턴의 대문자만. 정규식 `r"Part 63,\s*([A-Z]+):"` 면 충분
- `build`의 반환은 `{"letters": [...]}`. CLI는 `json.dump(..., ensure_ascii=False, indent=2)`로 `--out`에 쓴다
- 구현 후 실제로 실행해 `[4]frontend/public/decision-letters.json`을 만들고 같이 커밋한다:
  ```
  python "[2] db/pipeline/4_ADI+CAA/dashboard_letters_json.py" --parsed "[2] db/4) ADI+CAA/parsed/2026-09-22" --out "[4]frontend/public/decision-letters.json"
  ```
- 테스트 실행: 레포 루트에서 `python -m pytest` 는 `[]` 경로 문제로 파일 지정이 안 된다. `cd "[2] db/tests/4_ADI+CAA" && python -m pytest test_dashboard_letters_json.py -c ../../../pyproject.toml --rootdir ../../..` 로 돌린다
