# SUU-254 feat(frontend): 판정 결과를 편지 PDF 문서로 만든다

## 목표
AskResult(+질문)를 넣으면 `@react-pdf/renderer`의 `<Document>` 한 장짜리 편지가 나온다. 첫 장 맨 위에 "법적 판정이 아니다" 면책이 굵고 크게 박혀 있다.

## 건드릴 파일
- 고칠 것: `[4]frontend/package.json` — `@react-pdf/renderer` 를 dependencies에 추가 (`npm install @react-pdf/renderer`)
- 만들 것: `[4]frontend/src/app/applicability/LetterPdf.tsx` — `export function LetterPdf({ question, result }: { question: string; result: AskResult })`

## 안 하는 것
- 조문 본문(section text) 포함 안 함. Related sections 는 `section_key` + `subpart` 만
- 다운로드 버튼, page.tsx 연결, 메모 기능 없음 (다음 티켓)
- 백엔드 변경 없음
- `tests/` 아래 수정 금지

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 (`[4]frontend/tests/letter_pdf.test.tsx`) |
|---|---|
| 가짜 AskResult로 렌더하면 질문·후보 subpart·criteria·citation·checklist·section key가 모두 텍스트로 있다 | `가짜 AskResult로 렌더하면 질문·subpart·criteria·citation·checklist·section key가 모두 텍스트로 있다` |
| 면책 문구가 문서의 첫 번째 Text이고, 본문보다 큰 fontSize와 bold 스타일이 붙어 있다 | `면책 문구가 첫 번째 Text이고, 본문(Page)보다 큰 fontSize와 bold(Times-Bold)가 붙어 있다` |
| Page 스타일의 fontFamily 가 Times-Roman 이다 | `Page 스타일의 fontFamily가 Times-Roman이다` |

## Codex 메모
- 타입은 `[4]frontend/src/lib/api.ts` 의 `AskResult` / `Candidate` / `Criterion` 을 그대로 import 한다. `answer` 는 null 일 수 있다 → 그때는 Candidates/Checklist 절을 비운다.
- 문서 순서: [면책 박스] / 날짜 / `To: [Facility]` 빈칸 / `Re: <question>` / Candidates(subpart·title·criteria·citations) / Checklist / Related sections(`section_key` + subpart) / 맨 아래 짧은 면책 한 줄.
- 테스트는 `@react-pdf/renderer` 를 vi.mock 으로 바꿔서 `Document/Page/View/Text/StyleSheet` 만 쓴다. **이 다섯 개 외의 export(Font, Image 등)는 쓰지 않는다.** `style` 은 객체 또는 객체 배열 둘 다 된다.
- 첫 번째 `<Text>`가 반드시 면책 문구여야 한다. 영어 문구에 **"not a legal determination"** 이 들어가야 한다 (예: `This document is NOT a legal determination. For reference only.`). 면책 박스의 View 는 테두리, Text 는 `fontFamily: "Times-Bold"`, `fontSize` 는 Page 의 fontSize 보다 크게.
- `Page` 의 style 에 `fontFamily: "Times-Roman"` 과 본문 `fontSize`(예: 11)를 **꼭** 넣는다. 테스트가 Page의 fontSize와 면책 fontSize를 비교한다.
- Times-Roman / Times-Bold 는 PDF 내장 표준 폰트라 `Font.register` 가 필요 없다.
- 실행: `[4]frontend` 에서 `npm test`. 기존 테스트도 모두 초록이어야 한다.
