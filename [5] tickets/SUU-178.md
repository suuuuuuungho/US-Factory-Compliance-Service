## Codex 메모

### 왜 스레드 + 큐인가
`answer_question`은 동기 함수고 `on_event`도 동기 콜백이다. 응답을 흘려보내려면 **answer_question을 스레드에서 돌리고**, on_event가 `queue.Queue`에 넣은 것을 제너레이터가 꺼내 yield 한다. `threading`은 이미 import 돼 있다. `queue`만 추가.

### 모양
```python
import json, queue
from fastapi.responses import StreamingResponse

def _sse(event: str, data: dict) -> str:
    return f"event: {event}\ndata: {json.dumps(data, ensure_ascii=False)}\n\n"

@app.post("/ask/stream")
def ask_stream(body: Ask):
    if STATE["index"] is None:
        raise HTTPException(503, "index not ready")
    if not body.question.strip():
        raise HTTPException(400, "question is empty")
    q: queue.Queue = queue.Queue()
    index = STATE["index"]

    def run():
        try:
            result = answer_question(body.question, index=index, embed=..., rerank=..., llm=..., chat=...,
                                     on_event=lambda e: q.put(("stage", e)))
            if STATE.get("client"):
                save_answer_log(STATE["client"], answer_log_row(body.question, result, index.release_id))
            q.put(("result", result))
        except Exception as e:  # noqa: BLE001 — 스트림은 이미 열렸다. 에러도 이벤트로
            q.put(("error", {"detail": str(e)}))
        q.put(None)

    threading.Thread(target=run, daemon=True).start()

    def gen():
        while (item := q.get()) is not None:
            yield _sse(*item)

    return StreamingResponse(gen(), media_type="text/event-stream")
```
- embed/rerank/llm/chat 인자는 `/ask`와 **글자 그대로 같게**. 복붙해도 되고, 둘이 같이 쓰는 작은 dict `APIS = dict(embed=..., ...)`로 빼도 된다(그러면 `/ask`도 `**APIS`로 바꾸는 건 허용 — 동작 동일).
- `HTTPException`은 스트림 시작 **전**에 던진다 → 테스트가 503/400 status를 본다.
- 테스트의 가짜 `answer_question`은 `on_event=None` 키워드 인자를 받는다. 위치 인자로 넘기지 말 것.
- 테스트 SSE 파서는 `event:` 줄 + `data:` 줄 + 빈 줄. `json.dumps` 한 줄이어야 한다(indent 금지).
- `ensure_ascii=False`는 선택. 현재 데이터는 영어라 어느 쪽이든 된다.
- `save_answer_log` 실패는 기존 `/ask`처럼 조용히 넘어가야 한다 — `save_answer_log` 안에서 이미 try로 잡는지 `app/log.py` 확인. 잡고 있으면 그대로 두면 됨.
