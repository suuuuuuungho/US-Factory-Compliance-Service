## Codex 메모

### 모듈 모양 (테스트가 부르는 이름)
```python
def current_release_id(conn) -> str          # common_dataset_current where dataset='echo' and scope_key=echo_release.SCOPE_KEY
def fetch_rows(conn, release_id) -> dict[str, list[dict]]   # 표 이름 → dict 행 리스트 (psycopg.rows.dict_row)
def compute_stats(rows) -> dict              # 순수 함수. {"summary", "subparts", "yearly"}
def write_stats(stats, path) -> None         # parents 만들고 json.dump(ensure_ascii=False, indent=2)
def main(argv=None) -> int                   # --out 기본값 [4]frontend/public/echo-stats.json
```
- 계산은 SQL이 아니라 **Python**에서 한다(`compute_stats`가 순수 함수라서 fixture로 테스트할 수 있다). `fetch_rows`는 필요한 열만 `where release_id = %s`로 가져온다.
- `fetch_rows`가 가져올 표·열 (fixture와 같은 키):
  - `echo_facility`: pgm_sys_id
  - `echo_industry`: pgm_sys_id, code_system, code
  - `echo_program_subpart`: pgm_sys_id, cfr_subpart, subpart_desc, cfr_part, mapping_status (`subpart_code`는 `CAAMACTZZZZ` 같은 원본 코드라 안 쓴다. `code`는 `cfr_subpart`=`ZZZZ`)
  - `echo_violation`: violation_id, first_frv_date
  - `echo_violation_facility`: violation_id, pgm_sys_id
  - `echo_activity`: activity_kind, activity_id, activity_date, attributes (`activity_kind in ('titlev','formal')`만 가져와도 된다)
  - `echo_activity_facility`: activity_kind, activity_id, pgm_sys_id
  - `echo_penalty`: penalty_key, activity_kind, activity_id, amount
- DB 연결: `psycopg.connect(os.environ["SUPABASE_DB_URL"])` (`echo_ingest.py`, `fr_diff_load.py`와 같음). 스키마는 `[2] db/migrations/SUU-121_echo_tables.sql`.

### 계산 규칙
- **Part 63 시설 집합 F**: `echo_program_subpart`에서 `cfr_part='63' and mapping_status='mapped'`인 행의 pgm_sys_id (distinct). summary의 모든 수는 F 안에서만 센다. Subpart별은 그 `cfr_subpart`를 가진 시설 집합 안에서 같은 규칙으로 센다.
- `facilities`: |F|
- `mfg_facilities`: F 중 `echo_industry.code_system='NAICS'`이고 code가 `31`·`32`·`33`으로 시작하는 게 하나라도 있는 시설 수. SIC는 안 본다.
- `violation_facility_pct`: F 중 `echo_violation_facility`에 한 번이라도 나오는 시설 % (소수 1자리 반올림). F가 비면 0.0.
- **벌금(처분 단위)**: `echo_penalty.amount > 0`인 행을 `(activity_kind, activity_id)`로 묶어 **처분 하나 = 1건**으로 센다. 같은 처분이 시설 2곳에 붙으면 FORMAL_ACTIONS.csv 행이 2개라 `echo_penalty` 행도 2개(penalty_key 다름)지만 activity_id가 같다 → 1건. 금액은 같은 처분 행 중 max.
  - 처분이 F(또는 해당 subpart 시설 집합)의 시설에 `echo_activity_facility`로 하나라도 붙어 있어야 센다.
  - `penalty_count`·`penalty_median_usd`: 처분일(`echo_activity.activity_date`, formal은 SETTLEMENT_ENTERED_DATE) **2015-01-01 이후**만. summary와 subparts 둘 다 같은 기준(사용자 결정).
  - `penalty_median_usd`: 중앙값(`statistics.median`), 정수로 나오면 int, 없으면 `null`. 짝수 개면 두 값 평균.
- `deviation_y_pct`: `activity_kind='titlev'` 활동 중 F 시설에 붙은 것들에서 `attributes["FACILITY_RPT_DEVIATION_FLAG"] == 'Y'`인 비율 %. **분모 = 인증 건수**(시설 수 아님, 사용자 결정). 인증이 없으면 0.0.
- `subparts[]`: 키 `code, desc, facilities, mfg_facilities, violation_facility_pct, penalty_count, penalty_median_usd, deviation_y_pct`. `code`=`cfr_subpart`, `desc`는 그 code에서 가장 많이 나온 subpart_desc. 정렬: facilities 내림차순, 같으면 code 오름차순.
- `yearly[]`: `{"year", "violations", "penalties"}`. 위반은 F 시설에 붙은 violation의 `first_frv_date` 연도로 **violation_id당 1건**(시설 2곳에 붙어도 1). 벌금은 위 처분 단위(amount>0, F에 붙음)의 `activity_date` 연도로 — 여기는 2015 필터 **없음**. 2000년부터 데이터가 있는 마지막 해까지 **빈 해도 0으로 채운다**. 1999 이전은 버린다. 데이터가 하나도 없으면 `[]`.
- 날짜가 `None`인 위반·처분은 yearly에서 뺀다(penalty_count에서는 2015 이후 판정이 안 되므로 뺀다).
