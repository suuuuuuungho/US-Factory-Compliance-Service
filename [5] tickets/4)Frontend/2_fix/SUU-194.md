# SUU-194 fix(frontend): 답이 와도 빈 칸만 보이던 dockview 높이를 고친다

## 목표
답이 오면 Subparts·Checklist 패널이 실제 브라우저에서 보인다. (SUU-193 배포 후 빈 네모만 보였다.)

## 원인
dockview 루트(`.dv-shell`)는 `height: 100%`인데, 부모가 flex로 늘어난 칸이라 브라우저가 100%를 0px로 계산한다. jsdom 테스트는 크기를 재지 않아 못 잡았다. 배포 사이트에서 headless Chromium으로 재현·확인함.

## 건드릴 파일
- `[4]frontend/src/app/Workspace.tsx` — dockview 상자를 `relative`로 두고 `[&>div]:absolute [&>div]:inset-0`으로 dockview 루트를 꽉 채운다 (한 줄)
- `[4]frontend/tests/workspace.test.tsx` — 클래스 검사 1개 추가

## 안 하는 것
- 배치 로직·페이지 레이아웃 변경

## 완료 기준 ↔ 테스트
| 완료 기준 | 확인 |
|---|---|
| dockview 상자가 `relative` + `[&>div]:absolute [&>div]:inset-0` | `workspace.test.tsx` — `dockview 상자는 relative이고 dockview 루트를 absolute inset-0으로 꽉 채운다 (높이 0 방지)` |
| 실제 브라우저에서 답이 온 뒤 dockview 높이 > 0 | headless Chromium으로 로컬 dev 서버 확인: 0px → 402px, 세 패널 보임 |
