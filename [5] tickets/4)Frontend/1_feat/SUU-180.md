# SUU-180 feat(frontend): 카드 제목 띠만 색, 본문은 차콜

## 목표
후보 카드·Checklist 카드의 제목 줄(h2)만 gradient 색 배경이고, 카드 본문은 차콜(surface-1)이다.

## 건드릴 파일
- 고칠 것: `[4]frontend/src/app/page.tsx` — 후보/Checklist `<section>`·`<h2>`·`<ul>` className
- 바꿀 것: `[4]frontend/tests/color_cards.test.tsx`(SUU-174) 삭제 → `tests/card_title_band.test.tsx`로 교체

## 안 하는 것
- 기능·문구·API 호출 변경
- `globals.css`, `layout.tsx`, `TopNav.tsx`, `api.ts`
- SUU-175 가독성 클래스(`text-[22px] font-bold`, `space-y-3 leading-relaxed`, `<pre>`) 제거

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| 1번째 h2 `bg-gradient-violet`, 2번째 h2 `bg-gradient-magenta` | `card_title_band.test.tsx` > "후보 카드 제목 줄은 순서대로 violet, magenta 배경이다" |
| 후보 section에 `gradient-` 포함 클래스 없음 + `bg-surface-1` | "후보 카드 본문은 차콜이다" |
| Checklist h2 `bg-gradient-violet`, section `bg-surface-1`·gradient 없음 | "Checklist는 본문 차콜, 제목 줄만 보라다" |

## Codex 메모
- `STRIPES` 배열을 `border-gradient-*` → `bg-gradient-*`로 바꾸고 h2에 붙인다.
- 후보 section: `overflow-hidden rounded-lg border border-hairline bg-surface-1` (p-5·border-l-4 제거)
- 후보 h2: `px-5 py-3 text-[22px] font-bold leading-tight tracking-[-0.8px] text-ink ${STRIPES[i % 4]}`
- 후보 ul: `list-disc space-y-3 p-5 pl-10 leading-relaxed` (mt-3 → 카드 padding으로 이동)
- Checklist section: 후보와 같은 클래스, h2는 `bg-gradient-violet` 고정.
- SUU-172 `framer_style.test.tsx`가 후보 section에 `bg-surface-1 border-hairline rounded-lg`를 요구하므로 유지.
- 확인: `npm test` 25개 초록, `npm run build` 성공.
