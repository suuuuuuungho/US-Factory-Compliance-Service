# SUU-214 feat(frontend): 질문 칸을 react-bits PromptBar로 바꾼다

## 목표
/applicability 질문 칸(textarea + Ask 버튼)을 react-bits PromptBar(TS-CSS)로 바꾼다. 글을 쓰고 Send(↑)를 누르면 지금처럼 POST /ask.

## 건드릴 파일
- 만들 것 `[4]frontend/components.json` — shadcn CLI 설정 (`@react-bits` 레지스트리)
- 만들 것 `[4]frontend/src/components/PromptBar.tsx`, `PromptBar.css` — `npx shadcn@latest add @react-bits/PromptBar-TS-CSS` 가 받은 그대로. 손대지 않음
- 고칠 것 `[4]frontend/package.json` — motion, @hugeicons/react, @hugeicons/core-free-icons
- 고칠 것 `[4]frontend/src/app/applicability/page.tsx` — `form` 을 `<PromptBar sources=[] commands=[] models=[] efforts=[] busy={loading} onSend={...} width=... />` 로. onSubmit 은 `submit(text)` 로
- 고칠 것 옛 테스트: `applicability_page`, `ask_inline_form`, `framer_style`, `page`, `memo_pane` 등 — "Ask" 버튼 → 글 쓰고 "Send" 버튼. SUU-196/197 의 textarea·Ask 배치 검사는 PromptBar 가 대신하므로 뺌

## 안 하는 것
- @ 소스 / 명령 / 모델 / 효과 메뉴 (전부 빈 배열), 받아쓰기, 첨부
- 답 뒤 Workspace 네 칸 배치, Subparts·Checklist·Memo
- PromptBar 원본 코드 수정

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 (`prompt_bar_ask.test.tsx`) |
|---|---|
| `.prompt-bar` 있고 Ask 버튼 없음 | `/applicability 에 PromptBar(.prompt-bar)가 있고 Ask 버튼은 없다` |
| Send 누르면 그 글로 POST /ask, 답 표시 | `글을 쓰고 Send 를 누르면 그 글로 POST /ask 하고 답이 보인다` |

## 메모
- PromptBar 의 textarea 는 `aria-label="Prompt"`, 보내기 버튼은 `aria-label="Send"`(busy 면 "Stop"). 글이 비어 있으면 버튼이 disabled 라 테스트는 먼저 글을 써야 한다
- `+` 버튼은 항상 보인다(빈 메뉴). 원본을 안 고치기로 해서 남겨 둔다
- PromptBar 는 자기 상태(draft)를 가지므로 page 의 `question` state 는 없앤다
