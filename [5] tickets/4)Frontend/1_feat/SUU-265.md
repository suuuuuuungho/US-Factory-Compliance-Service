# SUU-265 feat(frontend): About 차트 수치를 출처와 함께 JSON으로 제공

## 목표
About 페이지(SUU-266)가 쓸 숫자를 `[4]frontend/public/about-stats.json` 한 파일에 모으고, 숫자마다 `source`(출처)를 붙인다.

## 건드릴 파일
- 만들 것: `[4]frontend/scripts/make_about_stats.py` — DB(연도별 2개)와 `public/echo-stats.json`을 읽고, 나머지 고정 숫자는 코드 안 표에서 가져와 JSON을 쓴다
- 만들 것: `[4]frontend/public/about-stats.json` — 위 스크립트로 생성
- 테스트(수정 금지): `[4]frontend/tests/about_stats.test.tsx`

## 안 하는 것
- About 화면(`src/app/about/**`), 기존 테스트 수정 — SUU-266
- `echo-stats.json`, `src/components/charts/**`, DB 스키마 수정
- `[1] docs/1) project/1_project.md` 커밋 (사람이 따로 정리 중인 파일)

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| 모든 숫자에 비어 있지 않은 `source` | `about-stats.json의 모든 숫자에 비어 있지 않은 source가 있다` |
| 연도별 규칙 개정 합 136, 연도별 판정서한 + 날짜 모름 = 1,127 | `연도별 규칙 개정을 더하면 136, …` |
| 과징금·위반 숫자 = echo-stats.json | `과징금·위반 숫자가 echo-stats.json summary와 같다` |

### series
- `rule_changes_by_year.data`: `[{year, count}]` 2018~2025, 8줄. DB `fr_document`에서 `type_raw = 'Rule'`, `scope_status = 'part63_list'`, `publication_date` 연도별 count. **현재 release만** (`common_dataset_current`). 2026-09-23 확인값: 19, 13, 43, 6, 15, 8, 19, 13 = 136
- `letters_by_year.data`: `[{year, count}]` 오름차순 + `letters_by_year.unknown`(날짜 모름 수). 현재 ADI release(`common_dataset_current` dataset `adi`, 2026-09-23 기준 `5cc370d0-…`)의 `adi_source_entry` 중 `scope_status = 'part63_candidate'` 1,127건
  - ADI(995): `letter_date_raw`('MM/DD/YYYY')의 연도. `12/30/1899`는 엑셀 빈 날짜 → unknown (6건)
  - CAA Dashboard(132): `letter_date_raw`가 비어 있다. `adi_entry_document` → `adi_document_version.signed_on` 연도. 없으면 unknown
  - 합계 + unknown ≠ 1,127 이면 **JSON을 쓰지 말고 멈춰서 사람에게 알린다**
- `penalty_by_subpart.data`: `[{code, desc, penalty_total_usd}]` echo-stats.json `subparts`에서 `penalty_total_usd` 큰 순 상위 10
- `rag_ndcg_steps.data`: `[{step, ndcg}]` = baseline 0.264 → Kanon 2 + context 0.437 → reranker 0.561 → rules 0.631 → LLM rerank 0.692 (3_rag §4)
- `rag_funnel.data`: `[{stage, count}]` = chunks 5625 → candidates 150 → reranked 20 → sent to model 10 (3_rag §6, 4_rag SUU-152)

### 주의
