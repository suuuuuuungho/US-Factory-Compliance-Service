# SUU-204 feat(frontend): 글꼴을 SF Pro로 바꾸고 상단 제목을 굵게

## 목표
사이트 글꼴을 Google Inter → Apple SF Pro(로컬 woff2)로 바꾸고, 상단바 제목을 굵게.

## 건드릴 파일
- 만들 것 `[4]frontend/src/app/fonts/SF-Pro-latin.woff2` — `SF-Pro.dmg`의 가변 `SF-Pro.ttf`에서 fonttools로 wght 400~700 만 남기고(wdth·opsz 고정) 라틴 글자만 잘라 woff2로. 60KB
- 고칠 것 `[4]frontend/src/app/layout.tsx` — `next/font/google` Inter → `next/font/local` (`variable: "--font-sf-pro"`, `weight: "400 700"`)
- 고칠 것 `[4]frontend/src/app/globals.css` — `--font-sans: var(--font-sf-pro)`
- 고칠 것 `[4]frontend/src/app/TopNav.tsx` — 제목 `font-medium` → `font-bold`
- 고칠 것 `[4]frontend/.gitignore` — `*.dmg` (218MB 원본은 커밋 금지)
- 고칠 것 `[4]frontend/tests/topnav_hero.test.tsx` — mock 대상 `next/font/google` → `next/font/local`

## 안 하는 것
- 다른 페이지의 글자 크기·굵기
- 한글 글리프 (라틴만 포함. 한글은 시스템 폰트로 fallback)
- SF Pro Display / Rounded / Text 정적 파일 (가변 하나로 충분)

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 (`sf_pro_font.test.tsx`) |
|---|---|
| layout 이 next/font/local + SF Pro, Inter 없음 | `layout.tsx 는 next/font/local 로 SF Pro 를 쓰고 Inter(next/font/google) 는 없다` |
| `--font-sans` 가 `--font-sf-pro` | `globals.css 의 --font-sans 는 --font-sf-pro 를 가리킨다` |
| 제목 링크 font-bold | `상단바 제목 링크에 font-bold 가 있다` |
| woff2 존재, 200KB 이하 | `fonts/SF-Pro-latin.woff2 가 있고 200KB 이하다` |

## 메모
- Apple SF Pro 라이선스는 Apple 플랫폼용 앱 디자인 용도. 공개 서비스로 갈 때 재검토
- 폰트 만들기: 7-Zip으로 dmg → pkg → Payload → cpio 순으로 풀면 `SF-Pro.ttf`(21MB). fontTools `instancer`로 축 고정 후 `subset` (Apple AAT 테이블 `morx/kerx/feat/ankr/trak/bsln/ltag/meta` 는 drop). instancer 결과를 파일로 저장했다가 다시 열어야 gvar subset 에러가 안 남
