# SUU-175 feat(frontend): 결과 글이 커지고 줄 간격이 넓어진다

## 목표
카드 제목은 headline(22px/700), 기준 목록은 줄 간격이 넓고, 옆 패널 조문은 body 크기로 읽기 편하다.

## 건드릴 파일
- 고칠 것: `[4]frontend/src/app/page.tsx` — className만

## 안 하는 것
- 기능·문구·API 호출 변경
- `globals.css`, `layout.tsx`, `TopNav.tsx`, `api.ts`
- 새 컴포넌트·새 파일
- `tests/` 수정

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| 후보 카드 h2에 `text-[22px]`, `font-bold` | `readable_text.test.tsx` > "후보 카드 제목은 headline 크기다" |
| 후보 카드 안 기준 `<ul>`에 `leading-relaxed`, `space-y-3` | `readable_text.test.tsx` > "기준 목록은 줄 간격이 넓다" |
| 옆 패널 `<pre>`에 `text-base`, `leading-relaxed` | `readable_text.test.tsx` > "옆 패널 조문은 body 크기다" |

## Codex 메모
- 테스트는 `classList.contains`로 **정확한 클래스 이름**을 본다. 아래 이름 그대로.
- `page.tsx` 위치와 바꿀 클래스:
  - 후보 카드 `<h2>` (`Subpart {c.subpart} — {c.title}`): `font-semibold` → `text-[22px] font-bold leading-tight tracking-[-0.8px] text-ink`
  - 후보 카드 기준 `<ul>`: `list-disc pl-6` → `mt-3 list-disc space-y-3 pl-6 leading-relaxed`
  - 인용 `<button>`/`<span>`: `mr-2 text-sm ...` 앞에 `mt-1 block` 추가 (인용을 다음 줄로). 기존 `text-accent-blue`/`underline`은 유지 (SUU-172 테스트).
  - Checklist `<h2>`와 `<ul>`도 같은 클래스로 맞춘다 (테스트는 안 보지만 통일).
  - 옆 패널 `<pre>`: `whitespace-pre-wrap font-sans text-sm` → `whitespace-pre-wrap font-sans text-base leading-relaxed text-ink`
  - 옆 패널 `<h2>`: `font-semibold` → `mb-3 text-[22px] font-bold leading-tight tracking-[-0.8px]`
- `within(card).getByRole("list")`가 후보 카드 안 `<ul>` 하나를 찾는다 — 카드 안에 `<ul>`을 더 만들지 말 것.
- 확인: `[4]frontend`에서 `npm test` 24개 전부 초록, `npm run build` 성공.
