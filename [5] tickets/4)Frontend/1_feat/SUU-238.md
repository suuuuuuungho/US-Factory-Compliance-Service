# SUU-238 feat(frontend): FR diff를 한 화면 스크롤로, 목록은 숨기고 뒤로가기

## 목표
FR 문서를 클릭하면 목록 표는 사라지고 diff 만 한 스크롤 영역에 이어서 보인다. 위에 고정된(sticky) 머리글이 지금 보고 있는 조항(§)으로 바뀐다. 뒤로가기 아이콘 하나로 목록으로 돌아간다.

## 건드릴 파일
- 고칠 것 `[4]frontend/src/app/federal-register/page.tsx` — 선택 시 목록 숨김 + 뒤로가기 버튼
- 고칠 것 `[4]frontend/src/components/FrDiff.tsx` — 섹션 카드 여러 개 → 스크롤 영역 하나 + sticky 머리글

## 안 하는 것
- 목록 표 모양·diff 계산 변경
- URL 라우팅(뒤로가기는 상태만 바꾼다)

## 완료 기준 ↔ 테스트
테스트 파일: `[4]frontend/tests/fr_diff_scroll.test.tsx`. 기존 `fr_list_view.test.tsx` 의 "행 클릭" 테스트는 목록이 사라지는 쪽으로 고친다.

| 완료 기준 | 테스트 함수 |
|---|---|
| 행 클릭 → 목록 없음, diff 있음, `aria-label="뒤로"` 버튼 있음. 뒤로 클릭 → 목록 다시, diff 없음 | `행 클릭하면 목록이 사라지고, 뒤로 버튼으로 돌아온다` |
| diff 안에 `[data-diff-scroll]` 하나, 섹션마다 `[data-diff-section]`, 카드 클래스 없음 | `섹션이 카드가 아니라 스크롤 영역 하나에 이어진다` |
| 머리글 `[data-diff-current]` 처음엔 첫 §, 스크롤로 둘째 섹션이 위로 오면 둘째 § | `스크롤하면 머리글이 지금 보이는 조항으로 바뀐다` |

## Codex 메모
Claude가 직접 구현·merge (사용자 지시).
- 머리글은 스크롤 영역 안 `sticky top-0`. 스크롤 이벤트에서 `getBoundingClientRect` 로 머리글 아래를 지난 마지막 섹션을 고른다
- 스크롤 영역 높이 `max-h-[calc(100vh-12rem)]` 정도, `overflow-y-auto`
