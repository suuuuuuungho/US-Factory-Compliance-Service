# SUU-184 feat(frontend): Subpart 카드 하나로 합치고 칸 안에서 스크롤

## 목표
2행 세 칸이 화면 높이에 딱 맞고 카드 안에서 스크롤된다. Subpart는 카드 하나 안에 보라 제목 띠가 후보마다 있다.

## 건드릴 파일
- `[4]frontend/src/app/page.tsx` — 구조·className만

## 안 하는 것
- 기능·API·문구, `layout.tsx`, `globals.css`
- 모바일(<md)은 지금처럼 세로 쌓임 + 페이지 스크롤

## 왜 바꾸나
`max-h-[calc(100vh-22rem)]`은 위쪽 높이를 어림잡은 값이라 실제(상단바+제목+폼 ≈ 460px)보다 작다. 페이지가 같이 늘어나서 칸 스크롤이 안 보인다. 어림잡지 말고 `main`을 `100dvh − 60px(상단바)`로 고정하고 2행이 남은 높이를 전부 쓴다.

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| Subparts 칸 안 `bg-surface-1` 카드 1개, 그 안에 Subpart h2 후보 수만큼, 전부 `bg-gradient-violet` | `single_subpart_card.test.tsx` > "Subpart는 카드 하나 안에 보라 제목 띠가 여러 개다" |
| Subpart 카드·Checklist 카드·조문 aside 모두 `overflow-y-auto` + `min-h-0` | "세 카드 모두 카드 안에서 스크롤된다" |
| `main` `md:h-[calc(100dvh-60px)]`, grid `md:grid-rows-[auto_minmax(0,1fr)]`, 세 칸 `min-h-0` | "2행이 화면 남은 높이를 다 쓴다" |
