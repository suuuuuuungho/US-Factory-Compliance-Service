## Codex 메모

### 지금 코드
`page.tsx`는 이미 `fetch("/fr-diff.json")` → `documents` state → `selectedDocument` state → `<FrDiff document={…} />` 구조다. 데이터 흐름은 그대로 두고 **JSX만** 바꾼다. `FrDiffDocument` 타입은 `FrDiff.tsx`에서 import 한다 (`sections[].node_key`는 `string`이지만 실제 데이터에 `null`이 섞여 있으니 `?.` 로 다룬다).

### 표 (DOM 계약 — 테스트가 이걸 본다)
- 감싸는 요소에 `data-pane="list"`. 선택 전에는 클래스에 `mx-auto`가 **있고**, 선택 후에는 **없다**
- 진짜 `<table>` / `<thead><th>` / `<tbody><tr><td>` 를 쓴다 (`role=columnheader`, `row`, `cell` 자동)
- `<th>` 글자 순서: `연번`, `Subpart`, `제목`, `개정일`, `변경`
- `<td>` 순서도 같다. 연번 = index+1
- 제목 칸 안에 `<button type="button">{document.title}</button>` — 기존 테스트가 `getByRole("button", { name: /제목/ })` 로 찾는다. 행(`<tr>`) 전체에 onClick 을 달아도 되지만 button 은 꼭 있어야 한다
- Subpart: `document.sections.map(s => s.node_key?.split("/")[2]?.replace("subpart-", ""))` → 빈 값 제거 → 중복 제거(등장 순서 유지) → `", "` 로 join. 비어 있으면 `—`
- 개정일: `document.effective_date ?? "—"`
- 변경 칸: `<span className="… text-semantic-success">+{added}</span>` 와 `<span className="… text-gradient-coral">−{removed}</span>` 를 **따로 span**으로. 마이너스는 `−`(U+2212). 테스트는 `getByText("+3")`, `getByText("−1")` 로 정확히 그 글자만 있는 요소를 찾으니 span 안에 다른 글자를 섞지 않는다
- diff 없는 문서(`document.reason` 있음): `<tr>` 클래스에 `text-ink-muted`. 클릭은 그대로 되고 `FrDiff`가 "변경 본문 없음" 을 보인다
- 선택된 행은 배경을 살짝 (예: `bg-surface-1`) — 테스트는 안 본다

### diff 영역
- `selectedDocument`가 있을 때만 `<section data-pane="diff" aria-live="polite"><FrDiff document={selectedDocument} /></section>` 을 렌더한다. 없으면 **DOM에 없어야** 한다 (지금은 빈 section 이 항상 있음 → 지운다)

### 레이아웃
- 선택 전: `<div data-pane="list" className="mx-auto w-full max-w-4xl">`
- 선택 후: 부모를 `grid lg:grid-cols-[minmax(20rem,28rem)_1fr] gap-6` 로, list 는 `mx-auto` 없이 왼쪽 열
- 왼쪽으로 "빠지는" 느낌은 `transition-all duration-300` 정도만. 애니메이션 라이브러리 추가 금지
- 색·폰트는 기존 토큰만 (`text-ink`, `text-ink-muted`, `border-hairline`, `bg-surface-1`, `text-semantic-success`, `text-gradient-coral`). `FrDiff.tsx`·`applicability/page.tsx` 쓰는 법을 따른다
