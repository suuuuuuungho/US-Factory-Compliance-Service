# SUU-198 feat(frontend): Memo 버튼으로 화면을 나눠 메모를 쓰고 저장한다

## 목표
`Subparts` `Checklist` 버튼 오른쪽에 `Memo` 버튼. 누르면 페이지가 좌·우 2분할된다.
왼쪽 = 질문 폼 + Workspace(기존 그대로), 오른쪽 = 메모 pane(제목 + 본문 + Save + 저장 기록).

## 건드릴 파일
- `[4]frontend/src/app/MemoPane.tsx` — 새 파일. 제목·본문 입력, Save, 저장 기록 목록. localStorage `applicability-memos`에 `{title, body, savedAt}[]` 저장. 기록 항목을 누르면 편집칸에 다시 불러온다
- `[4]frontend/src/app/Workspace.tsx` — 버튼 줄에 `toolbar?: ReactNode` 슬롯. FIXED 버튼 다음에 그린다
- `[4]frontend/src/app/applicability/page.tsx` — `memoOpen` state. 질문 폼+Workspace를 왼쪽 열로 묶고, 열리면 오른쪽에 `<MemoPane>`. Workspace의 toolbar에 `Memo` 토글 버튼(`aria-pressed`)
- `[4]frontend/tests/memo_pane.test.tsx` — 검사 5개

## 안 하는 것
- Supabase 저장, 삭제, 질문·답과 메모 연결, dockview 패널로 넣기(질문 폼까지 왼쪽으로 가야 하므로 페이지 단위 분할)

## 완료 기준 ↔ 테스트
| 완료 기준 | 확인 |
|---|---|
| 답이 오면 Subparts·Checklist 오른쪽에 Memo 버튼, pane은 아직 없음 | `Memo 버튼은 Checklist 오른쪽에 있고, 누르기 전엔 메모 pane이 없다` |
| 누르면 오른쪽에 pane(aria-label "Memo"), 질문 폼은 왼쪽 열에 | `Memo를 누르면 2분할: 왼쪽 열에 질문 폼, 오른쪽에 메모 pane` |
| 제목+본문 쓰고 Save → 기록에 제목·시각, localStorage에 저장 | `Save하면 기록 목록에 제목과 시각이 남고 localStorage에도 저장된다` |
| 기록 항목 클릭 → 편집칸에 다시 채워짐 | `기록 항목을 누르면 그 메모가 편집칸에 불려온다` |
| Memo 다시 누르면 pane 닫힘 | `Memo를 다시 누르면 pane이 닫힌다` |
