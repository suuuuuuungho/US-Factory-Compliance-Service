## Codex 메모

### 1. 데이터 고침 (먼저)
- 현재 `letters_by_year.unknown = 138`: CAA Dashboard 132건 날짜를 못 가져옴 → 2021~2025가 비어 차트가 "질문이 줄었다"로 보인다
- Dashboard 132건 날짜는 `public/decision-letters.json` `letters[].date`(전부 있음, 2020~2025)와 `source_key`로 맞추거나, `adi_entry_document → adi_document_version.signed_on` join을 고친다
- ADI `letter_date_raw = '12/30/1899'`(엑셀 빈 날짜) 6건만 `unknown`
- 1993년 전은 `data`에서 빼고 `letters_by_year.before_1993`(숫자)로. `sum(data) + before_1993 + unknown = 1127`
- 1,127 자체가 안 맞게 되면 멈추고 사람에게 알린다

- 각 h2는 자기 `<section>` 안에 둔다 (RAG 테스트가 `closest("section")`을 본다)
- 큰 숫자: `<span data-stat="키" data-value={String(stats[키].value)}>표기</span>`. 핵심 16개(테스트 목록)는 반드시. `data-stat`을 단 요소의 `data-value`는 JSON 원값 그대로
- 숫자 옆 작은 출처: `stats[키].source` 또는 조문 라벨
- 차트 요소 순서 = 위 표 순서(DOM 순서를 테스트가 본다). 각 `data-chart` 요소 안에 `svg`가 있어야 한다

### 3. 기술 메모
- JSON은 `import aboutStats from "../../../public/about-stats.json"` 정적 import (fetch 아님). page는 server component, 차트만 `"use client"` 파일로 분리
- bklit 부품: `src/components/charts/` (bar-chart, bar, bar-x-axis, area-chart, area, bar-squares, grid, tooltip). 사용 예 `src/app/echo/page.tsx`, `src/components/YearLineChart.tsx`
- 테스트는 ResizeObserver를 600×300으로 속인다 (echo_dashboard.test.tsx와 같음)
- 서체: 제목·큰 숫자·인용구 `font-serif`(New York), 본문 기본(SF Pro). 디자인 토큰은 `[4]frontend/DESIGN.md`
- 모바일 폭에서 가로 스크롤 없게
