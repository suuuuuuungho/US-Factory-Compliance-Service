# SUU-267 feat(frontend): About 차트를 bklit으로, 출처를 공개 출처로 교체

## 목표
About 차트 10개를 bklit 부품으로 다시 그리고, 화면 출처를 사용자가 찾아볼 수 있는 영어 공개 출처(`cite`)로 바꾼다.

## 건드릴 파일
- 고칠 것: `[4]frontend/src/app/about/page.tsx` — 직접 그린 차트 SVG 제거, `source` 대신 `cite` 표시
- 만들 것: `[4]frontend/src/app/about/` 아래 `"use client"` 차트 파일 (예: `AboutCharts.tsx`)
- 추가할 것: `npx shadcn add @bklit/funnel-chart`, `npx shadcn add @bklit/ring-chart` → `src/components/charts/`
- 고칠 것: `[4]frontend/scripts/make_about_stats.py` — 모든 stats·series에 `cite` 추가. 스크립트를 다시 돌려 `public/about-stats.json` 재생성
- 테스트(수정 금지): `tests/about_bklit.test.tsx`(새로), `tests/about_stats.test.tsx`(cite 추가), `tests/about_page.test.tsx`(차트 테스트에 waitFor만 추가)

## 안 하는 것
- 글·h2·숫자·섹션 순서 변경 (about_page 테스트 그대로 통과해야 함)
- 기존 `src/components/charts/**` 파일 수정. shadcn add가 **기존 파일을 덮어쓰자고 물으면 No**. 새 파일 추가만
- about-stats.json 숫자·`source` 변경. `cite`만 추가
- 다른 페이지, `[1] docs/1) project/1_project.md` 커밋

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| 타임라인 뺀 차트 10개가 bklit 부품, 직접 그린 svg 없음 | `타임라인을 뺀 차트 10개는 bklit 부품으로 그리고…` (about_bklit) |
| 화면 출처 = cite, 내부 이름·한글 없음 | `화면 출처는 about-stats.json의 cite이고…` (about_bklit) |
| JSON 모든 항목에 정해진 cite, source 유지 | `모든 숫자에 화면용 영어 cite가 있고…` (about_stats) |
| 기존 About 테스트 그대로 통과 | `about_page.test.tsx` 전체 |

## Codex 메모

### 1. 차트 ↔ bklit 부품
| data-chart | 부품 | 모양 |
|---|---|---|
| obligation-timeline | 직접 SVG (예외, 그대로) | 5년 타임라인 |
| corpus-size | `BarChart` orientation="horizontal" | tokens_max vs llm_context |
| rule-changes-by-year | `BarChart` (xDataKey="year") | 2018~2025 |
| sections-changed | `RingChart` 또는 `BarChart`+`BarSquares` | 45% |
| epa-wait | `BarChart` horizontal | 24h · 48h · 138일 |
| letters-by-year | `BarChart` (xDataKey="year") | 1993~2025 |
| violation-share | `RingChart` 또는 `BarChart`+`BarSquares` | 27.9% |
| penalty-by-subpart | `BarChart` horizontal | 상위 10 (echo/page.tsx 300줄 참고) |
| rag-ndcg-steps | `BarChart` | 0.264 → 0.692 |
| rag-funnel | `FunnelChart` | 5,625 → 150 → 20 → 10 |
| rag-scores | `RingChart` | 96.1 · 99.6 |

- `AreaChart`·`LineChart`는 x축이 날짜 전용이라 연도 라벨이 안 나온다 (`src/components/YearLineChart.tsx` 주석). 연도 차트는 `BarChart`를 쓴다. `@bklit/line-chart`는 기존 파일(time-series-chart-shell 등)을 덮어쓰므로 설치하지 않는다
- import 경로는 반드시 `@/components/charts/<이름>` (테스트가 이 경로를 가로채서 확인한다)
- 차트 `<figure data-chart>` 안에서 `<svg>`는 bklit 부품만 그린다. 제목·출처는 svg 밖 HTML로
- 사용 예: `src/app/echo/page.tsx` (BarChart, Bar, BarXAxis, 가로 막대)
- bklit은 크기를 잰 뒤 SVG를 그린다(비동기). 테스트는 waitFor로 기다린다

### 2. cite (화면용 출처, 영어)
`stats.<key>.cite`, `series.<key>.cite` 문자열. 값은 `tests/about_stats.test.tsx`의 `STAT_CITE`, `SERIES_CITE`와 글자까지 같게.

| key | cite |
|---|---|
| part63_pages | 40 CFR Part 63 (eCFR / govinfo PDF) |
| part63_words, part63_tokens_min/max | Our count of the 40 CFR Part 63 text |
| llm_context_tokens | Published context limits of leading AI models |
| rule_changes, rule_changes_by_year | Federal Register, final rules amending 40 CFR Part 63, 2018–2025 |
| sections_changed, sections_changed_pct | Sections of 40 CFR Part 63 amended by those rules, 2018–2025 |
| epa_median_days, epa_over_6mo_pct, epa_letters_sample | EPA Applicability Determination Index, 235 Part 63 letters |
| letters_total, letters_by_year | EPA Applicability Determination Index + CAA Applicability Determinations Dashboard |
| prison_years | Clean Air Act §113(c)(2), 42 U.S.C. 7413(c)(2) |
| violation_pct, facilities, penalty_*, penalty_by_subpart | EPA ECHO enforcement data, 2015– |
| rag_*, rag_ndcg_steps, rag_funnel | Our evaluation on 102 real EPA applicability questions |

- 페이지에서 `source`는 어디에도 보여주지 않는다. `Stat`의 작은 글씨·`Chart`의 "Source:" 모두 `cite`로
- 페이지 글자 전체에 한글, `.md`, `.json`, `DB`, `SUU-숫자`, `fr_document`, `adi_source_entry`가 없어야 한다 (bklit 차트 라벨·툴팁 포함)
- 스크립트 재실행이 DB 접속 문제로 안 되면, JSON에 `cite`만 손으로 넣지 말고 멈추고 알린다
