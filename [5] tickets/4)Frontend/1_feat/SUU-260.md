# SUU-260 feat(frontend): Decision Letter 표 열 경계 끌어 너비 조절

## 목표
`/decision-letter` 표의 머리글 오른쪽 경계를 마우스로 끌면 그 열이 넓어지거나 좁아진다. 외부 라이브러리 없이.

## 건드릴 파일
- 고칠 것 `[4]frontend/src/app/decision-letter/page.tsx` — `<colgroup>` 추가, 열 너비 state, `<th>` 마다 드래그 손잡이
- 이미 있음 `[4]frontend/tests/decision_letter_col_resize.test.tsx` — 테스트 4개

## 안 하는 것
- 너비 저장 (localStorage 등). 새로고침하면 초기값
- 더블클릭 자동 맞춤, 터치(pointer) 이벤트
- `federal-register/page.tsx`, 공용 컴포넌트로 빼기
- `tests/` 아래 수정·삭제

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| `<th>` 6개 안에 각각 `[data-resize-handle]` 요소, `<colgroup>` 안에 `<col>` 6개 | `머리글마다 data-resize-handle 손잡이가 있고 열마다 <col> 이 있다` |
| 손잡이 mousedown(clientX 100) → document mousemove(180) → mouseup 하면 그 `<col>` 의 `style.width` 가 처음보다 80px 큼 | `Facility 손잡이를 +80px 끌면 Facility <col> 너비가 80px 늘어난다` |
| 왼쪽으로 아무리 끌어도 `style.width` 는 `60px` | `아무리 왼쪽으로 끌어도 60px 아래로는 줄지 않는다` |
| mouseup 뒤 mousemove 는 무시 (리스너 해제) | `mouseup 뒤에 mousemove 해도 너비가 더 안 바뀐다` |

## Codex 메모
- 열 순서: `#`, `Facility`, `Title`, `Subpart`, `Date`, `PDF` (index 0~5). 테스트는 Facility(index 1)만 끈다.
- state: `const [widths, setWidths] = useState<number[]>([48, 180, 480, 120, 110, 90])` 처럼 **px 숫자 배열**. jsdom 은 레이아웃이 없어서 처음 너비를 DOM 에서 읽을 수 없다 → 초기값은 반드시 state 상수로.
- `<table>` 에 `table-fixed` 를 붙이고 `<colgroup>{widths.map((w, i) => <col key={i} style={{ width: `${w}px` }} />)}</colgroup>` 로 적용. 테스트는 `col.style.width` 를 `parseFloat` 하니 `"260px"` 형식이어야 한다.
- 손잡이: 각 `<th>` 를 `relative` 로 두고 안에 `<span data-resize-handle onMouseDown={...} className="absolute top-0 right-0 h-full w-1.5 cursor-col-resize select-none hover:bg-hairline" />`. 6개 모두.
- 드래그 로직 (라이브러리 없이):
  ```ts
  const MIN_WIDTH = 60;
  function startResize(index: number, event: React.MouseEvent) {
    const startX = event.clientX;
    const startWidth = widths[index];
    const onMove = (e: MouseEvent) =>
      setWidths((prev) => prev.map((w, i) => (i === index ? Math.max(MIN_WIDTH, startWidth + e.clientX - startX) : w)));
    const onUp = () => {
      document.removeEventListener("mousemove", onMove);
      document.removeEventListener("mouseup", onUp);
    };
    document.addEventListener("mousemove", onMove);
    document.addEventListener("mouseup", onUp);
  }
  ```
  테스트는 `fireEvent.mouseMove(document, …)` 를 쓰므로 리스너는 **`document`** 에 단다 (window 도 버블링으로 받지만 document 가 안전).
- `table-fixed` 가 되면 셀 너비는 `<col>` 이 정한다. SUU-259 의 Facility `max-w-[180px]` 는 더 이상 효과가 없지만 **지우지 말 것** (`decision_letter_col_width.test.tsx` 가 클래스를 검사한다). Title 의 `w-full max-w-0` 도 그대로 둔다.
- `table-fixed` 에서 `whitespace-nowrap` 셀(#, Subpart, Date, PDF)은 너비보다 글자가 길면 옆 칸으로 삐져나온다. `<td>` 에 `overflow-hidden` 을 추가해 잘리게 한다.
