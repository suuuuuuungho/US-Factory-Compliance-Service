# SUU-203 feat(frontend): 랜딩 글자·Start 없애고 판화풍 미국 국기를 넣는다

## 목표
`/` 히어로에서 h1·설명문·Start 버튼을 없애고, 우측 상단 어두운 하늘 위에 크고 자연스러운 판화(etching) 스타일의 물결치는 미국 국기 그림을 얹는다. 공장 에칭 배경·연기(SUU-201)는 그대로.

## 건드릴 파일
- 만들 것 `[4]frontend/public/flag-etching.png` — OpenAI 이미지 API(`gpt-image-1`)로 생성. **투명 배경(alpha) 필수**. 폭 1536px 이하, 500KB 이하(필요하면 Pillow로 줄이거나 pngquant). 커밋한다
- 만들 것 `[4]frontend/scripts/make_flag_etching.py` — 이미지 생성 스크립트 (프롬프트·크기·저장 경로를 코드로 남긴다. `OPENAI_API_KEY` 는 env에서 읽는다)
- 고칠 것 `[4]frontend/src/app/page.tsx`
  - `z-30` 글자 묶음(h1, p, Start `Link`) 삭제. `next/link` import 도 삭제
  - `next/image` 로 `<Image src="/flag-etching.png" alt="Etched American flag" width={...} height={...} priority className="absolute top-0 right-0 z-20 ... pointer-events-none select-none" />` 추가. `bg-canvas/60` 레이어(z-10)와 연기 위, 우측 상단
  - 크기: 데스크톱에서 화면 폭의 ~1/3 (`md:w-[34vw] max-w-[600px] h-auto`), 모바일은 `w-[60vw]`. 사진의 우측 상단 어두운 하늘을 채우되 냉각탑(오른쪽, y≈50%~)은 가리지 않는다
- 테스트(이미 있음, 수정 금지): `[4]frontend/tests/hero_flag_etching.test.tsx`

## 안 하는 것
- 애니메이션(국기는 정지된 물결 모양). CSS·JS 흔들기 금지
- 상단바(TopNav), 다른 페이지, `hero-etching.png`, `HeroSmoke`, `globals.css`
- npm 패키지 추가
- `tests/` 수정

## 이미지 프롬프트 (OpenAI gpt-image-1)
```
A waving American flag rendered as a fine-line copperplate etching / engraving,
in the style of a banknote or 19th-century intaglio print. White ink lines only,
no color, on a fully transparent background. Frozen mid-ripple with deep folds,
thin horizontal cross-hatching that follows the curves of the cloth; stars and
stripes readable but loose. Elegant, restrained, museum quality. No text, no frame,
no border, no pole, no watermark. The flag's left (hoist) edge and bottom edge
dissolve softly into transparency so it can sit over a dark night sky.
```
- `size="1536x1024"`, `quality="high"`, `background="transparent"`, `output_format="png"`
- 생성 결과가 검정 배경으로 나오면 다시 만든다. 투명이 아니면 사진 위에서 네모 상자처럼 보여 억지스럽다

## Codex 메모
- 현재 `page.tsx`: section `relative overflow-hidden`, 그 안에 `Image fill`(공장) → `div z-10 bg-canvas/60` → `HeroSmoke` 2개 → `div z-30`(글자). 글자 div 만 지우고 국기 `Image` 를 넣는다
- 공장 사진(`public/hero-etching.png`, 1600×880)의 우측 상단 약 55%×45% 영역이 어두운 하늘. 국기는 여기에 얹는다. 왼쪽 굴뚝(x≈14%, 29%)과 오른쪽 냉각탑(y≈50% 아래)은 가리지 않는다
- `next/image` 는 jsdom에서 `<img>` 로 렌더되고 `className` 이 그대로 붙는다. `fill` 대신 `width/height` 를 쓰면 부모 `relative` 는 이미 있으니 추가 작업 없음
- 흰 선이 `bg-canvas/60` 위에서 너무 튀면 `opacity-90` 정도로 살짝 눌러 사진과 톤을 맞춘다. 사진의 가로 해칭 결과 어울리도록 국기도 가로 해칭 위주
- 이미지 생성: `from openai import OpenAI; client.images.generate(model="gpt-image-1", prompt=..., size="1536x1024", quality="high", background="transparent", output_format="png")` → `b64_json` 디코드 → 저장. 500KB 넘으면 Pillow `quantize` 또는 폭 1200px 로 줄인다
- 테스트는 `[4]frontend` 에서 `npm test`. 빌드 `npm run build`. `next/image` 는 로컬 `/public` 파일이라 도메인 설정 불필요
- PR 본문에 미리보기 스크린샷(데스크톱·모바일) 첨부. "자연스러운가"는 사람이 본다
