# SUU-249 feat(frontend): ECHO 연도별 차트를 꺾은선으로, 지도는 맨 아래 넓게

## 목표
- "Violations and penalty actions by year", "Penalty dollars by year" 두 개를 막대 → **꺾은선**
- 주별 지도 카드를 5개 중 **맨 아래, 2열 폭**

## 왜 직접 그렸나
Bklit `AreaChart` 는 x 가 날짜(Date) 전용이고 눈금·툴팁 글자가 `Jan 1` 식으로 고정되어 있어 연도가 안 나온다. `src/components/charts/**` 는 안 고치기로 했으니 이미 깔린 `@visx/shape`(LinePath)·`@visx/scale`·`@visx/curve` 로 작은 `YearLineChart` 를 만들었다.

## 건드릴 파일
- 새로 `[4]frontend/src/components/YearLineChart.tsx` — 600×300 viewBox. 숫자 y 눈금 4개(점선), 5년 단위 x 눈금, 선마다 `path[data-series]`, 선이 2개 이상이면 범례, 마우스 위치의 해를 세로선·점으로 표시하고 아래 `data-testid="line-hover"` 에 `2021 · Violations 2,524 · Penalty actions 693`
- `[4]frontend/src/app/echo/page.tsx` — 두 연도 카드를 `YearLineChart` 로. `ChartCard` 에 `className`. 지도 카드를 그리드 마지막으로 옮기고 `md:col-span-2`
