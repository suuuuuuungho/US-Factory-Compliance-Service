# SUU-207 feat(db): FR 상세 JSON을 표 4개 jsonl과 품질 보고서로 바꾼다

## 목표
`raw/` 아래 받아둔 상세 JSON 전부를 `parsed/{as_of}/fr_document·fr_identifier·fr_cfr_reference·fr_date_event.jsonl` + `quality_report.json`으로 바꾼다. 깨진 문서는 `held`로 사유와 함께 남기고, 성공 + held = 문서 수(조용히 사라지는 문서 0).

## 건드릴 파일
- 만들 것 (`[2] db/pipeline/2_Federal Register/`):
  - `fr_documents.py` — `document_key(publication_date, document_number) -> str`, `document_row(detail: dict, manifest: list[dict]) -> dict`, `identifier_rows(document_key, detail) -> list[dict]`
  - `fr_references.py` — `cfr_reference_rows(document_key, detail) -> list[dict]`, `date_event_rows(document_key, detail) -> list[dict]`
  - `fr_parse.py` — `parse_all(root, as_of) -> report`, `main(argv)`: `--root`(기본 `[2] db/2) Federal Register`), `--as-of`(기본 오늘)
- 테스트 (Claude가 씀, Codex 수정 금지): `[2] db/tests/2_Federal Register/test_fr_{documents,references,parse}.py`. fixture는 기존 `fixtures/detail_*.json` 3개 그대로

## 안 하는 것
- 본문 블록(`fr_block`), §63.x·Subpart 추출, `dates` 문장 해석, 관계(`fr_relation`), Public Inspection
- `release_id`·`reference_id`·`event_id`·`*_object_id` — 적재(SUU-209)에서 붙인다. jsonl에는 넣지 않는다
- DB 적재, 실제 실행(SUU-210)
- 기존 `fr_collect.py`·`fr_raw.py`·테스트·fixture 수정

## Codex 메모
- 본보기: `[2] db/pipeline/1_eCFR/ecfr_parse.py`(jsonl 쓰기, quality_report 모양), `fr_collect.py`(manifest 읽기 `_manifest`).
- **입력**: `root/raw/{연도}/{발행일}_{문서번호}/manifest.json`을 전부 훑는다(`raw/lists/`는 제외). 폴더 이름은 `{publication_date}_{document_number}` — 첫 `_`에서 나눈다(문서번호에 `_`는 없다). manifest에서 `kind == "detail"`인 **마지막** entry의 `path`를 읽는다. `sha256`이 `content_hash`.
- **held 사유**: detail entry 없음 → `"no detail"`, `json.loads` 실패 → `f"broken json: {exc}"`, 필수 키(`document_number`, `publication_date`, `html_url`) 없음 → `"missing field: ..."`. held는 `quality_report.json`의 `held` 목록에 `{publication_date, document_number, reason}`. held 문서는 jsonl에 넣지 않는다.
- **fr_document 열** (`[2] db/migrations/SUU-208_fr_tables.sql` 순서): `document_key, publication_date, document_number, canonical_url(=html_url), title, abstract, type_raw(=type), action, subtype, agencies, citation, volume, start_page, end_page, effective_on, comments_close_on, signing_date, docket_ids, regulation_id_numbers, full_text_xml_url, pdf_url, content_hash, raw_metadata, scope_status, body_status`. 값은 `detail.get(...)` 그대로 — `null`은 `None`, 빈 문자열로 바꾸지 않는다. `scope_status`는 항상 `"part63_list"`(보완 수집은 아직 없다). `body_status`: manifest에 `xml`이 있으면 `"xml"`, pdf만이면 `"pdf_only"`, 둘 다 없으면 `"missing"`.
- **fr_identifier**: `dockets[].id` → `identifier_kind="docket"`, `regulation_id_numbers[]` → `"rin"`. 순서: docket 먼저, 그다음 rin, 각각 API 순서. `docket_ids` 목록은 쓰지 않는다(FRL 번호가 섞여 있고 옛 문서는 `"OAR-2002-0040, FRL-7461-4"`처럼 한 문자열이다 — 쪼개지 않는다). 같은 값이 두 번 나오면 한 번만.
- **fr_cfr_reference**: `cfr_references[]`마다 한 행. `title`은 int, `part`는 `str(part)`(옛 문서는 정수 63으로 온다), `subpart/section/paragraph = None`, `relation_type="affects"`, `raw_citation=f"{title} CFR {part}"`, `evidence_locator=f"api:cfr_references[{i}]"`, `review_status="검토 전"`. `part`가 `null`이면 `raw_citation="40 CFR"`, `part=None`.
- **fr_date_event**: `effective_on`이 있으면 딱 한 행 `{event_kind:"effective", event_date, applies_to:None, raw_text: detail.get("dates"), evidence_locator:"api:effective_on", review_status:"검토 전"}`. 없으면 0행. `comments_close_on`·`signing_date`는 fr_document 열에만 두고 이번엔 사건으로 만들지 않는다.
- **출력**: `root/parsed/{as_of}/fr_document.jsonl` 등 4개 + `quality_report.json`. 매 실행 폴더를 새로 쓴다(덮어쓰기). jsonl은 `json.dumps(row, ensure_ascii=False)` 한 줄씩. **재실행 동일**을 위해 문서를 `document_key`로 정렬하고, 행에 시각·uuid·랜덤을 넣지 않는다. dict 키 순서도 고정(위 열 순서).
- **quality_report.json**: `{"as_of", "status", "documents", "succeeded", "held": [...], "rows": {"fr_document": n, "fr_identifier": n, "fr_cfr_reference": n, "fr_date_event": n}, "started_at", "finished_at"}`. `documents = succeeded + len(held)`. `status`는 raw 폴더를 하나도 못 읽는 게 아니면 `"succeeded"` — held가 있어도 실패가 아니다. `parse_all`은 파일에 쓴 것과 같은 dict를 반환한다.
- `main(argv)`: `argparse`, `--root`는 `Path(__file__).resolve().parents[2] / "2) Federal Register"`, `--as-of`는 `date.today().isoformat()`. 보고서를 `print(json.dumps(..., ensure_ascii=False))`, 반환 `0 if status == "succeeded" else 2`.
- 네트워크 없음. 실제 1,532건 실행은 SUU-210.
