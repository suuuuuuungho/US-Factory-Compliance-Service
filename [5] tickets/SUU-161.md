## Codex 메모

### `main.py`에 추가할 것
```python
from ecfr_eval import _subpart_of_chunk, section_key_of_chunk
from app.answer import answer_question, section_text

@app.get("/section/{section_key}")
def section(section_key: str) -> dict:
    if STATE["index"] is None:
        raise HTTPException(503, "index not ready")
    index = STATE["index"]
    rows = [c for c in index.chunks if section_key_of_chunk(c) == section_key]
    if not rows:
        raise HTTPException(404, "section not found")
    return {"section_key": section_key, "subpart": _subpart_of_chunk(rows[0]),
            "text": section_text(index, {"chunk_key": rows[0]["chunk_key"]})}
```
- `section_key_of_chunk(chunk)`: `node_key` 마지막 조각(`40/63/subpart-PPPP/section-63.4481` → `section-63.4481`). `_subpart_of_chunk`: `subpart-PPPP` → `PPPP`. 둘 다 `[2] db/pipeline/5_rag/ecfr_eval.py`(pythonpath에 있음, `rank_sections`가 쓰는 것과 같은 함수)
- `section_text(index, section)`은 `section["chunk_key"]`의 앞부분(`…/section-63.4481/`)으로 청크를 모아 `_piece_order`로 정렬 → `"\n\n"`으로 잇는다. `[3] backend/app/answer.py`
- 404 몸통은 FastAPI `HTTPException(404, "section not found")` → `{"detail": "section not found"}`. 테스트가 이 문자열을 본다(없는 길의 `Not Found`와 구분)
- 청크 5,700개 선형 검색이라 ms 단위. 캐시 불필요
- 503(색인 준비 전)은 `/ask`·`/health`와 같은 규칙(SUU-167). 테스트는 안 본다
