# SUU-102 feat(db): ECHO ZIP 안 CSV를 한 행씩 dict로 읽는다

## 목표
ZIP을 압축 풀지 않고 안의 CSV를 한 줄씩 `(행번호, {열이름: 값})`으로 넘겨준다.

## 건드릴 파일
- 만들 것: `[2] db/pipeline/3_ECHO/echo_rows.py`
- 이미 있음 (수정 금지): `[2] db/tests/3_ECHO/test_echo_rows.py`
- 참고만 (수정 금지): `echo_zip.py` — CSV 여는 방식이 똑같다 (`zf.open` + `TextIOWrapper(utf-8-sig, newline="")`)

## 안 하는 것
- 값 변환·날짜 해석 (SUU-103), 테이블 매핑 (SUU-105~)
- 열 개수가 헤더와 다른 행 처리 (필요하면 나중에)
- `tests/` 아래 수정

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| 행 수가 `inspect_zip`의 `row_count`와 같고 행번호는 헤더 다음 첫 데이터 행이 1. 빈 셀은 `""` | `test_row_numbers_start_at_one_and_count_matches_inspect_zip` |
| 셀 안 `\r\n`이 값 안에 그대로 남고, BOM은 첫 열 이름에서 빠진다 | `test_keeps_newline_inside_cell_and_strips_bom` |
| 잘못된 UTF-8 → `UnicodeDecodeError` (대체문자 금지). `ZipFile.read()` 안 쓴다 | `test_bad_utf8_raises_and_whole_member_is_never_read` |

## Codex 메모

테스트가 부르는 것:

```python
def iter_rows(zip_path: Path, member: str) -> Iterator[tuple[int, dict[str, str]]]
```

- 제너레이터. 이렇게:
  ```python
  with zipfile.ZipFile(zip_path) as zf, zf.open(member) as raw, io.TextIOWrapper(
      raw, encoding="utf-8-sig", newline=""
  ) as text:
      reader = csv.reader(text)
      header = next(reader)
      for no, row in enumerate(reader, start=1):
          yield no, dict(zip(header, row))
  ```
- `newline=""` 없으면 셀 안 `\r\n`이 행으로 쪼개진다. `errors=` 인자는 주지 않는다 (기본 strict → 깨진 바이트에서 `UnicodeDecodeError`).
- `csv.DictReader`를 써도 되지만 열 수가 다를 때 `None`/`restkey`가 섞이니 위처럼 `dict(zip(...))`가 더 단순하다.
- 표준 라이브러리만. 20줄 안팎.
- 나중에 SUU-111이 `for no, row in iter_rows(zip_path, "ICIS-AIR_FACILITIES.csv")`처럼 11개 멤버에 대해 부른다. 실제 파일은 가장 큰 게 2.2억 바이트·258만 행이라 리스트로 모으면 안 된다.
