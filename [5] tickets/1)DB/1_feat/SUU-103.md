# SUU-103 feat(db): ECHO 날짜·결측·금액 변환 규칙을 만든다

## 목표
CSV 셀 문자열을 날짜·결측 여부·금액(Decimal)·코드 리스트로 바꾸는 순수 함수 4개.

## 건드릴 파일
- 만들 것: `[2] db/pipeline/3_ECHO/echo_values.py`
- 이미 있음 (수정 금지): `[2] db/tests/3_ECHO/test_echo_values.py`

## 안 하는 것
- 파일별 열 매핑, 테이블 행 만들기 (SUU-105~110)
- 새 날짜 형식 추측 (ISO, 2자리 연도, 일/월 순서) — 전부 None
- `tests/` 아래 수정

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| `MM-DD-YYYY`·`MM/DD/YYYY` → `date`, 앞뒤 공백 무시. 그 외(빈값, `N/A`, `Unresolved`, ISO, 일/월 뒤바뀜, 2자리 연도, 없는 날짜) → `None` | `test_parse_date_accepts_both_us_formats_and_rejects_the_rest` |
| `""`·공백·`N/A`·`-9999`는 결측, `"0"`은 아님. `parse_amount`: 결측→`None`, 숫자→`Decimal`, 숫자 아님→`ValueError` | `test_missing_markers_and_amount_keeps_zero_apart_from_empty` |
| `split_codes`: 공백(여러 개 포함)으로 나눔, 결측→`[]` | `test_split_codes_splits_on_whitespace_and_empty_is_empty_list` |

## Codex 메모

테스트가 부르는 것:

```python
def parse_date(text: str) -> date | None
def is_missing(text: str) -> bool
def parse_amount(text: str) -> Decimal | None
def split_codes(text: str) -> list[str]
```

- 실제 데이터에서 본 모양 (2026-09-17 raw ZIP 표본):
  - 날짜: 10개 파일은 `06/24/2004`, `ICIS-AIR_VIOLATION_HISTORY.csv`만 `05-04-2004`. Pipeline `VIOL_END_DATE`에는 `N/A`(37,386건)·`Unresolved`·`Unresolved (Addressed)`가 섞여 있다 → `None`.
  - 결측: `-9999`는 Pipeline `EVAL_ACTIVITY_ID`(42,480건). `N/A`는 `VIOL_END_DATE`.
  - 금액: `PENALTY_AMOUNT` 정수 대부분, `87733.33` 같은 소수 있음. `EA_PENALTY_AMT` `103449.5`. 음수·통화기호 없음.
  - 다중 코드: 항상 **공백 구분** — `SIC_CODES` `3541 3545`, `PROGRAM_CODES` `CAANSPS CAASIP`, `POLLUTANT_CODES` `7003 300000319 300000329`. (`STACK_TESTS.POLLUTANT_CODES`는 이름 문자열이라 못 나눈다 — SUU-107이 알아서 함. 여기서는 신경 안 씀)
- 구현 힌트:
  - `parse_date`: `s = text.strip()`; `for fmt in ("%m-%d-%Y", "%m/%d/%Y"): try: return datetime.strptime(s, fmt).date() except ValueError: pass`; `return None`. `%Y`는 4자리만 받고 `%m`은 1자리도 받으니 `6/4/04`는 `%Y`에서 실패한다 → None (테스트에 있음).
  - `is_missing`: `text.strip() in ("", "N/A", "-9999")`.
  - `parse_amount`: `if is_missing(text): return None`; `Decimal(text.strip())` — `decimal.InvalidOperation`은 `ArithmeticError`라 `ValueError`가 아니다. `except InvalidOperation: raise ValueError(...)`로 바꿔 던진다.
  - `split_codes`: `[] if is_missing(text) else text.split()`.
- 표준 라이브러리만. 30줄 안팎. 클래스·설정값 없음.
