# SUU-122 feat(db): ECHO 파싱 결과를 release로 등록한다

## 목표
`raw/{as_of}/manifest.json`의 ZIP 2개를 `common_*` 표에 "이번 release" 하나로 등록하고 release_id를 돌려준다.

## 건드릴 파일
- 만들 것: `[2] db/pipeline/3_ECHO/echo_release.py` — `register_release(root, as_of, *, client, now=None) -> str`, 상수 `DATASET="echo"`, `SCOPE_KEY="icis_air_national+caa_pipeline"`, `PARSER_VERSION`
- 이미 있음 (수정 금지): `[2] db/tests/3_ECHO/test_echo_release.py`

## 안 하는 것
- echo_* 적재 (SUU-123), 검사 (SUU-124), 공개 전환 (SUU-125)
- 실제 Supabase 접속 (client는 인자로 받는다)

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| manifest 하나로 `common_ingest_run` 1, `common_raw_object` 2, `common_dataset_release` 1(staging), `common_release_object` 2(role icis_air/pipeline) 행이 생기고 release_id가 반환된다 | `test_registers_run_two_raw_objects_one_release_and_two_release_objects` |
| 같은 입력으로 두 번 불러도 release가 하나만 있고 같은 release_id를 돌려준다 | `test_reuses_existing_release_id_without_creating_duplicate_rows` |

## 구현 메모 (Codex 토큰 부족으로 Claude가 구현)
- SUU-65 `ecfr_release.py`를 그대로 따른다. 다른 점만:
  - manifest 항목은 `name`으로 찾는다: `ICIS-AIR_downloads.zip` → role `icis_air`, `pipeline_caa_downloads.zip` → role `pipeline`
  - `manifest_hash = sha256(f"{icis_sha}:{pipeline_sha}")`
  - `common_raw_object.storage_uri` ← manifest `path`, `source_modified_at` ← `last_modified`(HTTP 날짜 `Sun, 13 Sep 2026 02:10:24 GMT`)를 `email.utils.parsedate_to_datetime(...).isoformat()`으로 ISO 변환. 없으면 None
  - `common_ingest_run.scope = {"zips": ["ICIS-AIR_downloads.zip", "pipeline_caa_downloads.zip"]}`, `counts = {"raw_objects": 2}`
  - `PARSER_VERSION`은 파서 모듈에 없어서 이 모듈에 `"1"`로 둔다. 파서 규칙이 바뀌면 여기를 올린다 (같은 ZIP이라도 새 release가 생기게)
