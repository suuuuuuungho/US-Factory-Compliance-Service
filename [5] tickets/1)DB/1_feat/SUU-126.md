# SUU-126 feat(db): ECHO 등록·적재·검사·공개를 한 번에 실행한다

## 목표
`python echo_ingest.py [as_of]` 한 번으로 register → load → check → publish가 순서대로 돌고 release_id가 출력된다. 검사 실패면 공개하지 않고 release를 `failed`로 남긴다.

## 건드릴 파일
- 만들 것: `[2] db/pipeline/3_ECHO/echo_ingest.py` — `run_echo_ingest(root, as_of, *, client, conn, code_map_version=None, register_release=..., load_release=..., check_release=..., publish_release=...) -> str`, `CheckFailed(RuntimeError)`(`.release_id`, `.problems`), `_latest_as_of(parsed_root)`, `__main__`
- 이미 있음 (수정 금지): `[2] db/tests/3_ECHO/test_echo_ingest.py`

## 안 하는 것
- 실제 실행 (SUU-127), 재시도·부분 롤백, 스케줄링 (Step 4)
- `__main__` 블록 자동 테스트 (실제 Supabase 연결 — 코드 리뷰로 확인)

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| register → load(code_map_version 기본 = as_of) → check → publish 순서, 같은 release_id, 반환값 = release_id | `test_calls_register_load_check_publish_in_order_with_the_same_release_id` |
| check `ok=False` → publish 안 부름, `common_dataset_release.status="failed"` update, `CheckFailed` 예외에 problems | `test_failed_check_skips_publish_marks_release_failed_and_raises_with_problems` |
| as_of 생략 시 `parsed/` 최신 폴더, 없으면 FileNotFoundError(경로 포함) | `test_latest_as_of_picks_the_newest_parsed_folder_or_raises` |

## 구현 메모 (Claude 구현)
- SUU-68 `ecfr_ingest.py` 모양. 기본값: `echo_release.register_release`, `echo_load.load_release`, `echo_check.check_release`, `ecfr_publish.publish_release`(SUU-125 — 새 모듈 없음).
- 실패 처리: `client.table("common_dataset_release").update({"status": "failed"}).eq("release_id", release_id).execute()` 후 `raise CheckFailed(release_id, problems)`. 메시지는 problems를 줄바꿈으로 이어 붙인다 (CLI가 그대로 보여준다).
- `__main__`: root = `Path(__file__).resolve().parents[2] / "3) ECHO"`, as_of = argv[1] 또는 `_latest_as_of(root / "parsed")`, `client = create_client(SUPABASE_URL, SUPABASE_SECRET_KEY)`, `conn = psycopg.connect(SUPABASE_DB_URL)` (`with` 로 닫는다). 성공 시 release_id 출력, `CheckFailed`면 problems 출력 후 exit 1.
- `SUPABASE_DB_URL`은 Session pooler(5432) 주소 (COPY 때문). `.env` 자동 로드는 안 한다 — eCFR과 같이 환경변수로 넘긴다.
