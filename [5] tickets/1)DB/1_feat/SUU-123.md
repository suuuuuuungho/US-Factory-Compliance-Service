# SUU-123 feat(db): jsonl 13개를 COPY로 echo 테이블에 적재한다

## 목표
`parsed/{as_of}/` jsonl 13개와 `code_map/{version}/echo_code_map.jsonl`을 release_id를 붙여 `echo_*` 표에 `COPY FROM STDIN`으로 넣는다. 같은 release를 다시 돌려도 행이 늘지 않는다.

## 건드릴 파일
- 만들 것: `[2] db/pipeline/3_ECHO/echo_load.py` — `load_release(root, as_of, release_id, code_map_version, *, conn) -> dict[str, int]` (표별 넣은 행 수, `echo_code_map` 포함)
- 고칠 것: `requirements.txt` — `psycopg[binary]` 추가
- 이미 있음 (수정 금지): `[2] db/tests/3_ECHO/test_echo_load.py`

## 안 하는 것
- release 등록(SUU-122), 검사(SUU-124), 공개 전환(SUU-125), 실제 실행(SUU-127)
- 충돌 행 고치기·합치기, `echo_source_row`의 정상(ok) 행 적재 (보류 행만)
- 인덱스, 트랜잭션 재시도

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 |
|---|---|
| 13개 표 행 수 = jsonl 줄 수(source_row는 held 줄 수), 모든 행 첫 열 release_id, `source_object_sha256` → `source_object_id`, 부모 표 먼저 COPY | `test_copies_every_jsonl_row_with_release_id_and_only_held_source_rows` |
| 같은 release_id로 두 번 돌려도 행 수 그대로. 자식 표부터 `DELETE ... WHERE release_id = %s` 13개 → COPY. code_map은 삭제 없이 `ON CONFLICT DO NOTHING` | `test_loading_the_same_release_twice_does_not_grow_any_table` |
| date는 ISO 문자열, numeric은 문자열 그대로(float 금지), jsonb는 `json.dumps` 문자열, None은 NULL, bool/int 그대로 | `test_values_are_copied_in_the_text_form_postgres_needs_for_each_column_type` |

## 구현 메모 (Codex 토큰 부족으로 Claude가 구현)
- psycopg 3: `with conn.cursor() as cur: with cur.copy(f"COPY {table} ({cols}) FROM STDIN") as copy: copy.write_row(values)`. 텍스트 COPY라 str/int/bool/None만 넘기면 Postgres가 열 타입으로 해석한다 — date·numeric·uuid는 문자열, jsonb는 `json.dumps(..., ensure_ascii=False)`.
- 열 목록 = jsonl 키 순서 그대로, 앞에 `release_id`. 예외: `echo_source_row`는 `source_object_sha256` 대신 `source_object_id` (`select o.object_id, o.sha256 from common_raw_object o join common_release_object r using (object_id) where r.release_id = %s`로 sha→id dict).
- 순서(FK): 삭제는 `echo_parse.TABLES` 역순, COPY는 정순 (`echo_source_row, echo_facility, echo_facility_identifier, echo_industry, echo_program, echo_program_subpart, echo_pollutant, echo_activity, echo_activity_facility, echo_violation, echo_violation_facility, echo_penalty, echo_pipeline_link`).
- jsonl은 한 줄씩 읽어 바로 write_row (750만 행, 4.5GB — 리스트로 올리지 않는다). 마지막에 `conn.commit()` 한 번.
- `echo_code_map`: 행마다 `insert into echo_code_map (...) values (%s,...) on conflict do nothing` (306행이라 COPY 불필요). `cfr_title`은 문자열 `"40"` → int.
- 실행 시(SUU-127) `SUPABASE_DB_URL`은 Supabase의 **Session pooler(5432)** 주소를 쓴다 (Transaction pooler는 COPY·긴 트랜잭션에 부적합).
