# SUU-108 feat(db): 공식·비공식 처분 CSV를 activity·penalty 행으로 바꾼다

## 목표
FORMAL_ACTIONS·INFORMAL_ACTIONS 한 행(dict)을 `echo_activity`(kind formal/informal) + `echo_activity_facility` + `echo_penalty`(공식만, 아니면 None)로 바꾼다.

## 건드릴 파일
- 만들 것: `[2] db/pipeline/3_ECHO/echo_actions.py`
- 이미 있음 (수정 금지): `[2] db/tests/3_ECHO/test_echo_actions.py`, `echo_values.py`(`is_missing`, `parse_date`, `parse_amount`), `echo_activities.py`(행 형식 참고 — 같은 10키)

## 안 하는 것
- 처분 단위로 금액 합치기·시설/위반에 배분하기 (`amount_scope="row"`로 두고 끝)
- 같은 ACTIVITY_ID 여러 행 합치기 (SUU-111 dedupe/충돌 보고)
- jsonl 쓰기, `release_id` 붙이기, `tests/` 수정, `echo_activities.py` 수정

## Codex 메모

테스트가 부르는 것:

```python
def action_rows(kind: str, row: dict[str, str], source_row_no: int) -> tuple[dict, dict, dict | None]
```

- Linear 티켓엔 `action_rows(kind, row)`로 적혀 있지만 **행번호 인자를 추가**했다. 이유: 실제 FORMAL에서 같은 `(ACTIVITY_ID, PGM_SYS_ID)` 쌍이 `ENF_TYPE_CODE`별로 여러 행이고 금액이 다른 쌍이 425개라, 벌금 키를 행 단위로 둬야 사실이 안 섞인다 (SUU-106 `pollutant_row`와 같은 방식).
- `kind`는 `formal` / `informal` 둘만. 다른 값은 `ValueError`.
- 실제 헤더 (2026-09-17 ZIP):
  - FORMAL 10열: `PGM_SYS_ID, ACTIVITY_ID, ENF_IDENTIFIER, ACTIVITY_TYPE_CODE, ACTIVITY_TYPE_DESC, STATE_EPA_FLAG, ENF_TYPE_CODE, ENF_TYPE_DESC, SETTLEMENT_ENTERED_DATE, PENALTY_AMOUNT`. 106,519행. 금액: 정수 71,890 / `0` 33,492 / 소수 1,137 / 빈값 0 (규칙은 둔다). 빈 날짜 42.
  - INFORMAL 10열: 앞 8열 같고 `ACHIEVED_DATE, OFFICIAL_FLG`. 339,878행, 빈 날짜 357. 같은 ACTIVITY_ID 중복 165,886행 (시설 여러 개).
- activity 키 순서 = `echo_activities.py`와 동일 10키: `activity_kind, activity_id, type_code, type_desc, lead_flag, monitor_code, monitor_desc, activity_date, raw_date, attributes`.
  - `type_*` ← `ACTIVITY_TYPE_*`, `lead_flag` ← `STATE_EPA_FLAG`, `monitor_*` ← 항상 None (열 없음)
  - 날짜 열: formal `SETTLEMENT_ENTERED_DATE`, informal `ACHIEVED_DATE`. `activity_date = parse_date(원문)`, `raw_date` 원문 (`""`도 `""`)
  - `attributes` = 쓴 열(`PGM_SYS_ID, ACTIVITY_ID, STATE_EPA_FLAG, ACTIVITY_TYPE_*`, 날짜 열, `PENALTY_AMOUNT`)을 뺀 나머지, 키는 열 이름, 값 `""`→None
- link = `{"activity_kind", "activity_id", "pgm_sys_id"}` (SUU-107과 같다).
- penalty (formal만) 키 순서: `penalty_key, activity_kind, activity_id, amount, amount_kind, currency, amount_scope, raw_amount, source_locator`
  - `penalty_key = f"formal:{source_row_no}"`, `source_locator = f"ICIS-AIR_FORMAL_ACTIONS.csv:{source_row_no}"`
  - `amount = parse_amount(row["PENALTY_AMOUNT"])` (Decimal, `""`→None), `raw_amount` 원문, `amount_kind="penalty"`, `currency="USD"`, `amount_scope="row"` 고정
- `""`→None은 `is_missing`. `strip()` 안 함. 표준 라이브러리만, 50줄 안팎. `from echo_values import is_missing, parse_amount, parse_date` (평면 import). `echo_activities.activity_rows`를 부르지 말고 독립으로 쓴다 (kind 검사가 다르다).
