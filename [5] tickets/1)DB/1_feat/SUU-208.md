# SUU-208 feat(db): FR 전용 테이블 4개를 Supabase에 만든다

## 목표
SUU-207 파서 산출 jsonl 4개가 들어갈 `fr_document`·`fr_identifier`·`fr_cfr_reference`·`fr_date_event`를 Supabase에 만들고 RLS로 외부 노출을 막는다.

## 건드릴 파일
- 만들 것: `[2] db/migrations/SUU-208_fr_tables.sql` — 적용한 DDL 기록
- Claude가 Supabase MCP(`apply_migration`)로 project `husqnrcuoaogdkbpjnep`에 직접 적용함 (SUU-121과 같은 방식). Codex 작업 아님. 티켓에 적은 "SQL 파일을 읽는 pytest"는 SUU-121 선례대로 DB 직접 조회로 대신했다

## 안 하는 것
- 데이터 적재 (SUU-209), `fr_block`·`fr_relation`·`fr_public_inspection` (본문 파싱 회차)
- RLS 정책 (SUU-63과 같이 정책 없이 RLS만 켠다 — service_role만 접근)

## 완료 기준 ↔ 확인 방법
| 완료 기준 | 확인 방법 |
|---|---|
| fr_ 표 4개, 각각 `release_id` FK | `pg_class`/`pg_constraint` 조회 → 4표, FK 수 document 4 · identifier 2 · cfr_reference 3 · date_event 2 |
| `fr_document (release_id, publication_date, document_number)` 고유 제약, 자식 3표 `(release_id, document_key) → fr_document` 복합 FK | `fr_document_release_id_publication_date_document_number_key` 확인, 자식 FK 확인 |
| 4표 모두 RLS 활성 | `relrowsecurity = true` 4개 |

## 적용 결과 (2026-09-21)
- `fr_document`: PK `(release_id, document_key)`, `document_key = '{publication_date}/{document_number}'`. 계획 3-5절 열에 API 값을 그대로 담는 열을 더했다: `effective_on/comments_close_on/signing_date`, `docket_ids/regulation_id_numbers`(jsonb), `full_text_xml_url/pdf_url`. `source_object_id/body_object_id/pdf_object_id`는 nullable FK → `common_raw_object` (적재기가 채움). `scope_status`(part63_list/supplement_candidate), `body_status`(xml/pdf_only/missing)
- `fr_identifier`: PK `(release_id, document_key, identifier_kind, identifier_value)`, kind는 docket/rin
- `fr_cfr_reference`: `reference_id uuid PK`, `(ecfr_release_id, ecfr_node_key)` → `ecfr_node` 복합 FK, 둘 다 NULL이거나 둘 다 있어야 함(check). 1차는 `subpart/section` NULL, `relation_type='affects'`, `review_status='검토 전'`
- `fr_date_event`: `event_id uuid PK`, 1차는 `event_kind='effective'`만
- 인덱스 7개: 발행일, 문서번호, (identifier_kind, identifier_value), 참조/사건의 (release_id, document_key), (title, part, subpart, section), (event_kind, event_date)

## Codex 메모
이 티켓은 Codex 작업이 아니다. SUU-207(파서)·SUU-209(적재)는 이 4개 표가 이미 있다는 전제로 짠다. 열 목록은 `SUU-208_fr_tables.sql`이 원본이다 — jsonl 키 = 열 이름.
