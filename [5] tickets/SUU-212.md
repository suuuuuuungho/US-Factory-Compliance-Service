# SUU-212 fix(frontend): 상단바 검은 배경 없애고 메뉴를 가운데로

## 목표
상단바는 글자만(제목 왼쪽, 메뉴 4개 가운데, 전부 흰색). 배경·밑줄 없이 뒤 화면이 비친다. 랜딩 히어로 이미지가 상단바 밑까지 올라온다.

## 건드릴 파일
- 고칠 것 `[4]frontend/src/app/TopNav.tsx` — `bg-canvas border-b border-hairline` 뺌, `grid grid-cols-[1fr_auto_1fr]`, nav `col-start-2`, 링크 `text-white`, header `relative z-40`
- 고칠 것 `[4]frontend/src/app/page.tsx` — section `min-h-[calc(100dvh-60px)]` → `-mt-[60px] min-h-[100dvh]`

## 안 하는 것
- 메뉴 항목·링크, 다른 페이지(applicability 등의 `100dvh-60px`는 그대로), 글꼴

## 완료 기준 ↔ 테스트
| 완료 기준 | 테스트 함수 (`topnav_transparent.test.tsx`) |
|---|---|
| header 배경·밑줄 없음, nav 가운데, 글자 흰색 | `header에 bg-canvas·border-b 없고, 메뉴 nav가 가운데 칸, 제목·링크가 text-white 다` |
| 히어로가 상단바 밑까지 | `랜딩 hero section이 min-h-[100dvh] + -mt-[60px] 다` |

## 메모
- 다른 페이지는 body 배경이 canvas(검정)라 상단바가 투명해져도 보이는 건 같다(밑줄만 사라짐)
- 히어로가 헤더 아래로 들어가므로 header에 `relative z-40`을 줘야 글자가 이미지 위에 보인다
