# SUU-200 feat(frontend): 기본 배치를 질문/Subparts+조문 | Memo | Checklist로

## 목표
첫 방문·Reset layout의 기본 배치:
```
Question (위, 높이 약 25%)        | Memo  | Checklist
Subparts | §조문 (Subparts 옆)     |       |
   ← 약 57% →                     ← 18% → ← 25% →
```
Memo가 처음부터 열려 있고, 조문(§)은 Subparts 오른쪽(왼쪽 열 안)에 열린다.

## 건드릴 파일
- `[4]frontend/src/app/Workspace.tsx`
  - `DEFAULT`에 `memo` 추가 (question → checklist 오른쪽 → subparts 아래 → memo는 checklist 왼쪽)
  - 첫 조문 위치: `subparts`가 있으면 그 오른쪽, 없으면 checklist/마지막 칸 오른쪽
  - 기본 칸 크기: `initialHeight`(question = 높이 25%), `initialWidth`(memo = 폭 18%, checklist = 25%). api.width/height가 0(jsdom)이면 생략
- `[4]frontend/tests/workspace.test.tsx`, `memo_pane.test.tsx` — 기본 탭에 Memo 포함, 조문 탭 위치, Memo 기본 열림으로 갱신

## 안 하는 것
- 저장 키 변경(사용자가 저장한 배치는 그대로), MemoPane 내용 변경
