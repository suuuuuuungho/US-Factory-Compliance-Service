# 미국 공장 Compliance AI — 3분 요약

> 미국 공장이 환경청(EPA)에 "이 규정이 우리 공장에 적용되나요?"라고 물으면 **답장까지 중앙값 101일.**
> 이 서비스는 **즉시**, 근거 조문과 함께 답합니다.

- 배포: https://us-factory-compliance-service.vercel.app
- **17일 · 1인 개발** (2026.09.10 ~ 09.26)

---

## 어떤 문제인가 — 숫자 3개면 충분합니다

1. 미국 공장이 지켜야 하는 대기오염 규정(40 CFR Part 63)은 **조문 2,473개, 약 463만 토큰.**
   사람이 다 읽을 수 없고, LLM 컨텍스트에도 통째로 안 들어갑니다.
2. 이 규정이 **월 1회 이상 개정**됩니다. 학습 시점에 멈춘 LLM만으로는 쓸 수 없습니다.
3. 대상 공장 **10곳 중 3곳(27.9%)이 위반 이력.** 서류를 틀리면 서명한 담당자 **개인이 법적 책임**을 지고,
   허가 갱신을 놓치면 **공장이 멈춥니다.**

---

## 가장 자랑하고 싶은 것 두 가지

**① "판정하지 않는다"를 문구가 아니라 코드 구조로 지켰습니다.**

AI가 "적용됩니다"라고 판정하면 사람은 원문을 안 읽습니다. "참고용입니다" 문구로는 행동이 안 바뀝니다.
그래서 답변 JSON에서 `applies` 같은 **판정 필드를 아예 삭제**해, 시스템이 판정을 구조적으로 말할 수 없게 했습니다.
대신 **후보 조항 + 적용을 가르는 기준 + 확인 체크리스트**를 주고, 모든 문장에 조문 근거를 답니다.

**② 기술을 그냥 채택하지 않았습니다. 실험을 통과해야 채택했습니다.**

**실험 9번 — 채택 6, 기각 3.** 임베더 2종, 리랭커 3종, LLM 2종, 하이브리드 가중치 132조합까지,
"좋다더라"로 고른 것이 하나도 없습니다. 전부 같은 평가셋 102건 위에서 전/후 숫자로 결정했습니다.
특히 **점수가 올라도 기각한 실험이 있습니다.** 정답 조문을 고정으로 끼워 넣는 방식은 지표가 올랐지만(+0.046),
평가셋의 정답을 미리 아는 꼼수라서 버렸습니다.

---

## 결과 — 감이 아니라 실측으로

평가셋부터 지어내지 않았습니다. **실제 공장이 EPA에 물은 질문 102건**(공식 판정서한)에서 질문과 정답 조문을 추출했습니다.

| 지표 | 시작 | 최종 |
|---|---|---|
| 정답 조문이 상위 5개 안에 (Hit@5) | 69% | **93%** |
| 검색 순서 품질 (nDCG@10) | 0.437 | **0.692 (+58%)** |

- 시작점(베이스라인)은 Kanon 2 임베더 + Contextual Retrieval. **출발점의 임베더부터 실험으로 골랐습니다** (일반 bge-m3 0.297 vs 법률 특화 Kanon 2 0.437).
- 그 위에 단계마다 실험으로 확인하고 채택/기각했습니다: 리랭커 3종 비교(+0.124) → 하이브리드 검색 → 후처리 규칙(+0.063) → LLM 리랭크(+0.061).
- 답이 근거 없이 지어낸 인용은 **코드가 자동으로 제거**합니다. (인용 근거율 99.6%)
- **품질 합격선을 CI에 넣어, 점수가 선 아래면 GitHub 병합이 자동으로 막힙니다.**

---

## 혼자 했지만, 팀처럼 일했습니다

저는 방향을 정하고, 판단하고, 검토만 했습니다. **코드는 한 줄도 직접 쓰지 않았습니다.**

```
사람 (아이디어·승인) → Claude Code (설계 + 실패하는 테스트 작성)
→ Codex (구현 + PR) → CI (테스트·규칙·품질 합격선 검사)
→ 사람 (직접 병합) → 자동 배포 (Render·Vercel) → Slack 알림
```

- **테스트 작성자(Claude)와 구현자(Codex)를 분리**했습니다. 구현자가 자기 코드에 맞춰 테스트를 고치는 것을 규칙으로 금지했습니다.
- 병합은 자동화하지 않고 **사람만** 합니다. 중요한 판단에는 사람이 개입합니다.
