# 프로젝트 소개 문서

이 폴더의 파일이 각각 무엇인지 적은 안내서입니다. `0_Project_summary` → `1_Project_full` 순서로 읽으면 됩니다.

| 파일 | 설명 |
|---|---|
| `0_Project_summary.md` | 면접관용 3분 요약 원본. 문제, 서비스 정의, 결과, 데이터 신뢰성, 어필 포인트, 개발 방식을 가장 짧게 담았습니다 |
| `1_Project_full.md` | 프로젝트 전체 설명서 원본. 문제 정의, 데이터셋과 신뢰성, RAG 검색·답변 품질 개선 실험, TDD 자동화, 콜드메일, 직접 정한 것까지 모두 담았습니다 |
| `0_Project_summary.docx` / `.pdf` | summary md를 `/report`로 만든 Word·PDF입니다. git에는 올리지 않습니다 |
| `1_Project_full.docx` / `.pdf` | full md를 `/report`로 만든 Word·PDF입니다. 목차가 들어 있고, git에는 올리지 않습니다 |

md가 원본입니다. 내용은 md만 고치고, Word·PDF는 `/report`로 다시 만듭니다. 작성 규칙은 `[1] docs/4) workflow/3_doc_rules.md`에 있습니다.
